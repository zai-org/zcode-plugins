# 胸牌桌签制作

直接用参会名单打印活动胸牌和桌签。选上名单（和 logo），填好活动名称和日期，就能得到排在 A4 上、带裁切角线的胸牌——名字自动调整到合适大小，下面是单位、职位，底部按身份（嘉宾、讲师、工作人员等）印不同颜色的色条。桌签对折后两面都能看到名字。五种胸牌尺寸，可选印每位参会者编号的二维码，中英文名都支持。在本地运行，不用设计服务，无需 API 密钥。

## 功能

- **直接用名单**：识别 姓名、英文名、单位、职位、身份、桌号、编号 以及英文列名。
- **A4 拼版胸牌**：100×70、90×120、4×3 英寸、85.6×54 或 A6，带裁切角线；页眉印活动名和 logo。
- **名字自动适配**：较长的中文、英文、少数民族姓名会自动缩小以放得下。
- **身份颜色**：每种身份自动配色，也可以自己指定（如 嘉宾=#b45309）。
- **桌签**：A4 横向，沿虚线对折，两面都能看到名字。
- **二维码**：可选把每人的编号印成二维码，方便签到扫码。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `name-badge-maker/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 attendees.xlsx 给 2026 青禾产品大会做胸牌”
- “换成 90×120 的胸牌，按身份排序，加上二维码”
- “打印桌签，不显示单位”

## 工具

| 工具 | 作用 |
|---|---|
| `badge_open` | 读取参会名单并预览胸牌，并打开面板 |
| `badge_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `badge_status` | 查看当前数据、问题和汇总 |
| `badge_export` | 导出 badges.pdf 和 tent-cards.pdf |

导出文件写到工作区的 `name-badge-maker/<项目>/` 文件夹。

## 范围（v0.1）

- 胸牌打印在普通纸上再裁切，v0.1 不支持不干胶标签模板。
- v0.1 不支持在胸牌上放照片。
- 中文需要电脑上有中文字体（会自动查找）。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `name-badge-maker/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/name-badge-maker/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-name-badge-maker test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
