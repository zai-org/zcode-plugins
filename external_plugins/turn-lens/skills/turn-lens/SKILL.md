# TurnLens

展示当前 ZCode 会话的统计卡片：轮数、步数、模型用时、工具调用用时、首 token 平均（TTFT）和输出速度（TPS）。数据来自本地只读会话数据库，不修改任何内容。

## 运行

脚本位于本技能目录下的 `scripts/session-stats.mjs`。技能加载时会给出本技能的 base directory，用它拼出脚本绝对路径后运行：

```bash
node "<skill-base-dir>/scripts/session-stats.mjs"
```

常用参数：

- `--session <id>`：指定会话 ID；省略时选择当前工作区最近更新的会话。
- `--workspace <dir>`：覆盖工作区目录（默认 `$ZCODE_PROJECT_DIR`，否则当前目录）。
- `--db <path>`：覆盖会话数据库路径（默认 `$ZCODE_SESSION_DB_PATH`，否则 `~/.zcode/cli/db/db.sqlite`）。
- `--include-active`：把当前进行中的轮次也算进去；默认只统计已完成的轮次。
- `--session-totals`：显示整个会话的累计统计；默认只显示最新一轮。
- `--auto`：自动展示模式（供 Stop hook 使用）。包含当前轮并把它视为“刚完成”，卡片不显示“进行中”提示。
- `--details`：追加每轮明细表。
- `--json`：输出 JSON 而不是 Markdown（调试或二次处理用）。

## 输出要求

- 成功时，脚本 stdout 已经是一张完整的 Markdown 卡片。把它**原样**作为回复主体展示，不要放进代码块，不要重排或改写数字。
- 可以在卡片前后各加一句简短说明（例如“统计的是已完成的轮次”），但不要重复表格内容。
- 脚本以非零状态退出或输出错误时，转述错误并给出修复建议；不要猜测数据。
- 不要修改数据库；脚本以只读方式打开。

## 指标口径

- 轮：`turn_usage` / `model_usage` / `tool_usage` 中出现的 turn_id 数量（默认排除进行中的轮次）。
- 步：`tool_usage` 中的工具调用数（按 tool_call_id 去重）。
- 模型用时：`model_usage` 请求区间的并集；包含模型排队、思考与流式输出时间，不含空闲等待。
- 工具调用用时：每轮工具执行区间的并集（并行工具只算一次）。
- 首 token 平均（TTFT）：主轮模型请求 `time_to_first_token_ms` 的算术平均。
- 输出速度（TPS）：主轮输出 tokens ÷（请求耗时 − TTFT），按请求汇总后计算。
- 用户输入（约）：从 `message` / `part` 读取用户消息文本，按 CJK 1 字≈1 token、其他约 4 字符≈1 token 估算；不是模型请求的上下文 tokens。
- 只统计 `main_turn` / 子智能体请求；不含标题生成和上下文压缩。子智能体会话需要显式用 `--session <id>` 指定。

## 单轮统计卡（v0.2.0，面板可开关）

插件注册了一个 `Stop` hook：每轮结束时运行 `session-stats.mjs --session <id> --auto`，把生成的**本轮**统计卡注入一次续写请求，助手会把卡片原样输出。

- 代价：每轮会多一次很短的模型请求（约几秒、几百 output tokens）。
- 副作用：续写会成为该轮最后一条助手消息，ZCode 可能把原本的主回复折叠；这是 hook API 的固有限制。
- 不会循环：hook 检查 `stop_hook_active`，并且上一轮回复已经包含统计卡（`📊 单轮统计卡`）时跳过。
- 子智能体会话跳过；没有可用用量记录时静默跳过。
- 开关：侧栏面板底部的「单轮统计卡」。这是**全局设置**，对所有会话生效；面板会写 `~/.zcode/cli/plugins/data/turn-lens/auto-display.json`。也可以设置环境变量 `SESSION_STATS_AUTO_DISABLED=1`、项目下 `.zcode/session-stats.auto-off`、插件数据目录 `auto-display.disabled`。
- 更新插件后需要重载会话或新建任务，hook 才会生效。0.10.0+ 的面板 UI 支持热刷新；hook 脚本改动下一轮生效。

## 侧栏面板（v0.11.0）

插件在 ZCode 侧栏注册了「TurnLens」面板（MCP Apps），默认每 10 秒刷新，可在底部下拉框选择 5 / 10 / 30 / 60 秒（向上展开，写 `localStorage["turnlens.pollMs"]`），始终包含进行中的轮次。面板跟随 ZCode 主题（背景/文字/边框/速度色/滚动条/气泡），强调色使用固定蓝色系（ZCode 浅色主题的 `--color-text-info` 接近黑色，不能直接拿来当强调色）；刷新按钮右侧的主题按钮循环 4 档：跟随 ZCode（默认）、白色浅色、深色、高对比度深色，选择写在 localStorage；标题按宿主 locale 只显示一种语言（中文「会话统计」/英文「Session Stats」）。数值超过 1 万用「万」、超过 1 亿用「亿」，最多 2 位小数，并带千分位。顶部不再有独立的轮次/步数 hero；汇总区上方一行小字显示轮次、步数和主轮请求，下面是两张**无边框**主卡：累计消耗 Token 和平均缓存命中率。累计消耗 = 模型输入 + 模型输出，卡内用输入/输出拆分条和两行小字；平均缓存命中率 = 会话缓存读取 tokens ÷ 会话模型输入 tokens，卡内有进度条和小字「缓存读取 / 未缓存读取」。每张卡只有一个气泡，多段内容统一分点；表格每个格子也只有一个合并后的气泡。其余区域沿用同一套卡片语言：四行指标、耗时占比、轮次表和底部设置卡都是无边框圆角卡片，阴影比两张汇总主卡更轻；暗色/高对比度用略亮的 `--surface` 区分页面。每轮明细：轮次/缓存命中率、状态、工具步数/模型用时、TTFT/TPS、用户输入、上下文长度/上下文增量、模型输入/模型输出、模型请求次数/工具请求错误；轮次和状态也可以在「列设置」里开关并参与左/中/右对齐，默认左对齐；缓存命中率在轮次下方换行并按 ≥95% 绿、≥85% 蓝、≥70% 黄、≥50% 橙、<50% 红分级着色；上下文增量 <0 时状态列显示「压缩」徽标，和「当前」徽标同排。表头每行都不换行，默认所有列等宽 70px，688px 可完整显示，窄侧栏横向滚动；拖动表头边界可调整列宽并写入 localStorage，「列设置」可恢复默认。成对表头用第二行弱化区分，无分隔线；状态圆点保留彩色光晕，TTFT/TPS 按 5 级速度着色；气泡左右内边距一致，圆点列表带悬挂缩进，所有多段内容都分点，大数用万/亿。汇总区是**会话累计**（累计模型用时、累计工具用时、平均 TTFT、平均 TPS），面板本身不出现纵向滚动条，只有轮次表内部滚动；面板底部「单轮统计卡」设置卡上下内边距为 2px，里面有一张迷你卡片示意图。引导输入（`session_input.delivery = 'guide'`）不会新建轮次行：同一轮仍聚合成一行，状态列显示「引导」徽标，用户输入估算包含引导消息文本；模型用时仍按整轮所有主轮请求区间合并。ZCode 的「工作时间」按引导消息分段并显示最新一段的墙钟时长，所以会和本表的整轮模型用时不同；模型用时气泡会同时给出 `lastSegmentMs`，即 ZCode 的最新分段工作时间。

面板由插件自带的 MCP server 调用同一个统计脚本取数，**不经过模型，不消耗 tokens**。

用户要打开面板时，优先告诉他从 ZCode 侧栏「+」→「新标签页」→「查看所有插件」里选择「TurnLens」并固定标签页（零额外请求）；也可以输入 `/turn-lens-panel`（兼容旧命令 `/session-stats-panel`）或说“打开会话统计面板”，模型调用 `open_session_stats`，宿主会按 `preferredDisplayMode: "fullscreen"` 把面板打开到侧栏，但这条路径会有一次很短的模型请求。新标签页的「应用插件」推荐位由 ZCode 客户端的 `uiPluginRecommendations` 配置决定，插件无法自己注册进去。若用户抱怨单轮统计卡让主回复折叠，建议在面板底部关闭它，改用面板实时统计。
