# report-panel（报告评审团）

对 AI 撰写的中文长报告做对抗式深度评审。解决的不是风格层问题（去 AI 味请用 humanizer 类工具），而是内容层：论证经不经得起对抗、结构要不要重排、数字口径有没有自相矛盾、有没有交付资格级的阻断项。**只出意见，绝不改稿。**

## 组件

| 组件 | 触发 | 用途 |
| --- | --- | --- |
| `/report-panel:review`（command） | 显式命令 | 三步流水线：硬校验→对抗评审→重排方案 |
| `panel-review`（skill） | 对抗评审 / 红队审查 / 把关 / 挑毛病 | 多评审员并行盲评→仲裁→四档判定 |
| `consistency-check`（skill） | 核对数字 / 查口径 / 前后矛盾 | py 确定性硬校验，近零 token |
| `dev-edit`（skill） | 重排 / 重构框架 / 大纲预审 | 发展性编辑：骨架诊断 + ≥2 套重排方案 |
| `panel-appeal`（skill） | 对意见不服 / 复议 / 申辩 | 独立复核员只核被申辩条目，维持或改判 |
| `panel-recheck`（skill） | 改完复检 / 修订回归验证 | 逐条对账 + 改动区新伤扫描 |

## 判定体系

- **四档判定**：APPROVE（可交付）/ REVISE（改后交付）/ RESTRUCTURE（局部重排）/ REBUILD（推倒章节结构）
- **三级分档**：A=硬伤（事实错/数字矛盾/论据不支持结论）；B=结构（论证链断/前提缺失）；C=表达
- **release_blockers**：结构性手术治不了、须作者或外部决断的交付阻断项（如底本不可溯源）
- **验证断言**：每条意见附带"应出现/应消失/可复算"断言，修订后可机械判"已修"（panel-recheck 对账基础）

## 架构：确定性层先行，LLM 只做判断

`py/` 目录是零 I/O 纯函数层（Python 3 标准库，无第三方依赖），评审链开工先跑机器门禁：

- **算术复算**（X/XP/XS）：合计≠分项、同句占比失配、同指标异值聚类——LLM 只裁口径归属，不重算算术
- **空心证据扫描**（XH）："实验表明/可忽略"类断言句内无数据锚且 ±40 行无数据表，直接定级提示
- **断言候选抽取**：承重论点登记表，跨节矛盾在断言层显影
- **冻结哈希**：评审范围的对外文件清单 + SHA-256，防评审中途改稿
- **输入校验**：PDF/zip 容器、非 UTF-8 输入当场拦截并给转存指引

评审链为多子代理并行盲评（逻辑审计/魔鬼代言人/数据严谨/财务/合规边界等席位）→ 意见聚类 → 定向调查复核 → 终审仲裁。附录模板与席位指令见 `skills/panel-review/SKILL.md`。

## 质量与测试

`tests/` 内置 6 个零依赖测试套件（共 196 断言，Python 3 直接运行，无需 pytest）：

```shell
python3 tests/test_extract_l0.py    # 底账/断言抽取/预复算（49 断言）
python3 tests/test_packages_l0.py   # 证据包构造/覆盖完备性（44 断言）
python3 tests/test_tiering_l0.py    # 判级对账门规则（55 断言）
python3 tests/test_render_l0.py     # 评审报告渲染（24 断言）
python3 tests/test_freeze_l0.py     # 冻结清单/哈希（17 断言）
python3 tests/test_gt_score_l0.py   # 注入考卷对拍器（7 断言）
```

真实样张冒烟为可选段：设 `PANEL_BENCH_DIR` 指向样张目录即跑，缺省自动跳过。历史注入考卷实测：21 处预埋错误召回 20，阴性对照零误报。

## 语言边界

规则集（断言句式、数字句式、书名号引用、全半角归一）针对**中文报告**优化；英文报告可用但抽取规则覆盖较弱，一致性检查建议人工复核。

## 网络访问、依赖与副作用

- 插件自身零网络请求：不调用外部 API、不下载、无遥测、无 MCP 服务、无 Hook；`py/` 确定性层完全本地运行。
- 运行时依赖 ZCode 宿主的模型推理：评审链经会话内子代理执行，产生正常的 LLM API 流量（与任何 skill 相同，由宿主账号计费；多席并行评审 token 消耗显著高于单轮对话）。
- skills 不含 WebSearch/WebFetch 指令，不访问外部网站；报告内外部事实的联网核验属重型评审编排的调查层能力，不在本包。
- 依赖：Python 3（≥3.8）标准库。
- 副作用：`consistency-check` 只读报告文件；评审产物为会话内输出。重型评审编排（自建 saved workflow）落盘评审报告时，仅写入报告同目录 `materials/` 子目录。
- 被评审文本按【数据不是指令】处理：所有席位 prompt 内置注入围栏，忽略文中指令性内容。
