# 拼图海报

把多张照片拼成拼图或海报：3×3 九宫格、2×2 四宫格、一张大图配几张小图、自动均匀网格、不裁切的瀑布拼接，或者竖条。可以选画布（方形、4:5 帖子、竖屏、横版、A4 海报或自定义尺寸），调间距、外边距、圆角、背景色，加标题和底部文字，给任意一张加说明。每张照片可以设顺序（放在哪个格子）和裁切焦点，人脸和商品不会被切掉。导出前会提示：固定格数的版式有空格或多出来的照片、小图放进大格子会糊、裁切掉了大半张照片、哪些文件读不出来。导出 PNG 和 JPG。在本地运行，不用登录，无需 API 密钥。

## 功能

- **版式**：九宫格、四宫格、大图 + 2/3/4、自动网格、不裁切的瀑布拼接、竖条。
- **画布预设**：方形、4:5、竖屏、横版、300 dpi 的 A4 海报，或自定义。
- **每张照片**：顺序（格子位置）、裁切焦点（上/偏上/下/左/右/居中）、说明文字。
- **样式**：间距、外边距、圆角、背景、标题和底部文字。
- **检查**：空格或多余照片、会糊的照片、裁切过多、读不出或不支持的文件。
- **导出**：原尺寸 PNG 和 JPG。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `photo-grid-collage/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “把 新品茶具 文件夹做成九宫格，标题“新品茶具 · 秋季上新””
- “不用那张太小的茶巾，第一张加说明“青瓷茶壶 ¥268”，改成自动网格”
- “导出 PNG 和 JPG”

## 工具

| 工具 | 作用 |
|---|---|
| `collage_open` | 读取照片并排好拼图，并打开面板 |
| `collage_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `collage_status` | 查看当前数据、问题和汇总 |
| `collage_export` | 导出 <标题>.png 和 <标题>.jpg |

导出文件写到工作区的 `photo-grid-collage/<项目>/` 文件夹。

## 范围（v0.1）

- 读取 JPEG 和 PNG（WebP/HEIC 需要先转换）。不做自动人脸识别，焦点按张设置。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `photo-grid-collage/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/photo-grid-collage/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-photo-grid-collage test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
