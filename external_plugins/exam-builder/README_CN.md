# 题库与试卷制作

用自己的题库出卷：检查题库，按题型、章节和难度抽题，出互不重复的 A/B 卷，导出可直接打印的 PDF 和单独的答案册。

## 功能

- **题库格式**：
  - Markdown：`# 章节`，每题以 `## 单选 | 易 | 5分 | id: F-01` 开头（题型：单选/多选/判断/填空/解答；难度：易/中/难 或 1–5），接着写题干，选项 `A. …`，然后 `答案：…`、`解析：…`。
  - Excel/CSV：一行一题，列为 ID、题型、章节、难度、分值、题干、A–D、答案、解析、图片（英文表头 Type/Chapter/Difficulty/Question… 也可以）。
  - 公式用 LaTeX 写在 `$…$` / `$$…$$` 中；图片用 `![](img/图.png)`，路径相对题库文件。
- **检查**：缺答案、答案不在选项里、选择题没有选项、图片文件找不到、公式写错、`$` 不成对、题型不明、重复题（编号相同或题干相同）。问题标明文件和行号；组卷时跳过这些题，改好再用。
- **组卷**：
  - 每种题型的题数和每题分值。分值默认用题目自带的分值，其次单选 5、多选 6、判断 2、填空 5、解答 12。
  - 可选章节和“易:中:难”比例。某个难度不够时用相邻难度补，并会提示。
  - 可出 1–10 套（A、B…），各套之间不重复。同一个种子、同一个题库，结果固定。
  - 单题“换一题”：换成同题型、同难度且没用过的题。
- **导出**（到 `exams/<标题>/`）：
  - 试卷 PDF：A4，卷头有标题、卷别、时间和满分，下面是姓名/班级/得分栏；大题标题如「一、单项选择题（本题共 6 小题，每小题 5 分，共 30 分）」。公式是矢量路径（MathJax），图片嵌入；选项按长度每行排 4、2 或 1 个；解答题留作答空白；一道题放得下时不跨页；有页码。
  - 答案册 PDF：答案和解析。
  - 两者的 HTML 版：单文件，公式是内联 SVG，图片已嵌入。
  - `paper.json`：每套卷的题号。
- **面板**：
  - 勾选题库，查看章节 × 题型统计和问题清单。
  - 填组卷规则，按卷别预览试卷或答案。
  - 鼠标移到题目上可换题，最后导出。

## 用法

在 ZCode Desktop 里对 Agent 说：

- “用我的题库出一份期中试卷：8 道单选、3 道填空、2 道解答，难度 5:3:2”
- “出 A、B 两套不重复的卷子，再导出答案册”
- “检查一下题库里有没有缺答案、公式写错的题”

## 工具

| 工具 | 作用 |
|---|---|
| `exam_bank` | 载入并检查题库，按章节、题型、难度统计 |
| `exam_build` | 按规则抽题，出一套或多套卷 |
| `exam_swap` | 替换某套卷中的一道题 |
| `exam_export` | 输出试卷和答案册的 PDF、HTML 以及 paper.json |

## 范围（v0.1）

- 不支持 Word（.docx）题库和 Word 公式对象；不做在线考试和阅卷。
- 题库是中文时默认中文卷头，否则英文；只支持 A4。
- PDF 里的图片需为 PNG 或 JPEG；HTML 版还支持 GIF、SVG、WebP。

## 隐私、网络与文件

- 本地运行：不联网，不需要 API Key；不修改题库文件。
- 写入 `.exam-builder/project.json`（题库、规则、选中的题）和 `exams/<标题>/`；没有 hooks。
- PDF 使用系统自带的中文字体（苹方 / 宋体 / Noto CJK 等），子集嵌入。

## 构建与测试（开发者）

- 源码：`ui-plugins/exam-builder/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-exam-builder test`；`EXAM_SAMPLES` 指向虚构的示例题库；`test:e2e` 需要 Chrome。
