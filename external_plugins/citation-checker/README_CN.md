# 引用来源核对

把报告和它引用的资料放在一起逐条核对：每个数字、每句引文、每个引用标记都去资料里找原文，标出不一致和找不到依据的地方，点一下就跳回资料对应页并高亮原文。

## 功能

- **报告**：Markdown、Word（.docx）、TXT，也支持 PDF、HTML。
- **资料**：PDF（需有文字层）、保存的网页（.html）、Word、Markdown、TXT；默认取报告所在文件夹里的全部支持文件。
- **核对哪些句子**：含数字的（年份、日期、序号只作线索）、含 8 字以上引号原话的（“…”「…」"…"）、带引用标记的（[1]、[1-3]、[^1]、【1】、(Smith, 2020)、（王磊，2019））。
- **找原文**：按中文二字组、英文单词和数值，找最接近的一句或相邻两句；表格类长段只截取相关部分。
- **数字**：按数值比对，认识 万/亿/万亿、thousand/million/billion、%、‰、个百分点，允许报告四舍五入（134.9 万亿 = 1349084 亿）；不一致时给出资料里同一位置的数字（“5.2% → 资料为 5.1%”）。
- **引文**：要求逐字一致（忽略空白、引号写法和脚注标记）；不一致时给出最接近的原文并逐词标出差异。
- **状态**：数字不符、引文不符、找不到依据、需确认（部分吻合或跨语言转述）、有依据；参考文献表写明了资料时，还会提示“依据出自另一份资料”。
- **面板**：按状态分组筛选；每条显示数字核对（绿=一致、红=不符）、资料数字和引文差异，并跳到原文：PDF 渲染整页并高亮那段，网页和文档显示上下文段落。可点“属实 / 部分属实 / 有误 / 无依据 / 待定”并写备注；`j`/`k` 切换上下条。
- **导出**：在报告旁边生成自带样式的 HTML 表格或 CSV（Excel 可开）：原句、位置、自动核对、结论、备注、出处和原文。

## 使用

在 ZCode Desktop 里对助手说：

- “把报告.md 和资料文件夹里的 PDF 对一遍，哪些数字写错了”
- “找出我稿子里没有出处的说法”
- “把核对结果导出成 HTML 表格发给审稿人”

助手会复核标出的条目（读资料原文，也能用中英文在资料里搜索）并记录结论；你可以在面板里随时改。

## 工具

| 工具 | 用途 |
|---|---|
| `cite_check` | 核对报告与资料，打开面板 |
| `cite_review` | 记录每条的结论和备注 |
| `cite_search` | 在资料里搜索段落（关键词、句子、数字） |
| `cite_export` | 导出核对表（HTML / CSV / Markdown） |
| `cite_status` | 查看已保存的结果和结论 |

## 范围（v0.1）

- 只做字面核对：比对数字和措辞；论证是否成立由审阅者（助手或你）判断。
- 扫描版 PDF 需先 OCR；跨页断开的句子按页分别匹配。
- 资料须是本地文件；网页请先另存为 .html（例如用“网页资料归档”插件）。
- 不读取 Word 脚注里的内容，正文里的引用标记照常识别。

## 隐私、网络与文件

- 完全本地运行：不联网，无需 API 密钥或账号。
- 只写 `.citation-check/<报告>.json`（结果与结论）和报告旁边导出的核对表；不修改报告和资料。没有 hooks。

## 构建与测试（开发者）

- 源码：`ui-plugins/citation-checker/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-citation-checker test`。`CITE_SAMPLES` 指向真实样例（国家统计局 2024 年统计公报 PDF、WHO 肥胖事实清单网页、一份故意写错几处的简报）。`test:e2e` 需要 Chrome。
