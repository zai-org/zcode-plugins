# 固定资产台账

用一张表管小公司的固定资产台账，生成二维码资产标签、折旧表和盘点表。按月计提折旧（当月购入次月起提），支持年限平均法、双倍余额递减法（最后两年改直线）和年数总和法，各类别可设默认年限，残值可写比例或金额；随时看到截至某天的累计折旧和净值。会发现重复或缺失的资产编号、重复录入的序列号、读不懂的日期和金额、残值不低于原值、没有使用年限、借出没写使用人或已逾期、没有存放地点，以及已提足折旧仍在使用的资产。导出 A4 二维码标签（50×30 或 70×40 mm）、折旧 Excel（台账、年度折旧、按类别和地点汇总、借出清单）和按地点分组带勾选框的盘点表。不用登录，无需 API 密钥，本机运行。

## 功能

- **折旧**：年限平均、双倍余额递减、年数总和；当月购入次月起提；各类别默认年限。
- **标签**：含资产编号、名称、地点的二维码标签；A4 上 50×30 或 70×40 mm。
- **检查**：编号和序列号重复、日期金额错误、残值不低于原值、缺年限、借出逾期或无人、缺地点。
- **导出**：含年度折旧和汇总的 Excel、二维码标签、盘点表。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `asset-register/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 资产 里的台账打印资产标签”
- “算到月底的累计折旧和净值”
- “导出折旧表、标签和盘点表”

## 工具

| 工具 | 作用 |
|---|---|
| `asset_open` | 读取资产台账并计算折旧，并打开面板 |
| `asset_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `asset_status` | 查看当前数据、问题和汇总 |
| `asset_export` | 导出 asset-tags.pdf、depreciation.xlsx 和 stocktake.pdf |

导出文件写到工作区的 `asset-register/<项目>/` 文件夹。

## 范围（v0.1）

- 用于内部管理，不是税务折旧计算；不含减值和重估。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `asset-register/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/asset-register/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-asset-register test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
