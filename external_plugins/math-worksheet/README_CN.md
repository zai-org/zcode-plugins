# 口算练习生成

几秒钟打印口算练习和答案。选年级题型（20 以内加减、100 以内进位/不进位加减、表内乘除、有余数的除法、三位数加减、两位数乘法等），或者自己设运算和数字范围。设题数、横式或竖式、挖空题（□ + 5 = 12）；换一个题组编号就是一套新题，编号不变就能重印同一套。可以改任何一道题，重新生成时保留。导出带姓名、用时、得分栏的练习卷，红色答案卷和 CSV。在本地运行，无需账号或 API 密钥。

## 功能

- **年级题型**：20 以内；100 以内不进位/进位退位；表内乘除；有余数的除法；三位数加减；两位数乘一位数；两位数乘两位数、除数是两位数。
- **自定义**：选 + − × ÷、数字范围、和的上限、是否进位、是否有余数。
- **可复现**：同一个题组编号总是同一套题；换编号就换新题，同一套内不重复。
- **挖空题**：□ + 15 = 40、50 − □ = 18 混在其中。
- **横式或竖式**，每行 1–5 题，字号可调，带姓名/用时/得分栏。
- **修改并锁定**：改过的题自动锁定，重新生成时保留。
- **自带题目**：每行一题的 .txt（37+48、□-5=12）也可以。
- **答案卷**：同样版式，答案用红色。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `math-worksheet/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “出 60 道二年级进位退位加减法”
- “表内乘除，每行 5 题，带答案”
- “再出一套新的”

## 工具

| 工具 | 作用 |
|---|---|
| `math_open` | 生成口算题，并打开面板 |
| `math_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `math_status` | 查看当前数据、问题和汇总 |
| `math_export` | 导出 worksheet.pdf、answers.pdf 和 problems.csv |

导出文件写到工作区的 `math-worksheet/<项目>/` 文件夹。

## 范围（v0.1）

- 只出整数题；分数和小数以后再做。
- 竖式适用于加减乘，除法保持横式。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `math-worksheet/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/math-worksheet/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-math-worksheet test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
