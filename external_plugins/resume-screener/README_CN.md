# 简历初筛

在自己电脑上，用岗位说明对一文件夹简历做初筛。从岗位说明（Markdown 或文本）读出必须项、加分项、最低年限和学历，再给每份简历打分——支持 Word、有文字层的 PDF、Markdown、文本，中英文均可——列出命中了哪些要求、缺了哪些必须项、按工作经历时间合并算出的年限、学历、邮箱和电话。中英文关键词互认（A/B 测试 = A/B test，餐饮 = restaurant 等）。岗位说明里的年龄、性别、婚育等要求会被提示，且不参与打分。还会发现重复投递（邮箱或电话相同）、读不出文字或扫描版的简历和缺少联系方式。可以给每位候选人记状态和备注，导出按分数排序的 Excel 筛选表和 Markdown 汇总。关键词匹配只用于加快初筛，最终由人来判断。不用登录，无需 API 密钥，简历不离开本机。

## 功能

- **解析岗位说明**：必须项、加分项（“A 或 B” 任一即可）、最低年限、学历；可在设置里修改。
- **读取简历**：.docx、.pdf（文字层）、.md、.txt；中英文，关键词跨语言互认。
- **每位候选人**：分数、命中和缺少的要求、合并后的工作年限、学历、邮箱、电话、状态、备注。
- **公平与规范**：年龄/性别/婚育要求会提示并忽略；重复投递、无法读取、缺联系方式。
- **导出**：标出缺项的 Excel 排名表、Markdown 汇总。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `resume-screener/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用数据分析师岗位说明筛一下 招聘 文件夹里的简历”
- “去掉重复投递，把前两名标成面试”
- “导出筛选表”

## 工具

| 工具 | 作用 |
|---|---|
| `screen_open` | 读取岗位说明和简历，给每位候选人打分，并打开面板 |
| `screen_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `screen_status` | 查看当前数据、问题和汇总 |
| `screen_export` | 导出 shortlist.xlsx（按分数排序）和 shortlist.md |

导出文件写到工作区的 `resume-screener/<项目>/` 文件夹。

## 范围（v0.1）

- 基于关键词和日期匹配，不是 AI 评价：换了说法的技能可能匹配不到。用它来排个序，再认真看简历。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `resume-screener/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/resume-screener/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-resume-screener test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
