帮助用户排查 zcode-token-usage-statusbar 的状态条、工具栏 chip 或回答末尾速率行不显示的问题。本命令只做诊断，不修改客户端、运行目录、配置或插件登记；状态条正常时不需要运行。

执行：用 Bash 运行体检脚本（插件根目录 = 本命令文件所在目录的上一级）：

    python3 "<插件根目录>/overlay_install.py" doctor

Windows 上 `python3` 可能是 Microsoft Store 存根（静默失败），依次改用 `python`、`py -3`；macOS/Linux 用 `python3`。

结果处理：

- 把输出原样转述给用户：`[OK]` 正常，`[WARN]` 需要注意，`[FAIL]` 异常；再按「建议动作」的编号逐条说明。
- 「建议动作」里涉及修改客户端文件、提权、重启 ZCode 或卸载的，先征得用户同意再执行；不要自行重启 ZCode。
- 输出以「体检未能完成」开头时，说明体检脚本自身出错：原样转述，不要猜测原因或声称已修复。
- 不要凭退出码下结论：体检跑完恒为 0，结论只看输出里的状态标签与建议动作。

补充说明（用户问起时再展开，不必每次输出）：

- 体检只读取插件登记、归档入口、运行目录与诊断文件，不读取也不输出任何凭据。唯一的落盘动作是在客户端安装目录做一次「建后即删」的可写性探针，与安装器用的是同一个。
- 状态条未注入时 `/install-overlay` 可手动安装；自动安装始终开启，新建或恢复会话也会自动修复。

用户附加要求：$ARGUMENTS
