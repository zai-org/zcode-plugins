description: 查看当前会话上下文构成，并引导打开 Context / 上下文洞察面板
argument-hint: [insights]
---
根据用户意图整理并回复上下文概览：

1. 调用 MCP 工具 `token_usage`（参数 `scope="current"`）获取当前会话的用量摘要；若该工具不可用，按 `/usage` 同款 CLI 退回方式执行 `python3 "<插件根目录>/zusage.py" now`。
2. 向用户展示当前会话的核心用量（输入/输出/缓存/预估费用），并明确提示可在 ZCode 桌面端直接打开可视化面板：
   - **当前会话明细（Context 标签页）**：悬停右下角「上下文容量」圆环后点击 **「上下文明细」**，或点击右侧边栏 `+` 新标签页 →「扩展」→ **「上下文组成」**。
   - **全部会话总览（上下文洞察）**：点击左侧主导航「插件市场」下方的 **「上下文洞察」**。
