---
description: 自动安装失败时手动安装/更新本机 ZCode 悬浮用量状态条（修改 app.asar，完全退出并重开生效）
---
帮助用户在自动安装/修复失败时，手动把 zcode-token-usage-statusbar 的悬浮状态条安装到本机 ZCode 桌面客户端；此命令是兜底，不是必经步骤。

执行：用 Bash 运行安装器（插件根目录 = 本命令文件所在目录的上一级）：

    python3 "<插件根目录>/overlay_install.py" install

Windows 上 `python3` 可能是 Microsoft Store 存根（静默失败），依次改用 `python`、`py -3`；macOS/Linux 用 `python3`。安装器（patch_install/monitor）打印的手动命令已带真实解释器绝对路径，照抄最稳。

结果处理（按以下优先级，不能仅凭退出码为 0 判断需要重启）：

- 失败、待收尾或输出安装/更新尚未完成、记录无法确认的提醒：优先转述实际输出，不得宣称安装成功或仅重启即可修复。
- 输出插件重启提醒：优先于「已安装，注入行已指向当前目录」。在最终回复正文的第一行，用引用块原样加粗安装器的实际提醒（不要使用 HTML 颜色标签；状态条加载后会将这条提示正文显示为红色）。通常为：

  > **🔴 zcode-token-usage-statusbar 插件提醒：用量状态条已安装或更新。请完全退出 ZCode（所有窗口）：从 ZCode 菜单选择「退出」，然后重新打开 ZCode，让窗口底部的用量状态条加载新版本。只关窗口、刷新页面或重开会话无效。**

  安装器可能弹出监控窗口，确认生效后会自动关闭，属正常现象。
- 仅输出「已安装，注入行已指向当前目录」，且没有待加载/待修复提醒：只表示无需重新注入；此时才可回复无需操作。若安装器已确认加载且无提醒，也不要额外要求重启。
- 失败：把安装器输出原样转述。权限不足时按平台处理：Windows（Program Files 等受保护位置，报 Errno 13/拒绝访问）以管理员身份打开终端（右键终端图标 →「以管理员身份运行」）重跑同一条命令；macOS/Linux（/opt 等系统位置）按提示建议 `sudo env HOME="$HOME" PATH="$PATH" python3 "<插件根目录>/overlay_install.py" install`（sudo 默认重置 HOME/PATH，会让运行目录定位失败，必须保留）。
- 若输出「运行中替换失败 / 待收尾」：Windows 上这是预期现象（运行中的 ZCode 锁定 app.asar），不是安装故障；说明完全退出 ZCode（从托盘退出）后监控会自动收尾（可能是监控窗口，也可能是无窗口的后台监控），无需重跑；监控未生效时再重跑同一条命令。

补充说明（用户问起时再展开，不必每次输出）：

- 卸载：`/uninstall-overlay`（留下卸载豁免，阻止自动重注入与提示）。
- 自动安装/修复始终开启（旧配置 `plugin_auto_install_overlay` 与环境变量 `ZUSAGE_PLUGIN_AUTO_INSTALL` 已不再读取），只有卸载豁免能阻止。自动安装会修改 `app.asar`，成功后仍需完全退出并重开；失败时才使用本命令兜底，仅重启无法修复尚未成功安装的状态条。
- 待重启由状态条 ⚙ 齿轮红点提醒（点进 ⚙ 面板「插件更新」分区后消失，该分区有「重启 ZCode」按钮与「已更新成功，点击重启 ZCode 即可生效」提示条）；更新成功且无需重启（浮层已自动热重载）、或仅有新版尚未安装时不亮红点。会话内不再注入文字提醒（自动安装失败的故障提示除外），本命令的命令行提醒输出保留。
- 该安装只影响桌面客户端；SSH 远程会话与本插件无关。
