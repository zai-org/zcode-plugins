# 表格数据清洗

一次清洗乱糟糟的 CSV 或 Excel 导出：多余和连续空格、全角数字字母、¥1,280.00 这样的金额文本、五花八门的日期格式、大写邮箱、带横线括号的电话、空行空列和重复行。自动识别列类型，每处修改都有记录，清洗不了的值会标出来。中文 Excel 导出的 GBK 编码 CSV 也能正确打开。在本地运行，无需 API 密钥。

## 功能

- **文本**：去首尾空格、合并连续空格、全角数字/字母/@ 转半角（中文标点不动）。
- **按列类型**：数字（¥1,280.00、(500)、２５６０ → 数字）、日期（2026/11/3、2026年11月5日、11/20/2026、2026.11.21 → 2026-11-03）、邮箱（转小写并检查格式）、电话（只留数字，保留 +）。
- **行和列**：删除空行、空列；按整行或关键列（如 客户名称）删除重复行。
- **你说了算**：每列自动识别类型，也可以手动指定（金额=text）；每条规则都能关掉；表格里任何单元格都能改。
- **可追溯**：cleaned.xlsx 把改过的单元格标黄并在批注里写原值，删除的行放在“removed”工作表；changes.csv 列出每一处修改。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `csv-cleaner/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “把 客户名单-导出.csv 清洗一下”
- “客户名称相同就算重复”
- “导出清洗后的 Excel 和修改记录”

## 工具

| 工具 | 作用 |
|---|---|
| `clean_open` | 读取表格、识别列类型并预览所有清洗结果，并打开面板 |
| `clean_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `clean_status` | 查看当前数据、问题和汇总 |
| `clean_export` | 导出 cleaned.xlsx（修改处标黄，删除的行在第二个工作表）、cleaned.csv 和 changes.csv |

导出文件写到工作区的 `csv-cleaner/<项目>/` 文件夹。

## 范围（v0.1）

- 一次一张表（.xlsx 取第一个有数据的工作表），最多 50,000 行。
- v0.1 不做模糊去重（例如“青禾茶业”和“青禾茶业有限公司”）。
- 公式按计算结果读取；.xls 请先另存为 .xlsx。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `csv-cleaner/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/csv-cleaner/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-csv-cleaner test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
