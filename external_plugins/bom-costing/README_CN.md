# 物料清单核算

把多层物料清单自动汇总成单位成本，并把生产计划变成采购清单。读取 Excel 或 CSV 里的物料表（编码、自制/外购、单价或加工费、库存、起订量、包装倍数、交期、供应商）和 BOM 表（父件、子件、用量、损耗率）。自下而上算出每个成品和半成品的成本（含损耗），按层级展开生产计划、先用现有的半成品和零件库存，采购数量按最小起订量和包装倍数向上取整。会发现物料表里没有的子件（如 P-OO5 会提示应为 P-005）、BOM 循环、缺单价、用量和损耗率错误、重复的 BOM 行、标为自制却没有 BOM 的物料、没用到的物料和交期长的物料。导出成本核算 Excel（每个产品的缩进 BOM、累计用量和成本、成本汇总、需求计算、按供应商的采购清单）、采购清单 CSV 和可打印的成本单。不用登录，无需 API 密钥，本机运行。

## 功能

- **成本**：逐层自下而上汇总，含损耗和各组件加工费。
- **需求**：按层级展开生产计划，扣减零件和半成品库存。
- **采购**：按起订量和包装倍数取整，按供应商分组，提示交期长的物料。
- **检查**：缺失子件（提示笔误）、循环、缺单价、重复行、没用到的物料。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `bom-costing/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “核算 台灯BOM 里的物料成本”
- “按生产 300 台 LAMP-01、150 台 LAMP-02 算采购量”
- “导出成本核算表和采购清单”

## 工具

| 工具 | 作用 |
|---|---|
| `bom_open` | 读取物料和 BOM 并汇总成本，并打开面板 |
| `bom_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `bom_status` | 查看当前数据、问题和汇总 |
| `bom_export` | 导出 costed-bom.xlsx、purchase-list.csv 和 cost-sheets.pdf |

导出文件写到工作区的 `bom-costing/<项目>/` 文件夹。

## 范围（v0.1）

- 不按日期排程，不考虑在途采购单；库存只算现有库存。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `bom-costing/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/bom-costing/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-bom-costing test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
