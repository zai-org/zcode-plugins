# 播客制作台

用主持人和嘉宾的录音制作一期播客：对齐音轨、剪辑、降噪、统一响度、加片头片尾、导出，同时保存可以再次打开修改的工程。

## 功能

- **多轨**：最多 8 轨，每支话筒一轨（只有一段录音也可以）。每轨可以设置名字、偏移、音量和静音。
- **自动对齐**：
  - 对前 5 分钟做 GCC-PHAT 互相关，利用串音（你的话筒里隐约录到的对方声音）或开头的拍手来对齐。
  - 会报告每轨的可信度。没把握时不改偏移，你可以在面板里对着波形用 ±10 ms / ±100 ms 微调。
- **所有音轨同步剪辑**：
  - 可以在波形上拖动选择、输入时间，或者让 Agent 按你说的区间剪。剪辑点有 15 ms 淡入淡出，不会有爆音。
  - 会列出混音里 ≥2.5 秒的停顿，点一下就缩短到 1 秒。
- **处理流程**：
  - 每轨先做高通和 FFT 降噪（关 / 轻度 / 较强），然后混音。
  - 片头片尾先单独调整响度。
  - 最后两遍 EBU R128 响度统一到 -16 LUFS（可选 -14 / -19 / -23），真峰值上限 -1.5 dBTP。
- **输出**（默认 `podcast/`）：
  - `节目名.mp3`（128 kbps 立体声，带 ID3 标题）和/或 `节目名.wav`（16 位 44.1 kHz）。
  - `节目名.cuts.md`：各轨偏移，以及每处剪辑和它在成片中的位置。
  - `节目名.podcast.json`：工程文件，可以重新打开、修改、再导出。
- **面板**：
  - 带刻度的波形轨道，可缩放、滚动，拖动即剪。
  - 从播放头试听 15 秒混音；剪辑表里可以试听每处剪辑点前后。
  - 参数设置，以及导出结果和实测响度。

## 使用

在 ZCode Desktop 中对 Agent 说：

- “把 主持人.wav 和 嘉宾.m4a 对齐，剪掉 12:30 到 14:05，加上片头片尾，导出 -16 LUFS 的 MP3”
- “超过 3 秒的停顿都缩短一点，嘉宾声音调小 2 dB”
- “重新打开第 12 期，再导出一份 WAV”

## 工具

| 工具 | 作用 |
|---|---|
| `podcast_open` | 打开录音（或工程），自动对齐，列出较长停顿，打开面板 |
| `podcast_save` | 校验并保存音轨、剪辑和参数 |
| `podcast_render` | 混音、剪辑、响度统一，导出 MP3/WAV 和剪辑清单 |

## 需要 ffmpeg

使用电脑上已安装的 ffmpeg，插件不附带。安装方法：macOS 用 `brew install ffmpeg`，Windows 用 `winget install ffmpeg`。如果不在 PATH 中，可在插件设置里填写路径。

## 范围（v0.1）

- 输入：WAV、AIFF、FLAC、MP3、M4A/AAC、OGG/Opus，或 MP4/MOV/WebM/MKV 里的音频。
- 各轨先混成单声道人声，再以立体声输出。片头片尾分别接在正片前后，不叠放。
- 自动对齐需要前 5 分钟里有共同的声音（串音或拍手）。只校正固定偏移，不处理超长录音的时钟漂移。
- 暂不包含：去口癖、AI 降噪模型、人声出现时自动压低音乐、章节标记。

## 隐私、网络与文件

- **全部在本地运行**：不联网、不上传，不需要 API 密钥或账号。
- 只读取你选的录音，只写入工作区里的输出文件夹。
- ffmpeg 以参数数组调用，不经过 shell。没有 hooks。

## 构建与测试（开发者）

- 源码位于 `ui-plugins/podcast-studio/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试（需要 ffmpeg）：`pnpm --filter @penova/plugin-podcast-studio test` 和 `test:e2e`。
- `E2E_PODCAST` 可以指向一个含 `host.wav`、`guest.wav`、`jingle.mp3` 的文件夹。
  - 主持人轨：我们用的是真实访谈录音（Wikimedia Commons，CC BY 3.0）。
  - 第二支话筒是模拟的：在真实讲课人声（MITx，CC BY 2.0）下面叠了延迟 1.84 秒的串音。
