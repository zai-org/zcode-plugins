# 评分量规

1. `rubric_open(inputs, settings?, project?)`：读取量规和学生名单并计分。inputs 是工作区相对路径。
   - 结果里有汇总、问题列表（错误 / 提醒）和前几行数据，每行有编号 `#n`。
   - inputs 传包含量规 .md 和名单 .csv/.xlsx 的文件夹；每行一位学生：id、name、c0…cN（各维度等级）、_score、comment、_feedback。
2. 向用户简要说明结果，先说错误和需要确认的地方，不要逐行念。
3. 用户要改时调用 `rubric_edit(project, settings?, set?: [{row, values}], add?, remove?)`。
   - 打分：`set: [{row, values: {c0: "优秀", c3: "良好"}}]`；去掉重复：`values: {include: false}`；加学生：`add: [{id: "809", name: "…"}]`。
4. `rubric_export(project, formats?)`：导出 rubric.pdf、scores.xlsx 和 feedback.pdf。把文件路径告诉用户。
5. 无效的等级（如 5）先问用户想打哪一级，不要猜。
