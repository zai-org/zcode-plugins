# 评分量规

写一次评分量规——维度、等级、分值和每一格的描述——然后给全班每人每个维度选一个等级即可打分。量规是一个简短的 Markdown（权重写成“论点 ×2”或“论据（8 分）”，等级写成 优秀 4 | 良好 3 | 合格 2 | 待改进 1，满分 20 之类）；学生名单是 CSV 或 Excel，可以已经填好等级（写等级名、首字、A–D 或分数都行）。每位学生得到按满分换算的分数和自动反馈：优点取自达到最高等级的描述，“下一步”给出两条，引用高一级的描述。会发现不存在的等级（4 级量规里写了 5）、只评了一半或没评的学生、重复的学生、缺少描述的格子、权重加起来不等于满分，以及所有人都同一等级的维度。导出可打印发给学生的量规表、带名次和等级分布的成绩表，以及每页三张、可裁开发回的反馈单。不用登录，无需 API 密钥，本机运行。

## 功能

- **Markdown 量规**：维度、权重、等级、分值、描述。
- **快速打分**：每个维度选一个等级；等级名、首字、A–D、分数都可以。
- **反馈**：优点和下一步直接引用量规描述。
- **检查**：无效等级、漏评、重复、缺描述、权重与满分不符、区分度低的维度。
- **导出**：可打印量规表、带名次和分布的成绩表、反馈单。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `rubric-maker/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 作文评分 里的量规给全班打分”
- “把不存在的等级改掉，去掉重复的学生”
- “导出量规表、成绩表和反馈单”

## 工具

| 工具 | 作用 |
|---|---|
| `rubric_open` | 读取量规和学生名单并计分，并打开面板 |
| `rubric_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `rubric_status` | 查看当前数据、问题和汇总 |
| `rubric_export` | 导出 rubric.pdf、scores.xlsx 和 feedback.pdf |

导出文件写到工作区的 `rubric-maker/<项目>/` 文件夹。

## 范围（v0.1）

- 反馈由量规描述拼成；重要的地方请加上老师自己的评语。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `rubric-maker/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/rubric-maker/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-rubric-maker test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
