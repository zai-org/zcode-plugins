# 抽奖分组工具

做谁都能核对的抽奖和随机分组。选上参与者名单，设好奖项（如 一等奖×1, 二等奖×3, 三等奖×5）和随机种子，就用基于 SHA-256 的随机数抽出中奖者——同样的名单和种子永远得到同样的结果，过程记录写下每一步，事后可以验证。可以按抽奖券数加权、排除某些人、锁定某个中奖者后重抽其余名额。也可以把所有人随机分组，并让每个部门平均分到各组。在本地运行，不用抽奖服务，无需 API 密钥。

## 功能

- **可复现**：基于 SHA-256 的随机数，种子可以提前公布；同样的名单 + 种子 = 同样的结果。
- **过程记录**：audit.json 写明算法、名单指纹和每一步（候选人数、随机数、中奖者）。
- **奖项和权重**：如 二等奖×3，可先抽小奖或按列出顺序；按抽奖券加权或人人相同；每人限中一次或可重复中奖。
- **锁定与重抽**：在某人那一行填上奖项即锁定，改种子就重抽其余名额。
- **均衡分组**：指定组数或每组人数，让部门等某一列在各组平均分布。
- **直接用名单**：识别 姓名、部门、抽奖券、不参与、工号 以及英文列名；重名会自动区分。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `raffle-draw/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 participants.csv 抽 一等奖×1、二等奖×3、三等奖×5，种子用 2026-annual”
- “锁定一等奖，其他重抽”
- “把所有人分成 4 组，各部门平均分配”

## 工具

| 工具 | 作用 |
|---|---|
| `raffle_open` | 读取参与者名单并抽奖，并打开面板 |
| `raffle_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `raffle_status` | 查看当前数据、问题和汇总 |
| `raffle_export` | 导出 result.xlsx 和 audit.json |

导出文件写到工作区的 `raffle-draw/<项目>/` 文件夹。

## 范围（v0.1）

- 这是抽签工具，不是彩票服务，不涉及收款或奖品发放。
- v0.1 没有大屏滚动动画，结果显示在面板里并可导出。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `raffle-draw/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/raffle-draw/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-raffle-draw test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
