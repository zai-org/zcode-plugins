---
description: 把任务拆解并派发给多个子智能体并行执行,汇总结果
argument-hint: "<要执行的任务描述>"
---

任务:$ARGUMENTS

1. 以当前会话系统提示的可用 agent types 清单为准盘点人选。
2. 把任务拆成相互独立的子任务(强耦合不硬拆),按各智能体 description 分派;没有合适人选用 general-purpose。只读智能体不派写任务。
3. 独立子任务在同一条消息里用多个 Agent 调用并行派发;有依赖的串行。派发消息写清范围、上下文、期望产出与只读约束。
4. 子智能体的最终报告用户看不到,必须转述;合并去重成一份最终报告,标注分歧与未决项。未完成的不得编造结果。

> 完整流程与红线以 `agent-team` 技能为准,本命令是其快捷入口。
