# 重复文件查找

找出文件夹里内容完全相同的文件——按大小和 SHA-256 内容哈希比对，不看文件名——并算出浪费了多少空间。每组自动保留一份（像原件的那个，不带“副本”“(1)”），你可以改选保留哪个，然后导出报告，或把多余副本移到待删文件夹。绝不直接删除文件，移走的文件还能放回原处。在本地运行，无需 API 密钥。

## 功能

- **只认完全相同**：先按大小、再按内容的 SHA-256 分组，“同名不同内容”不会误判，改过名的副本也能找出来。
- **保留哪一份**：智能（文件名不带“copy / 副本 / (1)”、路径最短）、最早、最新，或优先保留指定文件夹里的；每组都可以用“保留”勾选框改。
- **能省多少空间**：按浪费空间从大到小排列，摘要显示可以释放多少。
- **安全清理**：多余副本按原路径移到 duplicate-file-finder/<项目>/review/，绝不删除；“把移走的副本放回原处”可以还原。没有保留任何文件的组会被拦住。
- **筛选**：可忽略太小的文件和 .DS_Store 之类的扩展名；空文件不计。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `duplicate-file-finder/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “找出 下载/ 和 旧电脑备份/ 里的重复文件”
- “保留 合同/ 文件夹里的那份，其余移到待删文件夹”
- “撤销，把移走的副本放回原处”

## 工具

| 工具 | 作用 |
|---|---|
| `dupes_open` | 扫描工作区文件夹，把内容完全相同的文件分组，并打开面板 |
| `dupes_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `dupes_status` | 查看当前数据、问题和汇总 |
| `dupes_export` | 导出 duplicates.csv 和 duplicates.html，或把多余副本移到待删文件夹（附 moved.csv）；restore 可放回原处 |

导出文件写到工作区的 `duplicate-file-finder/<项目>/` 文件夹。

## 范围（v0.1）

- 只找完全相同的文件；v0.1 不识别相似图片（缩放过或重新压缩过的）。
- 范围限于工作区，每次最多 5 个文件夹、20,000 个文件。
- 插件不会删除文件；确认无误后请自己清空待删文件夹。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `duplicate-file-finder/` 文件夹；另外只有在你点“把多余副本移到待删文件夹”时才会移动文件（点“放回原处”可还原）。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/duplicate-file-finder/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-duplicate-file-finder test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
