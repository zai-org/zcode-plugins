# 网站离线打包

把构建好的**静态网站**（文档站、帮助中心、产品官网）做成离线版：双击 `index.html` 就能浏览，不需要服务器，也不需要联网。

## 功能

- **爬取**：从 `index.html` 出发，跟随所有站内链接，包括 `<a>`、`<link>`、`<script>`、`<img>`、`srcset`、`<source>`、`<video poster>`、`<iframe>`、行内样式、`<style>` 块，以及 CSS 里的 `url()` 和 `@import`。
- **修正链接，让 file:// 能打开**：
  - 根路径（`/css/site.css`）、目录式（`/guide/`）和省略扩展名（`/guide/install`）的地址都改成相对文件路径，分别变成 `../css/site.css`、`guide/index.html`、`guide/install.html`；页内锚点保留。
  - 填写“网站线上地址”后，指向线上站点的绝对链接（`https://docs.example.com/…`）也会改成本地路径。
- **收集文件**：只复制真正用到的页面和文件。没被链接的页面和文件会列出来，也可以选择一起打包。
- **离线搜索**：每个页面右上角都有搜索框（点击按钮或按 ⌘K / Ctrl+K）。搜索用 **MiniSearch**，索引存成 JS 文件，所以通过 `file://` 也能用。
- **报告**：
  - 坏链和缺失的文件，并注明出现在哪个页面。
  - 外部链接（离线时打不开）。
  - 没被链接的页面和没用到的文件。
  - 使用 `fetch()` 的脚本（浏览器在 `file://` 下会拦截这类请求）。
- **输出**：`<网站>-offline/` 文件夹和 `<网站>-offline.zip`。不会改动原网站。

## 用法

在 ZCode Desktop 里对 Agent 说：

- “把 dist 里的文档站做成离线版”
- “检查这个网站有没有坏链”
- “把帮助网站打包成不联网也能看的 zip”

也可以在面板里操作：选择目录，按需填写线上地址，然后点“只检查”或“生成离线包”。

## 工具

| 工具 | 作用 |
|---|---|
| `site_check` | 爬取并报告，不写入任何文件 |
| `site_pack` | 生成离线目录（和 zip），改写链接并加上搜索 |

## 范围（v0.1）

- 只支持已经构建好的静态网站。请先用你的生成器构建（Hugo、Docusaurus、VitePress、Jekyll 等）。需要服务器的网站（PHP、接口、没有静态导出的 SPA 路由）不在范围内。
- JavaScript 原样复制。脚本用 `fetch()` 读取本地数据的功能在 `file://` 下用不了，报告里会提醒。
- 外部资源（CDN 上的字体和脚本、嵌入的视频）不会下载，会作为外部链接列出。
- 输出目录必须在网站目录之外。已存在的输出目录只有在是本插件生成的情况下才会被覆盖。

## 隐私、网络和文件

- 本地运行，不联网，不需要 API 密钥。
- 读取网站目录；写入输出目录、zip 和 `.offline-site-packer/last.json`（上次的报告）。
