# 成绩统计分析

1. `grades_open(inputs, settings?, project?)`：读取成绩表，计算总分、等级和排名。inputs 是工作区相对路径。
   - 结果里有汇总、问题列表（错误 / 提醒）和前几行数据，每行有编号 `#n`。
   - 表头需要姓名或学号；其余数字列当作科目（总分、排名等列会被忽略并重新计算）。
2. 向用户简要说明结果，先说错误和需要确认的地方，不要逐行念。
3. 用户要改时调用 `grades_edit(project, settings?, set?: [{row, values}], add?, remove?)`。
   - 改分：`set: [{row, values: {数学: 135}}]`（科目名就是列名；缺考写“缺考”）；评语：`values: {comment: "…"}`。满分、权重、等级、排名方式在 settings。
4. `grades_export(project, formats?)`：导出 grades.xlsx、report-cards.pdf 和 summary.pdf。把文件路径告诉用户。
5. 有报错（超满分、非数字）时导出 Excel 和成绩单会被拦下，先修正。
