# 成绩统计分析

把成绩表变成总分、平均分、排名和成绩单。放入一张每行一名学生、每列一个科目的表：每科满分自动判断（100、150 等）也可手动设置，可以设科目权重；每个学生算出总分、加权平均、等级（优秀／良好／及格……）、年级和班级排名。同时给出各班各科的平均分、最高分、最低分、及格率、优秀率和分数段分布图。可以改分、给每个学生写评语，然后导出 Excel 成绩册、每人一页 A5 成绩单和统计报告 PDF。在本地运行，不用登录教务系统，无需 API 密钥。

## 功能

- **总分、加权平均与排名**：年级和班级排名，同分同名次（1、2、2、4）；可按总分或加权平均排名。
- **每科满分与权重**：根据成绩自动判断，或写“语文=150; 物理=100”“数学=1.5”。
- **等级**按满分百分比：“优秀 85; 良好 75; 及格 60; 不及格 0”，单科和平均都适用。
- **班级统计**：各科各班平均、最高、最低、中位数、标准差、及格率、优秀率、缺考人数。
- **分数段分布图**：面板和统计报告 PDF 里每科一张。
- **成绩单**：每人一页 A5，含各科成绩、班均、等级、排名、成绩与班均对比图、评语和家长签字栏。
- **检查**：超过满分、不是分数的内容、学生重复；“缺考”不计入平均。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `grade-book/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “分析 scores.xlsx 并排名”
- “数学权重 1.5，按平均分排名”
- “给每个学生生成成绩单”

## 工具

| 工具 | 作用 |
|---|---|
| `grades_open` | 读取成绩表，计算总分、等级和排名，并打开面板 |
| `grades_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `grades_status` | 查看当前数据、问题和汇总 |
| `grades_export` | 导出 grades.xlsx、report-cards.pdf 和 summary.pdf |

导出文件写到工作区的 `grade-book/<项目>/` 文件夹。

## 范围（v0.1）

- 每行一名学生；一张表一次考试或一个学期。
- 只做等级和排名，不含特定学校的绩点换算表。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `grade-book/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/grade-book/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-grade-book test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
