# Muse Illustration

[中文](./README_CN.md)

Turn **poems, verses, imagery — or a single line of inspiration** — into illustrations or posters.

The idea behind this plugin: the reusable asset is not any single image, but a **style recipe** — *positive prompt + negative constraints + reference image + parameters*. Images are just samples a recipe produces; the recipe itself is what you reuse, and what keeps growing as new results get adopted into the library.

---

## What's inside

| Component | Name | Description |
|---|---|---|
| **Skill** | `muse-illustration` | The whole workflow: parse imagery → pick a style → confirm output parameters → assemble the prompt → generate → deliver & archive |

No commands, no subagents, no hooks, no MCP servers.

## Built-in styles

| id | Name | Core idea |
|---|---|---|
| `jiangnan-muke` | Watermark woodcut | Warm off-white paper, flat colour blocks, short carved strokes — the flat language of colour-keyed relief printing |
| `riso-print` | Risograph print | A 3–4 colour limited palette, grain, ink unevenness and misregistration — handmade screenprint feel |
| `chunkcolor` | Color-field ink | A calm single-colour mass in the lower two-thirds, fine ink linework along the top edge, generous white space — modern exhibition-poster ink painting |

All three were validated on Du Mu's *Jiangnan Chun*; `jiangnan-muke` also transferred across subject matter to Bai Juyi's *Yi Jiangnan* and was still adopted — evidence that the recipes are portable across subjects.

## When it triggers

When the user supplies a poem / verse / imagery phrase / one-line inspiration and asks to "draw it", "generate an illustration", "make a poster", or "add artwork", or names one of the bundled styles.

## Dependencies and side effects (disclosed)

**Network access**

- The plugin makes **no network requests at runtime** and contains no external API calls.
- Note: the "Examples" section of `skills/muse-illustration/SKILL.md` references absolute image URLs on `raw.githubusercontent.com`. Those images are fetched **only by Markdown-rendering clients that display them**; the plugin itself never reads them. Remove that section if you need a fully offline package.

**Model / API / service dependencies**

- Requires the host's **text-to-image capability**. This plugin bundles no model, holds no API key, and asks for no credentials.
- Without a text-to-image tool available, the skill can only reach the "assemble the prompt" step — it cannot produce an image.

**File writes**

- Generated images go to the host's default output directory (user-overridable).
- When the user **adopts** an image, the skill copies it into `assets/cases/images/` and appends a case note under `assets/cases/` — this is the mechanism that makes the skill improve with use.

**Command execution / hooks / MCP servers**

- **None of the above.** The plugin ships no executable scripts, no hooks and no MCP server configuration.

**Other side effects**

- Consumes quota/credits of the host's text-to-image capability (roughly 5–10 credits per image); the skill states this to the user before generating.
