# Muse Illustration（灵感插图）

[English](./README.md)

把**诗词、词句、意象，甚至一句灵感**，变成插画或海报。

这个插件带来的核心观念是：可复用的资产不是某张图，而是一份**风格配方** ——「正向提示词 + 负向约束 + 参考图 + 参数」。配方跑出来的图只是效果样张；配方本身才是能反复复用、并随采纳案例不断长大的东西。

---

## 包含的组件

| 组件 | 名称 | 说明 |
|---|---|---|
| **Skill** | `muse-illustration` | 主能力：解析意象 → 选风格 → 确认出图参数 → 组装提示词 → 生图 → 交付与归档 |

无 Command、无 Agent、无 Hook、无 MCP Server。

## 内置风格

| id | 名称 | 内核 |
|---|---|---|
| `jiangnan-muke` | 江南春 · 水印木刻 | 米白纸底、平涂色块、短刻痕，套色 / 水印木刻的平面语言 |
| `riso-print` | 江南春 · risograph 版画 | 3–4 色有限调色板、颗粒噪点、套色错位的手工印刷感 |
| `chunkcolor` | 色块彩墨 | 下三分之二沉静单色面 + 上沿细墨线白描 + 大留白，展览海报式的现代彩墨 |

三条风格都已在杜牧《江南春》上验证过，其中 `jiangnan-muke` 跨题材到白居易《忆江南》同样被采纳 —— 证明配方具备跨题材可移植性。

## 何时会被调用

用户给出诗词 / 词句 / 意象词 / 单句灵感，并要求「画成画 / 出图 / 生成插画 / 做海报 / 配图」，或指定用某个已收录风格出图时。

## 依赖与副作用（如实声明）

**网络访问**

- 插件**运行时不发起任何网络请求**，不含任何外部 API 调用。
- 提醒：`skills/muse-illustration/SKILL.md` 的「效果示例」区块引用了 `raw.githubusercontent.com` 上的绝对图片地址。这些图片**只在支持渲染 Markdown 的客户端显示时才被拉取**，插件自身不会读取它们。需要彻底离线时，删掉该区块即可。

**模型 / API / 服务依赖**

- 需要宿主的**文生图（text-to-image）能力**。本插件不捆绑模型、不内置 API Key、不索要任何凭据。
- 若宿主没有文生图工具，技能只能走到「组装提示词」这一步，无法出图。

**文件写入**

- 生图产物写入宿主默认输出目录（用户可指定）。
- 用户**采纳**某张图后，技能会把该图复制一份到 `assets/cases/images/`，并按模板在 `assets/cases/` 追加一条案例记录 —— 这是本技能「越用越准」的机制。

**命令执行 / Hook / MCP Server**

- **均为无**。本插件不含任何可执行脚本、Hook 或 MCP Server 配置。

**其他副作用**

- 会消耗宿主文生图能力的额度 / 积分（每张约 5–10 积分）；技能在调用前会明确告知用户。

| 项 | 说明 |
|---|---|
| 插件许可证 | **MIT** |
| 随包的图片 | 全部为**本项目自己生成的 AI 图片**，不含第三方版权素材 |
| `assets/styles/*/ref.jpg` | 风格锚定图（作为 `image1` 传入以提升贴合度）。内容是本项目自产并被采纳的成图，即该风格的标杆样例 |
| `chunkcolor` 的原始参考图 | 是一张**第三方展览海报**，版权不属于本项目，**未随包发布**；案例记录中仅保留文件名以说明配方来源 |
| 第三方代码 / 二进制 | 无。不含预编译二进制、不含捆绑字体或素材包 |
