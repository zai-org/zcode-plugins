# 工时统计

把工时记录整理成给客户的结算单：打开计时工具导出的 CSV / Excel 或自己记的表格，按客户、项目和成员汇总工时，套用小时费率和取整规则，内部工作不计费，并提示重复记录、时间段重叠和没有费率的条目。导出 Excel 汇总和每个客户一份结算单 PDF，可以和发票一起发。在本地运行，不上传，无需 API 密钥。

## 功能

- **各种工时表**：CSV、TSV 或 Excel，中英文表头都能识别——日期、客户、项目、任务、成员、工时或开始/结束时间、是否计费、费率。
- **工时写法不限**：1.5、1:30、1h30m、90m、1小时30分，或开始和结束时间（可跨午夜）。
- **费率**：默认费率，加上“客户 = 300”“客户/项目 = 360”“@成员 = 200”这样的规则，越具体越优先；单条记录也可以单独设费率。
- **取整**：每条记录向上取整到 6、15、30 或 60 分钟，或四舍五入到 15 分钟。
- **不计费工作**：根据“计费”列或“内部 / internal”等关键词；结算单上列出但不收费。
- **检查**：重复记录、同一人时间段重叠、单条超过 12 小时、缺日期或工时、计费工作没有费率、不在结算期间的记录。
- **导出**：Excel（明细、按客户项目、按成员汇总）；每个客户一份结算单 PDF，含项目小计、税和合计；汇总 CSV。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `timesheet-report/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “按客户汇总 11 月的工时”
- “按这些费率给每个客户出结算单”
- “哪些记录重复或时间重叠了？”

## 工具

| 工具 | 作用 |
|---|---|
| `timesheet_open` | 读取工时记录并按客户和项目汇总，并打开面板 |
| `timesheet_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `timesheet_status` | 查看当前数据、问题和汇总 |
| `timesheet_export` | 导出 timesheet.xlsx、每个客户的结算单 PDF 和 summary.csv |

导出文件写到工作区的 `timesheet-report/<项目>/` 文件夹。

## 范围（v0.1）

- 生成的是结算单，不是正式发票——可附在你自己的发票后面。
- 每个项目只用一种货币。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `timesheet-report/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/timesheet-report/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-timesheet-report test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
