# 照片按日期整理

把乱七八糟的手机照片、截图和视频，按拍摄日期整理进“年/月”文件夹——日期取自 EXIF、视频创建时间或文件名里的日期，最后才用文件修改时间——还可以统一改名成 20261002_091500.jpg。每个文件都标明日期来源，日期可以手动改正，移动后还能撤销。在本地运行，无需 API 密钥。

## 功能

- **优先用真实日期**：JPEG/HEIC/TIFF/DNG 的 EXIF 拍摄时间、MP4/MOV 的创建时间，其次是文件名里的日期（IMG_20261103_101522、Screenshot 2026-11-05 at 10.22.31、微信图片_20261106、mmexport 时间戳），最后才用文件修改时间——并会提醒，因为拷贝会改变它。
- **文件夹结构**：2026/2026-10、2026-10、2026/10、2026/2026-10-02、2026-10-02 或不分文件夹；保留原名、改成日期，或“日期 + 原名”。
- **表格里改正**：日期可以写成 2024-02-02 12:00 或 2024年2月2日 等格式，来源会变成“手动”。会显示相机品牌和型号。
- **安全**：重名自动加 -2、-3，不会覆盖任何文件。移动模式可以撤销；复制模式写到插件输出文件夹，原文件不动。
- **先看清单**：organize-plan.csv 列出每个文件的日期、来源和去向。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `photo-date-organizer/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “把 手机相册/ 按拍摄日期整理成 年/月 文件夹”
- “顺便把文件名改成日期，像 20261002_091500.jpg”
- “撤销刚才的整理”

## 工具

| 工具 | 作用 |
|---|---|
| `photos_open` | 读取文件夹里每张照片和每个视频的日期，规划日期文件夹，并打开面板 |
| `photos_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `photos_status` | 查看当前数据、问题和汇总 |
| `photos_export` | 导出 organize-plan.csv，再把文件移动或复制到日期文件夹（organize-log.csv）；undo 可移回原处 |

导出文件写到工作区的 `photo-date-organizer/<项目>/` 文件夹。

## 范围（v0.1）

- 日期按相机记录的本地时间，不做时区换算（视频按电脑所在时区）。
- 不按人脸、地点或内容分组；v0.1 会读取 GPS 但不用于分文件夹。
- 每个项目一个文件夹（可含子文件夹），最多 20,000 个文件；DNG 以外的 RAW 格式按文件名或文件时间。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `photo-date-organizer/` 文件夹；移动模式下，只有在你点“开始整理”时才会移动所选文件夹里的照片（点“撤销上次整理”可移回）。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/photo-date-organizer/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-photo-date-organizer test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
