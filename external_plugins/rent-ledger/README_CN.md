# 房租台账

给几间出租房记房租账：租客、租约、收款各一张表，自动算出每位租客应收多少、哪笔逾期了几天，并打印收据。按租约的付款方式（月付、季付、半年付、年付）在各自交租日计租，最后不足一月按天计，收款先冲最早未付的房租，部分付款和预付都能处理。会发现收款记到了不存在的房号（如 3O2 会提示应为 302）、重复收款、读不懂的日期金额、租约到期后还有收款、迟交的房租和快到期的租约。导出台账 Excel（租客余额、应收计划、每笔收款冲抵了什么、欠款清单）、带金额大写的收据 PDF，以及可直接发给租客的礼貌催租提醒。不用登录，无需 API 密钥，本机运行。

## 功能

- **计租**：按租约月付、季付、半年付、年付，最后不足一月按天。
- **收款**：先冲最早的房租、部分付款、预付结转、收据编号。
- **检查**：不存在的房号（提示笔误）、重复收款、逾期天数、迟交、快到期的租约。
- **导出**：台账 Excel、带大写金额的收据、可直接发送的催租提醒。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `rent-ledger/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “看看 房租 里谁还欠房租”
- “登记 201 今天交的房租”
- “打印收据和催租提醒”

## 工具

| 工具 | 作用 |
|---|---|
| `rent_open` | 读取租客和收款记录，计算应收和欠款，并打开面板 |
| `rent_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `rent_status` | 查看当前数据、问题和汇总 |
| `rent_export` | 导出 ledger.xlsx、receipts.pdf 和 reminders.md |

导出文件写到工作区的 `rent-ledger/<项目>/` 文件夹。

## 范围（v0.1）

- 只算房租；水电费和押金只记录、不计费。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `rent-ledger/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/rent-ledger/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-rent-ledger test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
