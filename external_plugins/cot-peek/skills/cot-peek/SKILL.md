# 思考小窗

模型输出的思维链是英文的。本插件在屏幕右侧放一颗圆形悬浮球，模型每写完一轮思考，中文译文半秒内出现在悬浮窗里；窗开着时复制英文，1 秒内出中文。纯外部读取，不改 ZCode 任何文件，不注入模型上下文。

## 何时用

用户想看懂思维链、嫌英文思考难读、想要划词翻译，或提到「思考小窗」「悬浮球」时，走本流程。

## 安装

本 skill 所在目录的上两级就是插件根目录。在 pwsh 里运行：

```powershell
pwsh "<插件根目录>\install.ps1"
```

脚本做两件事：找到可用的 pythonw.exe，注册每分钟检查的计划任务 `ZCodeCotPeek`。之后只要 ZCode 在运行，小球就自动出现；ZCode 退出，小球即时跟随退出。

## 启动与停止

- 立即启动：`pwsh "<插件根目录>\install.ps1"` 装完计划任务后约 1 分钟内小球自动出现，或直接双击同目录的 `start-cot-peek.bat`。
- 收起：点窗口右上角 ×，小球保留。
- 彻底退出：小球右键 → 退出小窗。本次 ZCode 会话内不再自动拉起，重启 ZCode 后恢复。

## 排障

1. **小球没出现**：看插件根目录的 `cot_peek.log`。空日志说明实例没起来，先用 `start-cot-peek.bat` 手动启动看报错。
2. **没有译文**：确认 `~/.zcode/cli/rollout/` 下有新的 `model-io-session_*.jsonl` 在增长；点小球展开窗口，再点「思考流翻译」标签回溯补翻。
3. **翻译失败标红**：三个免费接口按火山 → 必应 → MyMemory 顺序降级，全挂时保留英文原文，稍后点标签重试。
4. **不想开机自启**：`pwsh "<插件根目录>\install.ps1" -Remove` 删除计划任务。

## 边界

- 仅支持 Windows 10/11，需要一份带 tkinter 的 Python。
- 翻译走公共免费接口，质量依赖接口方；代码、URL、路径、常见术语有占位保护。
- 只读 rollout 目录与进程快照，不写 ZCode 数据，不做提示词注入。
