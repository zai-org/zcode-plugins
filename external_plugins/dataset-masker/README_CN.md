# 数据脱敏

把含个人信息的表格交给外包、供应商或 AI 工具之前，先做一份安全的副本。自动识别姓名、手机号、邮箱、身份证号、银行卡号、地址和生日；每列可选：部分遮盖（138****1234）、哈希、替换成一致的化名（用户0001）、泛化（只留城市、只留年份）、清除备注里夹带的手机号和邮箱，或直接删除该列。如果还有个人信息残留会提醒你。在本地运行，无需 API 密钥。

## 功能

- **找出个人信息**：按列名和内容识别姓名、手机、邮箱、身份证、银行卡、地址、生日和备注列（中国身份证和手机号格式、邮箱、卡号）。
- **七种处理**：保留、部分遮盖、带密钥哈希（HMAC-SHA256——同一个值得到同一个哈希，仍可统计回头客）、化名（用户0001，前后一致）、泛化（年份、省/市/区、金额区间）、清除文本中的个人信息、删除列。
- **残留检查**：保留或只部分处理的列里如果还有手机号、邮箱或身份证号，会提醒你。
- **处理前后对比**：每列都能看到处理前后的样例，以及结果的前几行。
- **说明不泄密**：masking-report.md 只写每列怎么处理，不含任何原值和哈希密钥；原文件不会被修改。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `dataset-masker/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “把 会员数据-给外包.csv 里的个人信息脱敏后再发出去”
- “手机号做哈希，让对方还能识别回头客”
- “身份证号这一列直接删掉”

## 工具

| 工具 | 作用 |
|---|---|
| `mask_open` | 读取表格、识别个人信息列并预览脱敏结果，并打开面板 |
| `mask_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `mask_status` | 查看当前数据、问题和汇总 |
| `mask_export` | 导出 masked.csv、masked.xlsx 和 masking-report.md（只记录处理方式，不含原值） |

导出文件写到工作区的 `dataset-masker/<项目>/` 文件夹。

## 范围（v0.1）

- 识别规则针对中国和常见国际格式，请务必检查列清单。
- 脱敏降低风险，但不等于法律意义上的匿名化保证；少见的组合（生日 + 区县）仍可能识别出个人。
- 每个项目一张表；v0.1 不识别备注里夹带的人名。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `dataset-masker/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/dataset-masker/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-dataset-masker test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
