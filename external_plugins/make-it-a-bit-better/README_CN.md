<h1 align="center">make-it-a-bit-better（好一点点）</h1>

<p align="center"><strong>一轮好一点点，轮次积累成产品进步。</strong></p>

一个跑自主产品打磨循环的 skill 插件。每轮**强制开一场新头脑风暴**（3 个视角强制的子代理），**择一个小角度**，实现、验证并提交，落账到项目级 ledger。一轮装不下的好想法进 **icebox**，不硬塞。哲学就是名字本身：不做重写——一轮好一点点，轮次积累成产品进步。

## 为什么不直接让 agent「优化一下」？

即兴 prompt 也能改出一段代码，但给不了这个循环的三个结构保证：

- **每轮强制新风暴** — 3 个强制视角专找前几轮漏掉的，再按账本去重；即兴 prompt 只会重炒模型上次说过的话。
- **一个小而验证过的改动** — ≤3 文件 / ≈100 行，真实检查必须通过，检查红了就回滚而不是带伤提交；即兴 prompt 优化的是「看起来做完了」。
- **跨轮记忆，外加一个校验器** — 账本记得什么已落地、什么还值得做，自带校验器保证它不作假。即兴 prompt 每次从零开始。

## 输入

| 输入 | 默认 | 作用 |
|------|------|------|
| `target` | 当前工作目录 | 要打磨的仓，必须是仓根目录。非 git 目标、或嵌在别人的仓里的子目录，动工前就被拦下。 |
| `rounds N` | 1 | 跑几轮（说「N 轮」或「继续」皆可）。给了 N 就连跑满 N 轮不再询问；连续两轮风暴出不了合格候选会提前自停。 |
| `focus` | 无 | 要聚光的功能/路径（如刚上线的功能）。贯穿每个视角的风暴生成，区内候选排序优先。 |
| `no-git` | 关 | 允许目标是非 git 目录或单个文件。不点名就不开；开启后每轮改动以备份代替 commit。 |

## 一轮长什么样

1. **接地** — 读产品、近期提交和账本；账本检查报出的问题先处理完，再动手。
2. **风暴** — 3 个新子代理各戴一个视角镜头，只交净新增候选；前几轮找到但没选中的，躺在账本的待选池里。
3. **择一** — 按感知面 × 新鲜度 ÷ 成本排序，单轮上限 ≤3 文件 / ≈100 行。待选池里连续三轮被越过的条目必须有归宿，不许一直饿着。
4. **落地** — 遵守目标仓自身规范，只留完整改动，不留 TODO / mock。
5. **验证** — 用目标仓自己的测试 / 构建 / lint / 冒烟；检查红了先在上限内修，修不好就零带伤离场。没验证过绝不谎称验证过。
6. **落账** — 一个 commit（`mabb #N: <角度>`）加一行账本记录，由自带校验器核对。
7. **续轮** — 默认问一次是否继续，给了 N 就连跑；连续两轮风暴贫瘠就自停，不硬凑弱改动。

协议正文——每一道闸、账本格式、失败轮的出路——都在 [`SKILL.md`](skills/make-it-a-bit-better/SKILL.md)。本页只是摘要；两边不一致时，以技能文本为准。

每轮以固定的 6 字段轮报收尾——`angle:` / `who feels it:` / `what changed:` / `evidence:` / `icebox additions:` / `next-round hint:`——整场运行以 4 字段总结落幕：`rounds:` / `changes:` / `icebox added:` / `leftovers:`。空字段写 `none`。

## 账本

目标仓的 `.agents/mabb/ledger.md` 是循环的记忆：

- **记录行** — 每轮一行：维度、角度、commit、文件、证据，各占短短一格。账本超出预算后旧记录行折进归档，轮次累积也只有几千字节。
- **待选池** — 够小但没被选中的好候选，排好序，最多八条（`B-1` 是榜首）。下一轮风暴从它们出发，只让各视角找新的。
- **冰柜** — 一轮装不下的好想法。整个想法全部落地才销账；只落了一部分，就把条目改写成剩下的部分。
- **检查而非相信** — `scripts/ledger.mjs check` 在每轮开头跑一次、每次写完账本再跑一次：核对格式与编号；仓里已经不存在的 commit 会被报出来，历史被重写也不会悄悄断线索。

## 副作用披露（供评审）

- **模型调用**：每轮派 3 个短命头脑风暴子代理（无子代理工具的客户端退化为会话内三趟）——N 轮约 3N 次这样的调用。
- **文件**：在目标仓写改动本身，外加本地账本 `<target>/.agents/mabb/`。no-git 模式下这里还留一份备份，以及失败轮的改动前后副本。
- **Git**：每轮在目标仓落一个本地 commit（失败轮恰好两个：本轮 commit + 其 revert——失败 diff 留在历史，零带伤提交）。别人的未提交改动绝不被暂存。多人协作仓先提分支方案再动。**绝不 push**，除非你当次明说。
- **账本隐私**：账本尚未被忽略时，往仓的 `.gitignore` 加一行 `.agents/mabb/`——绝不忽略整个 `.agents/`——并单独提交为 `mabb: ignore the ledger`（`.gitignore` 上有别人的改动时，改写进 `.git/info/exclude`）。团队已跟踪的账本每轮多一个小 commit（`mabb #N: ledger`）。
- **网络**：除模型 API 外无任何访问。
- **运行时**：自带校验器需要 Node 18.13 或更新（零依赖）；跑不起来时循环在动工前就停。
- **上下文**：技能文本由契约测试限定在 16,000 字符以内、正文每行不超过 400 字符，小上下文 agent 永远装得下一轮。

## 安装

```bash
# DeepSeek Harness
dsh plugin add /path/to/make-it-a-bit-better   # 或：dsh plugin add make-it-a-bit-better

# ZCode
zcode plugins install make-it-a-bit-better@<marketplace>

# Codex
codex plugin add make-it-a-bit-better@<marketplace>
```

DSH 形态需要 DSH `>=0.2.1-rc.2 <0.3.0`。

## 快速开始

装好插件后：

> 对 /path/to/repo 跑 3 轮 make it a bit better

也可以带上方向盘：指定仓、要 N 轮、聚光一个区域：

> 对 /path/to/repo 跑 5 轮 make it a bit better，focus 在结账流程

预期：每轮一条账本记录，最多 N 个已提交的小改进——说「最多」是因为连续两轮风暴贫瘠会自停，检查红了修不好就整轮回滚。commit 数少于 N 是循环在诚实，不是坏了。
