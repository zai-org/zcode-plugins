# 甘特图计划

把一张简单的任务清单变成带真实工作日日期的甘特图。写上任务、工期（工作日）、负责人和前置任务，插件会让每个任务在前置任务完成后的下一个工作日开始，跳过周末和你列出的节假日，标出里程碑，并高亮关键路径——决定完工日期的那条任务链。指定开始日期、改工期或改依赖，所有日期自动跟着变。导出 SVG 和 PNG 甘特图、Excel 排期表和网页。在本地运行，不用登录，无需 API 密钥。

## 功能

- **按工作日排期**：工期按工作日计算，跳过周末和列出的节假日（也可以把周末算作工作日）。
- **依赖关系**：前置写“4, 5”，就在两者都完成后的下一个工作日开始；指定的开始日期会保留，除非前置任务完成得更晚（会提示）。
- **关键路径**：浮动时间为 0 的任务标红，每个任务都显示浮动天数。
- **里程碑**：工期 0 画成菱形并标日期；进度百分比填充在任务条里。
- **自动检查**：循环依赖、找不到的或重复的任务编号。
- **导出**：带月份、日期、周末底色和依赖箭头的 SVG 与 2 倍 PNG 甘特图；标出关键任务的 Excel 排期表；网页。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `gantt-planner/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 tasks.csv 做一张甘特图，12 月 25 日放假”
- “前端开发要 12 天，完工日期变成哪天？”
- “导出甘特图和排期表”

## 工具

| 工具 | 作用 |
|---|---|
| `gantt_open` | 读取任务，按工作日和依赖关系排期，并打开面板 |
| `gantt_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `gantt_status` | 查看当前数据、问题和汇总 |
| `gantt_export` | 导出 gantt.svg、gantt.png、schedule.xlsx 和 gantt.html |

导出文件写到工作区的 `gantt-planner/<项目>/` 文件夹。

## 范围（v0.1）

- v0.1 只支持“完成-开始”依赖（不支持提前/滞后或“开始-开始”）。
- 不做资源平衡：同一负责人的任务可能重叠。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `gantt-planner/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/gantt-planner/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-gantt-planner test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
