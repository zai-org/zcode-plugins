# 销售提成计算

从销售明细表算出每位销售的提成，并生成清楚的个人提成单。设置阶梯比例——超额累进（像个税一样每档只算该档部分）或全额阶梯（达到哪档全部按哪档）；配件、服务等品类可以单独设比例；退货、取消的订单自动扣回提成。可以只算某个月，每一行的比例和提成都看得到，还会提示重复订单、退货记错人、同一个人名字写法不一致。导出提成汇总 Excel 和每人一页的 PDF 提成单。在本地运行，不用登录 CRM，无需 API 密钥。

## 功能

- **大白话写阶梯**：“0-5万:3%; 5万-10万:5%; 10万+:8%”或“5万:3%; 10万:5%; 以上:8%”。
- **两种算法**：超额累进（每档只算该档部分）或全额阶梯（达到哪档全部按哪档）。
- **特殊品类**：“配件:8%; 服务:12%”——这些品类的行（没有品类时按产品名包含该词）单独计提，不计入阶梯。
- **退货扣回**：状态为退货/退款/取消或金额为负的行冲减当期销售，并按同样的有效比例扣回，上个月的订单也一样。
- **自动检查**：订单号重复、退货记在别人名下、名字写法不一致、不在期间内的行。
- **导出**：汇总/明细/规则三张表的 Excel，以及每人一页、含阶梯明细和签字栏的 PDF 提成单。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `sales-commission/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 sales.xlsx 算 10 月的提成”
- “配件按 8%、服务按 12%，不计入阶梯”
- “改成全额阶梯看看差多少”

## 工具

| 工具 | 作用 |
|---|---|
| `commission_open` | 读取销售明细并计算提成，并打开面板 |
| `commission_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `commission_status` | 查看当前数据、问题和汇总 |
| `commission_export` | 导出 commission.xlsx 和每人一份 PDF 提成单 |

导出文件写到工作区的 `sales-commission/<项目>/` 文件夹。

## 范围（v0.1）

- v0.1 所有人用同一套提成规则（不支持个人目标或封顶）。
- 按表里的金额计提，不考虑毛利或成本。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `sales-commission/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/sales-commission/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-sales-commission test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
