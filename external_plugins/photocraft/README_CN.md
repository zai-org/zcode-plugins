# PhotoCraft ZCode 插件

在 ZCode 面板中使用 PhotoCraft 进行图片编辑，支持打开工作区文件和通过宿主保存导出。

## 使用

从本市场安装并启用 `photocraft`。打开会话中的 **PhotoCraft** 面板，运行 `/photocraft:open`，或让 Agent 调用该插件的 `open_editor` 工具。可选的 `path` 为工作区相对路径。使用应用自带的文件选择器或拖放打开文件；Agent 可通过 `open_editor(path)` 打开工作区文件。

用应用原有工具进行编辑。保存和导出会请求 ZCode 的“另存为”对话框；取消或失败后，可用错误提示中的“重新保存导出”重试。面板就绪后，Agent 可调用全部 25 个上游 MCP 工具，直接操作面板中的同一份文档；通用命令工具还可访问完整命令目录。先调用 `open_editor`。MCP 保存会按指定路径写入工作区并报告落盘结果，手动导出仍使用“另存为”。

## 要求和限制

- ZCode 须支持 MCP Apps 面板、WASM CSP 声明和 `ui/download-file`；随包 MCP 服务需要 Node.js 24 或更高版本。
- 每次 MCP 操作最多读取 256 个文件、合计 128 MiB，每个输出文件上限为 128 MiB。工作区文件导入上限为 128 MiB，宿主另存为导出上限为 50 MiB。超过上限会明确报错。
- 功能以 Web 版为准，受浏览器图形、音频和格式能力限制。它不是原生桌面程序。打印、全屏、剪贴板和原生音频插件取决于宿主及浏览器能力，不保证可用。
- 随包内置 LXGW WenKai（霞鹜文楷）中文字体，供界面及应用支持的文本渲染路径回退使用，无需安装系统字体或联网下载。
- 首次打开默认使用简体中文；未翻译的内容沿用上游回退。切换语言及偏好保存由应用自身处理。
- 未保存文档属于当前面板，关闭前请保存；此封装不承诺文档恢复或跨会话同步。

## 权限和数据

服务只读取当前工作区内明确请求的文件，并检查真实路径，阻止符号链接逃逸。应用资源通过 MCP 按 2 MiB 分片读取，并验证 SHA-256。封装不会监听网络端口、运行时下载依赖或向外部服务发送文件。MCP 输出经过路径和符号链接检查后，在工作区内原子保存；指定的输出文件可能被覆盖。面板关闭或断连会终止等待，不会自动重放超时的修改命令；已经发出的操作应先检查文档状态再决定是否重试。上游应用可能保存浏览器偏好设置。

## 构建和来源

源码位于 `ui-plugins/photocraft`，共用适配器位于 `ui-plugins/craft-runtime`。`pnpm build` 优先使用构建缓存中的 Web 编译快照；缓存没有时用 Rust 和 Trunk 从固定的上游提交编译，快照不提交到仓库。`pnpm --filter @zcode/plugin-photocraft build:web` 可强制重新编译。环境要求和验证方法见共用适配器说明。

上游为 [PhotoCraft](https://github.com/storytold/photocraft)，版本 0.7.0，提交 `649b1d5d92c08bf846631a868adc8a5c6ec6e888`。快照由 Trunk 从源码编译生成，不是下载的 Release。`dist/BUILD.json` 记录来源和文件哈希。上游及依赖的许可保留在 `dist/licenses/`，Rust 应用采用 MIT OR Apache-2.0；ArtCraft 品牌仍遵循上游商标条款。

这是基于上游项目的独立 ZCode 封装，不是 ArtCraft 官方插件。PdfCraft、DesignCraft 的品牌图形已按上游条款移除；补丁及哈希保留在源码和构建记录中。

## 后台保留

编辑器声明后台保留，以便隐藏后继续工作。同一窗口超过四个后台保留页面时，宿主可回收三十分钟未活跃且不忙的页面。离开前请保存；回收不保留未保存的页面内存。
