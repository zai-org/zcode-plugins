# 表格对比

对比同一张表格的两个版本——上个月和这个月的价目表、两次导出的客户名单——准确看出新增了哪些行、删除了哪些行、哪些单元格改了，旧值新值并排显示。按货号这类编号列匹配行，排序变了也不会误报；可以忽略细小的数字差异和多余空格。可导出标色的 Excel、变化清单和报告。在本地运行，无需 API 密钥。

## 功能

- **智能匹配**：自动找关键列（两边都不重复的第一列，如 货号），也可以指定一列或多列；没有关键列时按行号对比。
- **每一处变化**：新增行、删除行、修改的单元格（旧值和新值）；还会提示新增或删除的列、重复的关键值。
- **不误报**：199 和 199.0 视为相同；可设数字容差、忽略多余空格、忽略大小写。
- **标色 Excel**：新版本里修改的单元格标黄（批注写旧值），新增行标绿，新增列标蓝；删除的行单独一个工作表；另附变化清单。
- **备注**：可以给任意变化加备注（如“涨价已通知”），导出时一并保留。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `sheet-diff/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “价目表-10月.xlsx 和 价目表-11月.xlsx 有哪些变化？”
- “按 门店+货号 匹配行”
- “忽略小于 0.01 的差异”

## 工具

| 工具 | 作用 |
|---|---|
| `sheetdiff_open` | 对比两张表，列出新增、删除和修改的行，并打开面板 |
| `sheetdiff_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `sheetdiff_status` | 查看当前数据、问题和汇总 |
| `sheetdiff_export` | 导出 diff.xlsx（新版本标色、删除的行、变化清单）、changes.csv 和 diff.html |

导出文件写到工作区的 `sheet-diff/<项目>/` 文件夹。

## 范围（v0.1）

- 一次对比两张表，各取 .xlsx 的第一个有数据的工作表。
- 只比较值，不比较格式和公式。
- 每张表最多约 100,000 行。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `sheet-diff/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/sheet-diff/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-sheet-diff test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
