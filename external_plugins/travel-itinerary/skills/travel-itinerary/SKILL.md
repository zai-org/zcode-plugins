# 行程单制作

1. `trip_open(inputs, settings?, project?)`：读取行程表，检查时间、时区和住宿。inputs 是工作区相对路径。
   - 结果里有汇总、问题列表（错误 / 提醒）和前几行数据，每行有编号 `#n`。
   - inputs 传行程表 .xlsx/.csv（或所在文件夹）；每行一项：日期、开始、结束、结束日期（退房/到达日期）、时区、到达时区、类型、事项、地点、地址、预订号、备注。
2. 向用户简要说明结果，先说错误和需要确认的地方，不要逐行念。
3. 用户要改时调用 `trip_edit(project, settings?, set?: [{row, values}], add?, remove?)`。
   - 改时间：`set: [{row, values: {start: "13:30", end: "15:30"}}]`；航班补到达时区：`values: {endTz: "东京"}`；改入住日期：`values: {date: "2026-12-21"}`；隔天到达写 `end: "07:10 +1"`。
4. `trip_export(project, formats?)`：导出 itinerary.pdf、itinerary.ics 和 itinerary.xlsx。把文件路径告诉用户。
5. 时区留空表示和上一行相同；航班/火车跨时区一定要写到达时区，否则后面各行都会按出发地时间算。
