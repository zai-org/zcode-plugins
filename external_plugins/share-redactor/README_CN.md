# 分享前资料脱敏

把文件发给外部之前，先去掉里面的个人信息：自动找出来、逐处确认、导出干净的副本，再检查一遍有没有漏掉。

## 功能

- **支持的文件**：`.pdf`（有文字层）、`.docx`、`.xlsx`、`.csv`、`.txt`、`.md`。
- **能找到的内容**：
  - 手机号：中国大陆手机号（含空格、横线、+86 写法）、固定电话、国际号码。
  - 身份证号（校验位和出生日期都会验证）。
  - 银行卡号（Luhn 校验）。
  - 邮箱地址。
  - 金额（可选）。
  - 你输入的任何姓名或词语，比如客户姓名、项目代号。
- **查找范围**：
  - DOCX：正文、页眉、页脚、脚注、尾注、批注；被格式拆开的文字也能找到；还包括 `mailto:` 链接和文档属性。
  - XLSX：所有工作表，包括存成数字的单元格（脱敏后改成文本，公式会去掉）。
  - PDF：页面文字（跨行断开的号码也能识别）、链接注释和元数据。
- **确认面板**：
  - 每处命中都带上下文。取消勾选即保留这个值，所有文件里同一个值都保留，比如公司客服电话。
  - PDF 页面上直接显示将要涂黑的框。点框可以保留；在页面空白处拖动可以手动涂黑其他区域，比如签名、照片。
- **输出**：
  - 副本保存在 `redacted/<文件名>.redacted.<扩展名>`，原文件不改动。
  - DOCX、XLSX 和文本文件直接替换，可选三种方式：标签（`[手机号]`）、色块（`███`）、部分遮盖（`138****5678`）。默认清除作者等文档属性。
  - **PDF 会被“拍平”**：每页转成图片再涂黑，文字层、链接、表单和元数据都不会保留。
  - `redaction-log.csv` 记录每处脱敏的类型和位置，不含原值。
- **导出后自检**：重新完整读取每个输出文件（全部文字、链接、属性和元数据），确认脱敏的值一个都没剩，带不带空格、横线的写法都会检查。PDF 还要确认没有文字层。

## 使用方法

在 ZCode Desktop 里对 Agent 说：

- “把 报价单.pdf 和 客户名单.xlsx 里的手机号、身份证号、银行卡号脱敏，我要发给外部”
- “再把王晓明、李娜这两个名字也隐藏，但公司的客服邮箱保留”
- “导出脱敏副本，告诉我自检有没有通过”

## 工具

| 工具 | 用途 |
|---|---|
| `redact_scan` | 扫描文件，列出每处命中（带编号），打开确认面板 |
| `redact_save` | 修改选项，按编号保留或取消保留 |
| `redact_export` | 写出脱敏副本、日志和自检结果 |

Agent 看到的始终是部分遮盖后的值（例如 `138****5678`）。

## 范围（v0.1）

- 不识别图片里的文字和扫描件（OCR）；扫描页请在面板里手动框选。
- 姓名只能按你给的列表查找，不做自动姓名识别。
- 不支持旧版 `.doc` / `.xls`、PPTX 和图片文件；DOCX/XLSX 里嵌入的图片保持原样。
- 拍平后的 PDF 体积更大，文字不能再选中或搜索。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件。只写入输出文件夹（默认 `redacted/`）和工作区里的 `.share-redactor/settings.json`。没有 hooks。

## 构建与测试（开发者）

- 源码：`ui-plugins/share-redactor/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-share-redactor test` 和 `test:e2e`（e2e 需要 Chrome 和 poppler-utils）。
- `REDACT_SAMPLES` 指向样本文件：合同、客户名单、通讯录、会议纪要和报价单，里面的个人信息全部是虚构的。
