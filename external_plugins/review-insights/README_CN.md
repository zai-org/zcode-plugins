# 商品评价分析

看清顾客到底在夸什么、在抱怨什么。打开店铺导出的评价（CSV 或 Excel，有评价内容，最好也有星级），每条评价按短句拆开，归到质量、尺码、物流、包装、价格、外观、气味、使用体验、客服等主题（中英文都支持）。报告列出每个主题的主要差评和好评原因并附原话、差评占比、星级分布，还会标出疑似重复刷评和没有归类的评价。主题词库可以自己改，单条评价的倾向和主题也能手动修正，最后导出 HTML 报告和 Excel。在本地运行，不用登录，无需 API 密钥。

## 功能

- **按短句归类**：一条评价可以夸外观、吐槽尺码，各自计入对应主题。
- **好差评判断**：先看星级，再按短句细分，能处理否定（“没有色差”算好评，“不太满意”算差评）。
- **词库可改**：每行一个主题，中英文关键词。
- **手动修正**：单条评价的倾向和主题都能改。
- **检查**：重复内容（疑似刷评）、超出 1–5 的评分、空评价和未归类评价。
- **导出**：带原话和主题条形图的 HTML 报告，以及主题汇总 + 评价明细的 XLSX。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `review-insights/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “分析 reviews.csv，告诉我主要差评原因”
- “加一个“面料”主题，关键词 面料、布料”
- “导出分析报告”

## 工具

| 工具 | 作用 |
|---|---|
| `reviews_open` | 读取评价并按主题归类，并打开面板 |
| `reviews_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `reviews_status` | 查看当前数据、问题和汇总 |
| `reviews_export` | 导出 review-report.html 和 review-insights.xlsx |

导出文件写到工作区的 `review-insights/<项目>/` 文件夹。

## 范围（v0.1）

- 基于关键词而不是大模型：说法特别的评价需要补充关键词。
- 一次读取一个导出文件。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `review-insights/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/review-insights/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-review-insights test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
