# 透视汇总报表

像 Excel 数据透视表一样把明细表变成汇总报表——按门店、品类、销售员或任意字段分组，把月份或季度横向展开，对数值求和、计数或求平均——不用再折腾 Excel 的透视表菜单。支持百分比、前 N 名和条形图；可导出整洁的 Excel 报表、CSV 或可打印的 HTML 页面。在本地运行，无需 API 密钥。

## 功能

- **透视字段**：一个或多个行字段、可选的列字段、值字段可求和、计数、平均、最小、最大或不重复计数。
- **日期**：日期列可按日、ISO 周、月、季度或年分组。
- **一眼看懂**：总计行列、占行/列/总计的百分比、按数值排序、只显示前 N 名（其余仍计入总计），附条形图。
- **开箱即用**：根据数据自动建议行字段和值字段（如 品类 和 金额）；¥1,000 这样的金额文本也能正确求和。
- **导出**：带数字格式和总计行的 Excel 报表（附原始数据）、CSV，以及可打印成 PDF 的 HTML 页面。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `pivot-report/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “汇总 订单明细-2026.xlsx：按门店和月份统计销售额”
- “显示每个门店占总额的百分比”
- “只看金额前 5 的商品”

## 工具

| 工具 | 作用 |
|---|---|
| `pivot_open` | 读取明细表，按建议字段生成透视汇总，并打开面板 |
| `pivot_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `pivot_status` | 查看当前数据、问题和汇总 |
| `pivot_export` | 导出 pivot.xlsx（透视、百分比和原始数据工作表）、pivot.csv 和带条形图的 pivot.html |

导出文件写到工作区的 `pivot-report/<项目>/` 文件夹。

## 范围（v0.1）

- 一次一张表（取第一个有数据的工作表）；不做表间关联。
- v0.1 没有计算字段和按值筛选（请先筛好源数据）。
- 条形图显示按行合计的前 15 行。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `pivot-report/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/pivot-report/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-pivot-report test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
