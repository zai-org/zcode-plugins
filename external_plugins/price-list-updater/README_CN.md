# 批量调价

一次改完整张价目表：饮料涨 5%、某个供应商的商品加 1 元、单个 SKU 改成 12.9，或者按进价加成定价，再统一取尾数（12.9、12.99、19 这样）。每行显示原价、新价、涨跌和毛利率；单个价格可以手动改，之后调规则也会保留。会提示毛利率过低、低于进价、涨跌幅过大和没有匹配到商品的规则。导出新价目表（保留原表所有列，改动的价格标色、批注原价）和改价对照 CSV。在本地运行，不用登录店铺，无需 API 密钥。

## 功能

- **规则从上往下，第一条匹配的生效**：“分类=饮料,零食: +5%”“供应商=绿源: +1”“SKU=A001: =12.9”“名称=有机: x1.1”“全部: 成本+40%”。
- **尾数取整**：到分、角、元、0.5，或尾数 .99、.9、.8、个位 9；可向上、向下或就近。
- **单个价格手动改**：在表格里直接改，标记为手动，改规则后仍保留。
- **检查**：毛利率低于下限、低于进价、涨跌幅超过设定、规则没匹配到商品、规则写错。
- **原表更新**：保留原表所有列和顺序；涨价标红、降价标绿，批注原价；另附“改价对照”表。
- **改价对照 CSV**：只含改动的商品，方便通知同事或导入收银系统。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `price-list-updater/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “饮料涨 5%，其他涨 3%，尾数取 .9”
- “生鲜按进价加 50% 定价”
- “导出改价对照表”

## 工具

| 工具 | 作用 |
|---|---|
| `prices_open` | 读取价目表并按规则调价，并打开面板 |
| `prices_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `prices_status` | 查看当前数据、问题和汇总 |
| `prices_export` | 导出 updated-prices.xlsx 和 price-changes.csv |

导出文件写到工作区的 `price-list-updater/<项目>/` 文件夹。

## 范围（v0.1）

- 每张表一个价格列；工作簿只读第一个工作表。
- 只改价格，不改库存，也不会发布到店铺。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `price-list-updater/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/price-list-updater/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-price-list-updater test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
