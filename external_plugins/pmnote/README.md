# PMNote

Find and read PMNote public sources for game project management, delivery risks, cross-team collaboration, career preparation, and game development AI tools. Ask ZCode a relevant question or invoke the `pmnote` skill explicitly. Answers should cite the original sources.

## Requirements and effects

- Network access to pmnote.ai and linked public sources.
- Python 3 for optional read-only readers of dynamic public interviews, works, and tool details. No account or API key is required. The interview search sends only the requested keyword.
- The plugin includes no hooks or MCP server and does not write data to PMNote. External sites have their own policies.
- The Skill files are provided under the included [PMNote license](skills/pmnote/LICENSE). The author authorizes distribution of this plugin by the ZCode official marketplace; linked third-party works retain their own rights.
