# Sitemap Builder

Get a static website ready for search engines: point it at the site folder and get a correct sitemap.xml and robots.txt, with clean URLs, last-modified dates, change frequency and priority you can adjust per page. Pages marked noindex or with a canonical elsewhere are left out, and every internal link, image, script and stylesheet is checked so broken links are listed before you publish. Runs locally on your files; no crawler service or API keys.

## Features

- **Correct sitemap.xml**: absolute, URL-encoded addresses (Chinese file names too), clean URLs without .html or index.html, lastmod, changefreq and priority.
- **Sensible defaults**: home 1.0 and lower priority for deeper pages; dates from <meta name=date> or article:modified_time, else the file date.
- **Leaves out what shouldn't be indexed**: noindex pages, 404 pages and pages whose canonical URL points elsewhere — you can still tick them back in.
- **Broken link check**: relative, root-relative and same-domain absolute links, images, scripts and stylesheets; folders resolve to index.html and extensionless links to .html.
- **robots.txt**: Allow or your Disallow paths, plus the Sitemap line.
- **Panel**: pick input files, adjust settings, see problems, edit any cell in the table, preview the result and export — all in the ZCode side panel. Edits are saved in `sitemap-builder/<project>.project.json` and kept until you re-open the inputs.

## Usage

Ask the agent in ZCode Desktop:

- "Make a sitemap for site/ at https://tea.example"
- "Which links are broken?"
- "Block /drafts/ in robots.txt"

## Tools

| Tool | Purpose |
|---|---|
| `sitemap_open` | Read the site's pages, plan the sitemap and check links. Opens the panel |
| `sitemap_edit` | Change settings, edit cells by row, add or remove rows |
| `sitemap_status` | Show the current rows, issues and summary |
| `sitemap_export` | Write sitemap.xml, robots.txt and link-report.csv |

Output goes to `sitemap-builder/<project>/` in the workspace.

## Scope (v0.1)

- Static HTML folders only; pages generated by a server or JavaScript router are not discovered.
- External links are not checked (no network access).
- One sitemap file, up to 50,000 URLs; no sitemap index or image/video sitemaps in v0.1.

## Privacy, network and files

- **Everything runs locally.** No network, no uploads, no API keys or accounts.
- Reads only the files you choose. Writes only the `sitemap-builder/` folder in the workspace. No hooks.

## Build and test (developers)

- Source: `ui-plugins/sitemap-builder/`.
- Build: `pnpm install --frozen-lockfile && pnpm build`, then add `dist/local-marketplace` as a local source.
- Tests: `pnpm --filter @penova/plugin-sitemap-builder test` and `test:e2e` (needs Chrome; sample files in `test/samples/`).
