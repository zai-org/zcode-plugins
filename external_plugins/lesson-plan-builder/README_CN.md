# 教案制作

用简单的 Markdown 写教案，得到格式规范、可打印的 Word 和 PDF 教案——并检查评课时常被扣分的地方。每课包含基本信息（学科、年级、教材、课时）、教学目标、重难点、教学准备、教学过程（环节标题下写 教师/学生/设计意图，或表格，或一行一个带分钟数的环节）、板书设计和作业。可在表格里改任何条目和环节，增加环节或作业，设置授课人、日期和上课时间（每个环节自动标出起止时刻）。会检查环节时间加起来是否等于课时，标出用“了解/理解/掌握”等模糊动词、没有可观察结果的目标，教师连续讲授很久却没有学生活动的环节，环节里用到但教学准备里没列的教具，以及缺少目标、重难点或作业。整个单元导出为一份文档——每课一页，教学过程做成 环节/时间/教师活动/学生活动/设计意图 表格，可留教学反思空行——Word、PDF 和 Markdown。不用登录，无需 API 密钥，本机运行。

## 功能

- **输入简单**：每课一个 Markdown；教学过程可用标题、表格或一行一个环节。
- **可编辑**：目标、准备、环节、板书、作业都是一行，可增删。
- **时间**：总时长对照课时，每个环节标出起止时刻。
- **检查**：模糊目标、只有教师活动的长环节、未列入准备的教具、缺少的部分。
- **导出**：Word、PDF、Markdown，每课一页，标准教学过程表。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `lesson-plan-builder/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “把 教案 文件夹里的两课时做成 Word 和 PDF 教案”
- “把超时的环节调好，给第2课时补上作业”
- “导出教案”

## 工具

| 工具 | 作用 |
|---|---|
| `lesson_open` | 读取教案文件并检查，并打开面板 |
| `lesson_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `lesson_status` | 查看当前数据、问题和汇总 |
| `lesson_export` | 导出 lesson-plans.docx、lesson-plans.pdf 和 lesson-plans.md |

导出文件写到工作区的 `lesson-plan-builder/<项目>/` 文件夹。

## 范围（v0.1）

- 检查的是结构和表述，不评判教学内容本身。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `lesson-plan-builder/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/lesson-plan-builder/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-lesson-plan-builder test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
