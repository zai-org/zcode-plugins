# 赛程对阵

用一份参赛名单办公司或学校比赛：生成单循环（或主客双循环），或按种子排位、高种子轮空的淘汰赛（可加三四名决赛），给每轮排日期，边比赛边录比分，实时得到积分榜或填好的对阵图。已经打完的比分可以从表格导入。积分榜按积分（胜/平/负积分可设）排名，再看相互战绩、净胜分、总得分；淘汰赛胜者自动晋级，平局需要写决胜分如 2(4):2(3)。会发现比分和队名的笔误、重复的队伍和种子、对阵还没确定就录了比分、同一队同一天被排两场，以及需要抽签或加赛的同分。导出含赛程和交叉表的积分榜 Excel、可发群里的对阵图/积分榜 SVG 和 PNG，以及带比分格的可打印赛程表。不用登录，无需 API 密钥，本机运行。

## 功能

- **赛制**：单/双循环，或按种子排位、带轮空和三四名决赛的淘汰赛。
- **比分**：写 21:15 或 2(4):2(3)；可导入已赛比分。
- **积分榜**：积分、相互战绩、净胜分、总得分；淘汰赛自动晋级。
- **检查**：比分和队名笔误、重复、提前录分、一天两场、未分出的同分。
- **导出**：积分榜 Excel、对阵图/积分榜图片、可打印赛程表。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `tournament-bracket/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 羽毛球赛 里的名单排单循环赛程”
- “录入今天的比分”
- “导出积分榜和对阵图”

## 工具

| 工具 | 作用 |
|---|---|
| `bracket_open` | 读取参赛名单并生成赛程，并打开面板 |
| `bracket_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `bracket_status` | 查看当前数据、问题和汇总 |
| `bracket_export` | 导出 standings.xlsx、bracket.svg、bracket.png 和 schedule.pdf |

导出文件写到工作区的 `tournament-bracket/<项目>/` 文件夹。

## 范围（v0.1）

- 适合单阶段赛事；小组赛 + 淘汰赛可以分成两个项目来做。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `tournament-bracket/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/tournament-bracket/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-tournament-bracket test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
