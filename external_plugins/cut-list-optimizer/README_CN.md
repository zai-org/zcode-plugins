# 板材开料优化

把家具、柜体的零件排到板材上，得到可打印的开料图、要买几张板和封边总长。读取零件清单（名称、长、宽、数量、材料、纹理、封边）和板材尺寸单价，按断头锯方式排版（每一刀都是通切，适合推台锯），大件优先，计入锯缝和修边，有纹理的零件不旋转。会发现比板材还大或只能横纹放下的零件、没有对应板材的材料（提示相近的名称）、读不懂的尺寸、数量和封边写法，以及几乎空着的最后一张板。导出每张板一页、零件带标注的开料图 PDF，全部板材的 SVG，以及开料单 Excel（每个零件在哪张板、位置坐标，各材料的张数、利用率、金额和封边米数）。不用登录，无需 API 密钥，本机运行。

## 功能

- **排版**：断头锯排版，计锯缝和修边；顺纹零件不旋转。
- **材料**：多种板材尺寸和单价；分别算张数、利用率和金额。
- **封边**：每件写 四边、2长1短 或 L2W1；按材料汇总米数。
- **检查**：超尺寸零件、只能横纹放下、未知材料（提示相近名称）、尺寸错误、最后一张几乎空着。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `cut-list-optimizer/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 衣柜 里的零件清单排开料图”
- “算一下要买几张板”
- “导出开料图和开料单”

## 工具

| 工具 | 作用 |
|---|---|
| `cut_open` | 读取零件清单并排版，并打开面板 |
| `cut_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `cut_status` | 查看当前数据、问题和汇总 |
| `cut_export` | 导出 cutting-diagrams.pdf、cutting-diagrams.svg 和 cut-list.xlsx |

导出文件写到工作区的 `cut-list-optimizer/<项目>/` 文件夹。

## 范围（v0.1）

- 只支持矩形零件；不管理余料，不输出 CNC 程序。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `cut-list-optimizer/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/cut-list-optimizer/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-cut-list-optimizer test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
