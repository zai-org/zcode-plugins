# 电商商品图助手（Product Photo Studio）

把一批商品照片处理成可以直接上架的图片：去掉纯色背景、统一商品大小和位置、加阴影，一次导出白底主图、透明 PNG 和各平台需要的尺寸。不满意的图可以在侧栏单独调整。

## 能做什么

- **批量去背景**：去掉与照片边缘相连的纯色 / 浅色 / 渐变棚拍背景，保留商品内部的白色标签；已有透明通道的 PNG 直接使用。边缘做柔化和去色边处理。
- **统一尺寸和位置**：自动裁到商品本身，按“主体占比”放到画布中央（或底部对齐），所有图的商品大小一致。
- **阴影**：地面椭圆柔影或轮廓投影，可调浓度。
- **多尺寸导出**：白底 800×800（淘宝/天猫/京东主图）、1000×1000（拼多多/抖店）、Amazon 2000×2000、Shopify 2048×2048、社媒 1080×1080、小红书 1080×1440、透明 PNG 1600×1600，以及自定义尺寸。
- **单张调整**：在面板里选中任意一张，单独改容差、大小、位置、阴影、背景色，只重新导出这一张。
- **自动提醒**：背景复杂、几乎没去掉背景、商品贴边、容差过高等情况会在缩略图上标出。
- **设置可复用**：整批设置保存为 `.photostudio.json`，下一批商品直接套用同样的风格。

## 使用

在 ZCode Desktop 中对 Agent 说：

- “把 products 文件夹里的商品照全部做成 800×800 白底主图和透明 PNG”
- “把所有商品图统一大小、加柔和阴影，导出 Amazon 2000×2000”
- “香水那张位置太靠上了，往下挪一点，只重新导出这一张”

也可以从会话侧栏打开“电商商品图助手”，勾选工作区里的图片。左侧是全部图片的设置和输出尺寸，中间是缩略图，点一张在下方单独调整，最后点“全部导出”。

## 工具

| 工具 | 作用 |
|---|---|
| `photos_open` | 打开一批照片（文件夹、路径或已保存的项目），检查并打开面板 |
| `project_save` | 保存设置为 `.photostudio.json` |
| `photos_export` | 按所选尺寸导出全部或部分照片 |

## 支持范围（v0.1）

- 输入：JPG（自动按 EXIF 方向旋转）、PNG（含透明通道）。
- 去背景适用于纯色、浅色或渐变的棚拍背景。**复杂背景**（桌面、户外、场景图）、头发、透明玻璃不在 v0.1 范围内：缩略图会提示“背景不是纯色”，建议先用其他工具抠好透明 PNG 再放进来。
- 暂不支持：WebP / HEIC 输入、画笔精修、换场景背景。

## 隐私、网络与文件写入

- **全部在本机处理**，不联网，不上传图片，不需要任何 API 密钥或账号。
- 只读写当前工作区：原图不会被修改，结果写到输出文件夹（默认 `product-photos-output/<尺寸>/`），项目设置写到你指定的 `.photostudio.json`。不执行命令，没有 Hook。

## 构建与测试（开发者）

源码在 `ui-plugins/product-photo-studio/`。仓库根目录执行 `pnpm install --frozen-lockfile && pnpm build`，在 ZCode 插件商店添加 `dist/local-marketplace` 为本地来源后安装。测试：`pnpm --filter @penova/plugin-product-photo-studio test`（真实商品照 + 合成样本，校验主体占比、居中、白底纯白、透明背景）与 `test:e2e`（浏览器面板测试，可用 `E2E_PHOTOS` 指向自己的商品照文件夹）。
