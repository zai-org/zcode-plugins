# Archify Panel (archify-panel)

<p align="center">
  <img src="assets/icon.png" alt="Archify Panel" width="120" />
</p>

[Archify](https://github.com/tt-a1i/archify), adapted for the ZCode side panel: this plugin bundles Archify's diagram engine (v3.2.0) and brings architecture, workflow, sequence, dataflow, state machine, ERD, class, tree, timeline and waterfall diagrams into the ZCode side panel with full interaction and export.

> Source repository: [tt-a1i/archify](https://github.com/tt-a1i/archify) — the upstream diagram engine (Apache-2.0).

> 中文文档：[README_CN.md](README_CN.md)

## Features

- Agent-driven rendering: describe a diagram in natural language; the agent renders it with the bundled Archify runtime
- Interactive side panel: results open in the ZCode side panel in full-interaction mode
- Export: PNG, SVG and share cards from the diagram's own export menu, saved into the workspace

## Install

Install from the ZCode Plugin Marketplace (**Settings → Plugins → Plugin Marketplace**), search for Archify.

## Usage

After installation, just ask the agent to draw, for example:

- "Draw an architecture diagram of this repository's frontend and backend"
- "Show the login request flow as a sequence diagram"

The agent renders via the bundled skill `archify-panel`; the result opens in the side panel automatically.

## Security & side effects

- **MCP server**: registers a local stdio MCP server `archify` that provides the diagram rendering tools
- **File writes**: rendered artifacts are written to the workspace `.archify-panel/` (exports go to `exports/`)
- **Browser use**: the render pipeline launches the local browser for a measurement step; data stays on the machine
- **Network access**: none. Rendering is fully local; the plugin calls no external services
- **Telemetry**: none

## Build from source

Plugin source lives in `ui-plugins/archify-panel/` in this repository; the install directory contents (`dist/` and `vendor/`) are generated by the repository build:

```bash
pnpm install --frozen-lockfile
pnpm build
```

The build produces `dist/server.mjs` and `dist/ui/panel.html`; `vendor/` is copied into the install directory by the stage script.

Tests (after building):

```bash
node ui-plugins/archify-panel/test/smoke.mjs /tmp/archify-smoke     # server: render and read artifacts
node ui-plugins/archify-panel/test/panel-run.mjs                   # panel: export bridge end to end
```

### Local development (inline loading)

To develop without the marketplace, load the plugin directory directly via `plugins.dirs` in `~/.zcode/cli/config.json`:

```json
{ "plugins": { "dirs": ["/absolute/path/to/archify-panel"] } }
```

- **Use an absolute path.** The desktop app expands `~/`, CLI tools do not.
- **Each `plugins.dirs` entry is a plugin root** (containing `.zcode-plugin/plugin.json` directly), not a parent directory of several plugins.
- **Do not install this plugin from a marketplace at the same time.** The host deduplicates by `name@marketplace`; `archify-panel@inline` and `archify-panel@<marketplace>` are separate keys and both would load — two MCP processes, duplicate panel registrations and skills.

## Structure

```text
.zcode-plugin/plugin.json     manifest: MCP server + side panel declaration
skills/archify-panel/SKILL.md skill: how the agent renders and drives the panel
dist/                         build output: MCP server and panel frontend
vendor/archify/               bundled Archify runtime (Apache-2.0)
assets/icon.png               plugin icon
```

Source (`src/`, `test/` and build scripts) lives in `ui-plugins/archify-panel/` in this repository.

## How it works

The agent calls `render_diagram`; the server runs Archify's `finalize` pipeline (validation, delivery, static checks, browser measurement) and writes the artifact to the workspace `.archify-panel/`, registering it as the current diagram. The side panel reads the artifact HTML via an MCP resource and embeds it in full-interaction mode inside an inner iframe `srcdoc`; the shell renders no toolbar of its own, only a bottom status bar.

Exports go through the diagram's own "Export" menu. Sandboxed iframes block native downloads, so the panel keeps a permanent export bridge: it intercepts the binary export output, saves it to `.archify-panel/exports/` via `save_export`, and asks the host to open a save dialog.
