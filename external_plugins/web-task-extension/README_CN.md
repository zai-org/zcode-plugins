# 网页操作转浏览器扩展

把你在浏览器里反复做的事变成一个 **Chrome / Edge 扩展**，点一下就自动跑完。描述一下流程，Agent 把它写成步骤，本插件生成 **Manifest V3** 扩展，**只申请必要权限并逐项说明用途**，自动校验后打包。

## 功能

- **步骤**：
  - `open` 打开网址；`click` 点击（按选择器，可再按文字筛选）；`fill` 填写文本 / 下拉框 / 复选框（可提交表单）；`wait` 等待元素出现、消失或固定时长。
  - `extract` 每个元素提取一条记录，字段可写成 `".price"`、`"a@href"`、`"@data-id"`，可沿“下一页”最多翻 N 页。
  - `download` 把提取的数据存成 **CSV**（UTF-8 带 BOM，防表格公式注入）或 **JSON**，或下载链接指向的文件。
  - **设置项**由用户在设置页填写（文本、数字、日期、下拉），步骤里写 `{{key}}` 引用；另有内置的 `{{today}}`、`{{now}}`。步骤可设为可选，可单独设超时和备注。
- **生成** `extensions/<名称>/`：
  - 弹窗：**运行任务**按钮、实时步骤进度、结果预览、重新下载 CSV / JSON。
  - 设置页：设置项、步骤列表、权限说明表。
  - 用 `chrome.scripting` 在标签页里执行步骤的 Service Worker；自动生成的图标；中英文界面（`_locales`）；`PERMISSIONS.md`；附加载说明的 `README.md`。
  - 可直接上传商店的 zip：`extensions/<名称>-<版本>.zip`。
- **最小权限**：
  - 固定只有 `storage`、`scripting`。
  - 有下载步骤才加 `downloads`。
  - 网站权限只包含步骤打开的网站和你额外列出的网站；没有“打开”步骤时改用 `activeTab`，不申请任何网站权限。
  - 从不申请 `tabs`、`<all_urls>`、cookies、history、webRequest，也没有常驻内容脚本。每项权限都用中英文通俗说明。
- **校验**：
  - Manifest：V3；名称、描述、版本号规则；引用的文件都存在；图标是对应尺寸的 PNG。
  - 权限：都是已知权限、最小化，且与步骤完全对应；网站匹配模式合法，并覆盖每个打开的网址。
  - 代码：没有内联或远程脚本、内联事件、`javascript:` 链接（MV3 CSP）；所有脚本语法正确；不用 `eval`。
  - 多语言文案齐全；任务前后一致：占位符都有定义，下载在提取之后，占位符不能改变网站。
  - 手动改过文件后用 `ext_check` 重新校验。

## 使用

在 ZCode Desktop 里对 Agent 说：

- “我每天早上在供应商门户搜刹车配件，把有货的抄进表格，帮我做成扩展”
- “做一个把这个页面表格存成 CSV 的扩展”
- “再加一步，把规格单也下载下来”

然后打开 `chrome://extensions`，开启**开发者模式**，点**加载已解压的扩展程序**并选择文件夹，固定图标后点**运行任务**。面板里能看到步骤、权限、弹窗预览和校验结果；点**编辑步骤**（JSON）可以修改，修改后会重新生成并升级版本号。

## 工具

| 工具 | 用途 |
|---|---|
| `ext_new` | 按步骤和设置项新建扩展：生成、校验、打包 |
| `ext_update` | 修改步骤 / 设置 / 网站 / 名称，重新生成并升级版本号 |
| `ext_check` | 按磁盘上的现状重新校验，没问题就重新打包 |
| `ext_list` | 列出已生成的扩展 |

## 范围（v0.1）

- 支持 Chrome / Edge（Manifest V3，Chrome 110+），暂不支持 Firefox。
- 不自动登录：请先自己登录网站再运行。不要把密码写进设置项（插件会提醒）。
- 不处理：屏蔽自动化的网站、验证码、跨站 iframe、Shadow DOM 选择器。
- 发布到 Chrome 应用商店由你自己决定（zip 已备好）。
- 需要点“运行任务”才执行，不含定时运行。

## 隐私、网络与文件

- 插件本身在本地运行，不联网，不需要 API Key。会写入 `extensions/<名称>/`、zip 和 `.web-task-extension/extensions.json`。
- 生成的扩展不向任何地方发送数据。只在你点“运行任务”时操作列出的网站，设置和结果保存在浏览器里。
