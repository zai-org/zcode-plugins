# MCP Bids

Поиск публичных федеральных закупок США и публикаций TED с чтением документов и ссылками на источники.

## Подключение

Войдите в https://mcpbids.com/account и создайте личный API-ключ. Задайте переменную `MCPBIDS_API_KEY` в окружении запуска приложения и полностью перезапустите его. Не отправляйте ключ в чат, репозиторий, историю команд или снимки экрана. У RU и международного сервиса разные аккаунты и ключи.

ZCode: Node.js 22+, Settings → Plugins → Create → Add marketplace → `https://github.com/pixelligue/mcpbids-plugins`, затем установите `mcpbids`. Локальный `stdio.mjs` наследует переменную и передаёт MCP-запросы на `https://mcpbids.com/mcp`.

Kimi Code: `/plugins install https://github.com/pixelligue/mcpbids-plugins`, затем `/reload`. Kimi Work: импортируйте репозиторий через Plugin Builder; поддержку `bearerTokenEnvVar` в Work нужно проверить отдельно. Работоспособность в Code не доказывает совместимость облачного каталога.

DeepSeek Harness 0.2.1-rc.2: в Desktop установите Git-источник или архив релиза через менеджер плагинов приложения. Для `dsh web`: `dsh plugin --profile web add git+https://github.com/pixelligue/mcpbids-plugins.git#v1.0.0`, затем перезапустите профиль. Плагин подключает официальный MCP-клиент; отдельный skill для DSH не регистрируется.

## Использование и ограничения

Попросите агента проверить `list_sources`, найти несколько закупок, открыть найденную карточку и прочитать доступный документ с точными ссылками на блоки. Инструкция `procurement-research` включена для Kimi/ZCode. Поиск работает по собранному индексу; полнота и актуальность всего рынка не гарантируются. Источники и состояние документов необходимо проверять. Сбор свежих данных и наблюдения запускаются только по запросу пользователя. Наблюдения требуют опроса, рассылки и push нет. Подачи заявок, подписания и подтверждения юридической пригодности нет.

## Доступ и данные

Чтение требует `tenders:read` и `documents:read`; сбор и наблюдения требуют `tenders:collect` и `watches:write`. Ключи кабинета наследуют права сервиса; ограничивайте вызовы инструментов настройками подтверждения в приложении. Действуют права и лимиты аккаунта. Используется персональный bearer-ключ; OAuth здесь не заявлен.

Адаптер отправляет ключ и запросы только на `https://mcpbids.com/mcp`, запрещает перенаправления, не читает файлы учётных данных, не запускает shell или модель, не устанавливает зависимости и не собирает данные в фоне. Аргументы и результаты видны агенту и провайдеру его модели. По запросу операции могут создавать задания и личные наблюдения на сервере. Оригиналы скачиваются по запросу. Документы считаются недоверенными источниками. Телеметрия адаптером не добавляется.

Локальный stdio-адаптер рассчитан на stateless JSON: запрос до 64 КиБ, ответ до 16 МиБ, ожидание до 120 секунд; общий SSE/sessionful MCP не поддерживается.
