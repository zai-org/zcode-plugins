# 批量重命名

按规则批量重命名整个文件夹：查找替换或正则、带序号/日期/文件夹名的命名模板、大小写和空格整理、扩展名统一小写，也可逐个手动指定新名。改名前就能看到每个文件的“原名 → 新名”和所有冲突，安全执行（互换名字、只改大小写也没问题），留下改名记录，还能撤销上一次改名。在本地运行，无需 API 密钥。

## 功能

- **规则**：查找替换（普通文本或正则，可用 $1）、命名模板 {name} {n} {date} {parent} {ext}、起始序号和位数，按文件名或修改时间编号。
- **整理**：全小写/全大写/首字母大写，空格改成 - 或 _ 或去掉，合并连续空格，扩展名统一小写，非法字符（\ / : * ? " < > |）自动替换。
- **手动改名**：在表格里给任意文件填新名字，不写扩展名就保留原扩展名。
- **安全**：新名字重复、和其他文件撞名、正则写错都会报错并阻止改名；改名分两步，互换名字和只改大小写都能正确处理，中途出错会自动还原。
- **撤销**：上一次改名有记录，可用“撤销上次改名”按钮还原（“全部导出”不会触发撤销）。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `batch-file-renamer/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “把 相册/ 里的照片按时间顺序改成 杭州-001.jpg、杭州-002.jpg……”
- “扫描件/ 里把“scan_”换成“合同-”，扩展名统一小写”
- “撤销刚才的改名”

## 工具

| 工具 | 作用 |
|---|---|
| `rename_open` | 列出工作区文件夹里的文件并预览新文件名，并打开面板 |
| `rename_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `rename_status` | 查看当前数据、问题和汇总 |
| `rename_export` | 导出改名清单 rename-plan.csv、实际改名（附 rename-log-*.csv），或撤销上次改名 |

导出文件写到工作区的 `batch-file-renamer/<项目>/` 文件夹。

## 范围（v0.1）

- 只改文件名、不改文件夹名，范围限于工作区；隐藏文件会跳过。
- 每个项目最多 5 个文件夹、5,000 个文件；子文件夹可选。
- 按照片 EXIF 拍摄日期命名请用另一个插件（照片按日期整理）。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `batch-file-renamer/` 文件夹；另外只有在你点“执行改名”（或“撤销上次改名”）时，才会重命名你所选文件夹里的文件。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/batch-file-renamer/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-batch-file-renamer test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
