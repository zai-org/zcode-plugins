# 帮助中心制作

把一个放 **Markdown / HTML** 文档的文件夹生成 **静态帮助中心**：分类导航、面包屑、相关文章，以及离线可用的即时 **全文搜索**。改了文档后，**增量构建** 只重写受影响的页面，并告诉你原因。

## 功能

- **读取文档**：
  - 子文件夹就是分类；放在根目录的文件归入“常规”。
  - 支持 front matter：`title`、`description`、`order`、`tags`、`related`、`updated`、`category`、`draft`。没写标题时，用开头的 `#` / `##` / setext 标题。
  - 文件夹里的 `index.md` 作为该分类的介绍；根目录的 `index.md` 作为首页介绍。
  - 支持 HTML 文件（例如从 CMS 导出的）：读取标题、meta 描述和标签，去掉导航、脚本和内联事件。
- **可选的 `help-center.json`**（放在文档目录里）：`title`、`description`、主题色 `accent`、`logo`、`footer`、`baseUrl`、`lang`，以及分类名称、说明和顺序。
- **生成** `help-center/`：
  - 首页：搜索大框加分类卡片；分类页：文章列表。
  - 文章页：面包屑、侧边栏（本分类文章加全部分类）、“本页内容”目录、相关文章（先用你写的 `related`，再按共同标签和相近标题补足）、上一篇 / 下一篇。
  - 搜索页和 404 页；设置了 `baseUrl` 时生成 `sitemap.xml` 和 canonical 链接。
  - 响应式布局，支持浅色 / 深色主题；界面中英文自动识别。
  - 图片等文件原样复制，`.md` 链接改写成 `.html`。
- **搜索**：构建时用 [MiniSearch](https://github.com/lucaong/minisearch) 生成索引，以脚本形式随站点发布。
  - 任何静态托管都能用，直接双击打开（`file://`）也能用，不需要服务器或外部服务。
  - 支持前缀和模糊匹配；标题、标签、小标题权重更高；中日韩文字按单字和双字切分。
  - 输入时实时下拉，可用键盘选择（按 `/` 聚焦搜索框）；另有搜索结果页。
- **增量构建**：
  - 每个页面记录它依赖的内容：正文、同分类文章列表、分类列表、相关文章、上一篇 / 下一篇、站点设置、模板。
  - 只重写依赖有变化的页面，并逐页列出原因（例如“相关文章变了”）。删掉的文章会被移除，改过的图片会重新复制。
  - 点“全量重建”可重写全部页面。
- **检查**：指向文章或文件的坏链、失效的 `#锚点`、指向文档目录外的链接、两个文件生成同一个页面、缺失或重复的标题、空文章、无效的 `related`、草稿。

## 使用

在 ZCode Desktop 里对 Agent 说：

- “用 docs 文件夹生成帮助中心”
- “我改了几篇文章，更新一下帮助中心”
- “检查帮助文档里有没有坏链”

也可以用面板：选择文档目录 → **生成帮助中心**；以后改了文档点 **增量构建**。面板里能浏览站点结构、预览任意页面，并查看哪些页面被重写及原因。用浏览器打开 `help-center/index.html`，或把整个文件夹上传到静态托管（Cloudflare Pages、Netlify、GitHub Pages、S3 等）。

## 工具

| 工具 | 用途 |
|---|---|
| `hc_scan` | 查看文档目录的分类、文章和问题（不写文件） |
| `hc_build` | 生成或更新站点（默认增量，`full` 为全量重建） |

## 范围（v0.1）

- 托管由你决定：输出是普通的静态文件夹，部署（例如到 Cloudflare Pages）是另外一步。
- 不含“是否有帮助”反馈、统计、评论、需要登录的文章（这些需要后端）。
- 一个站点一种语言；代码块不做语法高亮；不执行 MDX、Liquid 等模板语法。

## 隐私、网络与文件

- 在本地运行，不联网，不需要 API Key。生成的站点不从其他服务器加载任何东西。
- 读取文档目录；写入输出目录和 `.help-center/builds.json`；只删除自己以前生成的页面。
