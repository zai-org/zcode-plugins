# 排课表

把每个班需要的课——科目、任课教师、每周课时、共用场地、固定时段、连堂——排成不冲突的班级课表和教师课表。教师限制（周三下午教研、周一前两节不排……）和场地容量（操场可同时上两个班、机房一个班）可以写在附加工作表或设置里。排课时班级、教师、场地都不会重复占用，固定课（如 班会 周五7）不动，连堂排在一起，同一科目尽量分散到一周各天，主科尽量排上午，避免某位老师一天课太满；排不下时会说明原因。改教师、课时或固定时段后课表自动重排。导出含总表、每班和每位教师课表的 Excel，以及按科目着色、横版可打印张贴的 PDF。不用登录，无需 API 密钥，本机运行。

## 功能

- **课程需求表**：班级、科目、教师、课时、场地、固定时段、连堂；教师限制和场地容量表。
- **不冲突**：班级、教师、场地不重复；遵守固定时段和限制。
- **分布合理**：科目分散到各天，主科排上午，教师每天课量均衡。
- **检查**：排不下的课及原因、冲突的固定课、超负荷的教师和班级、无法识别的时段。
- **导出**：总表 + 每班 + 每位教师的 Excel，按科目着色的 PDF。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `timetable-builder/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 排课/课程需求.xlsx 排课”
- “把冲突的固定课改掉”
- “导出班级和教师课表”

## 工具

| 工具 | 作用 |
|---|---|
| `timetable_open` | 读取课程需求并排课，并打开面板 |
| `timetable_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `timetable_status` | 查看当前数据、问题和汇总 |
| `timetable_export` | 导出 timetables.xlsx 和 timetables.pdf |

导出文件写到工作区的 `timetable-builder/<项目>/` 文件夹。

## 范围（v0.1）

- 适合一个年级或一所学校的快速排课，不是全区级别的优化求解器。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `timetable-builder/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/timetable-builder/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-timetable-builder test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
