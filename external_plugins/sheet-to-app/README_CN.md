# 表格转小应用

把**库存、预约、客户等表格**（.xlsx / .csv / .tsv）变成一个小网页应用：**只有一个 HTML 文件**，双击就能打开，能搜索、筛选、用表单增删改。不需要服务器，不用注册账号，也不联网。

## 功能

- **字段映射**：读取表头和数据，自动判断每一列的类型：文本、长文本、数字、金额、日期、邮箱、电话、链接、选项、是/否。同时判断哪些列必填、选项列有哪些选项、哪一列是唯一编号（SKU、ID、编号…）、哪一列是记录标题。所有判断都可以在面板里改，也可以直接让助手改。
- **数据问题**：列出必填却为空、类型不对（数字列里写了“十”、邮箱或日期格式不对）、不在选项里、编号重复的行，并标出表格行号。这些行仍会导入，在应用里标红显示。
- **生成的应用**（`apps/<id>/index.html`）：
  - 在文本类列里搜索；每个选项列、是/否列都有筛选；点表头排序；分页显示。
  - 用表单新增、修改、删除记录，带校验（必填、数字、日期、邮箱、链接、编号不能重复）。
  - 可选的高亮规则，例如“库存 ≤ 5 → 库存不足”。
  - 导出 CSV（用 Excel 打开中文不乱码）、导入 CSV（追加或替换）、JSON 备份与恢复。
  - 界面可选中文或英文，可设置主题色。
  - 数据保存在打开这个文件的浏览器里（localStorage）。
- **表格更新后**：`app_refresh` 重新读取表格，保留你的字段设置，新增的列自动加上，删掉的列自动去掉，然后重新生成。已经用过这个应用的人会看到提示条，可以选择载入新数据；在他们选择之前，自己做的修改都会保留。

## 使用

在 ZCode Desktop 里对助手说：

- “把库存表.xlsx 做成一个能查询、能修改的小应用”
- “用这个预约表 CSV 生成一个预约管理页面”
- “表格更新了，重新生成应用，保留我的设置”

也可以用面板：选择表格，点 **生成应用**，调整字段类型、显示名和高亮规则，再点 **应用修改并重新生成**。右侧是静态预览。

## 工具

| 工具 | 作用 |
|---|---|
| `app_new` | 读取表格、推断字段映射、生成应用并列出数据问题 |
| `app_update` | 修改字段（类型、显示名、必填、选项、列表/筛选/隐藏、编号列、标题列）和设置（标题、语言、颜色、每页行数、排序、高亮），然后重新生成 |
| `app_refresh` | 表格改了以后重新读取，保留设置并重新生成 |
| `app_check` | 只检查数据问题，不重新生成 |
| `app_list` | 列出这个工作区里的应用 |

## 范围（v0.1）

- 一个应用对应一张工作表，第一行是表头，最多 20,000 行。
- 数据只保存在一台电脑的一个浏览器里，多人之间不同步。要换电脑，请用 **备份** 或 **导出 CSV**；以表格为准。
- 在应用里做的修改不会写回原表格；需要的话，导出 CSV 即可。
- 不包含托管。`apps/<id>/` 是普通静态网站，以后可以上传到 Cloudflare Pages 等静态托管，但数据仍然按浏览器各自保存。
- 公式按最近一次计算的结果读取。.xls 文件需要先另存为 .xlsx。

## 隐私、网络与文件

- 全部在本地运行，不联网，不需要 API Key。生成的应用也不加载任何网络资源。
- 读取表格，写入 `apps/<id>/index.html` 和 `.sheet-to-app/apps.json`（保存的字段映射）。原表格不会被改动。
