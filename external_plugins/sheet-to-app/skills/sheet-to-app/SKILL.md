# 表格转小应用

1. 找到表格（.xlsx / .csv / .tsv，第一行是表头）。工作簿有多张表时，问清楚用哪一张，用 `sheet` 参数指定。
2. 调用 `app_new({source, title?, lang?})`。它会推断字段类型、必填项、选项和编号列，写出 `apps/<id>/index.html`，并列出表格里的数据问题。
3. 向用户说明：识别出的字段（类型不对的要指出），以及数据问题（第几行、哪一列、什么问题）。问题行仍会导入并标红，用户可以在应用里改，也可以先改原表格。
4. 按用户的要求用 `app_update` 调整：字段类型、显示名、必填、选项、哪些列显示、筛选或隐藏，编号列、标题列，以及标题、语言、主题色、默认排序、高亮规则（例如 `{column:"库存", op:"<=", value:5, label:"库存不足"}`）。
5. 表格更新后，调用 `app_refresh({id})`，设置会保留，然后把新增和删除的列告诉用户。
6. 告诉用户：用浏览器打开 `apps/<id>/index.html` 就能用；数据保存在这个浏览器里，换电脑前请先“备份”或“导出 CSV”；应用里的修改不会写回原表格。以后要放到网上，可以把 `apps/<id>/` 文件夹上传到 Cloudflare Pages 等静态托管。
