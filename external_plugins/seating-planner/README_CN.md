# 座位编排

几秒钟排好考场、教室或宴会的座位。打开名单，选择“几排 × 每排几座”或圆桌；考试时同班同学不相邻，指定的人分开坐，好朋友坐一起，需要靠前的人排在前排，宴会可以按亲友或部门尽量同桌。输入座位即可固定，改随机种子重新排其余的人，排不下或冲突的规则都会列出来。导出可打印的座位表 PDF（附按姓名查座位的清单）和 Excel。在本地运行，不用登录，无需 API 密钥。

## 功能

- **两种布局**：几排 × 每排几座（R1C1 在前排最左，第 1 排离讲台最近），或圆桌（T1-1…）。
- **规则**：同组不相邻（考试）、“与谁分开”、“与谁一起”、前排座位、宴会按组同桌。
- **固定座位**：输入座位（R2C3、2-3、第2排第3列、3桌4号）即可固定，其他人围绕它重新安排。
- **可复现**：同样的名单和种子得到同样的结果，改种子即可重新打乱。
- **自动检查**：人数超过座位、座位不存在或被重复占用、无法满足的规则、规则里写了名单外的名字。
- **导出**：A4 横向座位图（标出讲台）、按姓名排序的座位查询页，以及含名单和座位图两张表的 Excel。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `seating-planner/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 students.csv 排一个 6 排 × 8 座的考场，同班不相邻”
- “把王子涵固定在 R6C8，其他人重新排”
- “改成 4 桌、每桌 10 人，同一家人尽量同桌”

## 工具

| 工具 | 作用 |
|---|---|
| `seats_open` | 读取名单并按规则分配座位，并打开面板 |
| `seats_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `seats_status` | 查看当前数据、问题和汇总 |
| `seats_export` | 导出 seating-chart.pdf 和 seating.xlsx |

导出文件写到工作区的 `seating-planner/<项目>/` 文件夹。

## 范围（v0.1）

- 按规则逐个安排座位；规则很紧时可能仍有冲突（会列出来）。
- v0.1 不支持拖拽，在表格里输入座位即可调整。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `seating-planner/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/seating-planner/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-seating-planner test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
