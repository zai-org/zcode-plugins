# 游戏音效素材包

按游戏事件清单制作音效，整理已有的声音，最后交付一套音量统一、分类清楚的素材包。

## 功能

- **合成音效**：
  - 每个事件（跳跃、金币、受击、爆炸、激光、升级、脚步、挥动、按钮点击、确认、错误……）按名字（中英文都可以）匹配一个预设，并归到一个分类文件夹（player、pickup、combat、ui……）。
  - 合成器沿用 sfxr 的思路、自己实现：振荡器（方波、锯齿、正弦、三角、噪声）、带冲击的包络、滑音、颤音、琶音、占空比扫动、滤波、重复。
  - 每个声音都有一个**种子**，可以复现；换种子就是换一个变体，也可以调音高、长度、滑音。
- **已有声音**：
  - 支持 WAV；MP3/OGG/FLAC/M4A 通过电脑上的 ffmpeg 读取。
  - 可以去掉首尾静音，也可以用等功率交叉淡化（结尾淡入开头）做成**无缝循环**。
- **统一响度**：所有声音调到同一个门限 RMS 目标（默认 -18 dBFS），峰值不超过 -1 dBFS；每个声音还可以单独设置相对音量。
- **导出**（到 `sfx/`）：
  - `分类/名字.wav`（16 位，22.05 / 44.1 / 48 kHz）和/或 `.ogg`（Vorbis，通过 ffmpeg）。
  - `manifest.json` / `manifest.csv`：事件、文件、时长、是否循环、响度、峰值，以及预设 + 种子或来源文件。
  - `名字.sfx.json`：工程文件，可以重新打开。
- **面板**：
  - 按分类列出所有声音，每个都可以试听，显示波形和实测响度。
  - 合成声音：切换预设、🎲 换变体、拖动滑块调音高 / 长度 / 滑音。
  - 已有声音：去静音、循环、交叉时长。
  - 每个声音都能改音量、删除。直接输入事件名就能新增。

## 使用

在 ZCode Desktop 中对 Agent 说：

- “给我的平台跳跃游戏做一套音效：跳跃、拾取金币、受伤、死亡、按钮点击、菜单确认”
- “把 rain.wav 做成无缝循环，音量和其他音效统一”
- “跳跃声再高一点、爆炸再长一点，然后也导出 OGG”

## 工具

| 工具 | 作用 |
|---|---|
| `sfx_open` | 从事件清单和/或已有声音（或工程）开始，打开面板 |
| `sfx_save` | 保存名字、分类、预设、种子、参数、去静音 / 循环、音量和设置 |
| `sfx_export` | 渲染全部声音，按分类导出 WAV/OGG 和清单 |

## 范围（v0.1）

- 输出单声道。合成部分是纯 JavaScript，不需要安装任何东西；只有读取非 WAV 文件或导出 OGG 时才需要 ffmpeg。
- 响度统一用门限 RMS（dBFS）而不是完整的 LUFS，对短音效来说更合适。
- 不包含 AI 生成音效。

## 隐私、网络与文件

- **全部在本地运行**：不联网、不上传，不需要 API 密钥或账号。
- 只读取你导入的声音，只写入工作区里的输出文件夹。
- ffmpeg（可选）以参数数组调用，不经过 shell。没有 hooks。

## 构建与测试（开发者）

- 源码位于 `ui-plugins/game-sfx-pack/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-game-sfx-pack test` 和 `test:e2e`。
- `E2E_SFX` 可以指向真实录音。我们用的是 Wikimedia Commons 上两段公有领域的雨声录音。
