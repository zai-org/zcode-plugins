# 客户名单整理

把好几份乱七八糟的客户表（CRM 导出、展会登记表、通讯录）合成一份干净、去重的名单，每一次合并都有记录。

## 功能

- **输入**：CSV、TSV、XLSX；中文 Excel 存的 GBK/GB18030 CSV 自动识别。每个文件的列映射到统一模板：姓名、电话、电话2、邮箱、邮箱2、公司、职位、城市、微信、备注。根据中英文表头（表头没用时看内容）自动猜映射；名/姓分列会拼起来。
- **规范化**：
  - 姓名：中文去掉中间空格，全大写/全小写的英文名改成首字母大写。
  - 电话：一格多个号码会拆开；用 libphonenumber 转成国际格式（`+86 138 1234 5678`、`+86 21 6234 5678`、`+44 20 7946 0958`），保留分机，无效号码标红；默认国家为中国（可改）。不可能是中国号码的 10 位号码按北美号码处理并提示。
  - 邮箱：转小写、去掉 `mailto:`，格式错误标红。公司：中文名用全角括号；比较时忽略“有限公司 / Inc. / LLC”等后缀。
- **查重**：
  - 确定重复自动合并：电话或邮箱相同且姓名相容，或电话和邮箱都相同。
  - 可能重复左右对照（不同的值高亮）交给你确认：电话相同但姓名不同（共用座机？）、同名同公司、同名且号码后 8 位相同、同名且邮箱用户名相同。
- **合并规则**：按文件顺序取第一个非空值；多出的电话/邮箱放到电话2/邮箱2；公司取更完整的全称；其他冲突写进备注和合并日志。
- **导出**：Excel 四个工作表（联系人、合并日志、问题、待确认），或 CSV（联系人 + 合并日志，UTF-8 带 BOM）。
- **面板**：选文件、看统计、逐对确认、改字段映射、浏览搜索结果（无效值标红）、看合并日志、导出。

## 使用

在 ZCode Desktop 里对助手说：

- “把 CRM 导出和展会登记表合成一份干净的客户名单”
- “找出这三个表里重复的客户”
- “把整理好的名单导出 Excel，附上合并日志”

## 工具

| 工具 | 用途 |
|---|---|
| `contacts_load` | 读名单、映射字段、规范化、自动合并确定重复、列出可能重复 |
| `contacts_map` | 修改某个文件的字段映射 |
| `contacts_decide` | 可能重复：合并或保留两条 |
| `contacts_export` | 导出整理后的名单（xlsx / csv，附合并日志；或 vCard .vcf，可导入手机和邮箱通讯录） |

## 范围（v0.1）

- 不联网查重或补全信息；不支持 vCard/Outlook 格式（先导出为 CSV）。
- 面板里不能撤销自动合并；可修改原始行或映射后重新整理。
- .xls 需先另存为 .xlsx。

## 隐私、网络与文件

- 本地运行：不联网，无需 API 密钥；不修改原始文件。
- 写入 `.contact-cleaner/project.json`（文件、映射、确认结果）和导出文件夹（默认 `cleaned/`）。没有 hooks。

## 构建与测试（开发者）

- 源码：`ui-plugins/contact-list-cleaner/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-contact-list-cleaner test`。`CONTACT_SAMPLES` 指向虚构的样例名单。`test:e2e` 需要 Chrome。
