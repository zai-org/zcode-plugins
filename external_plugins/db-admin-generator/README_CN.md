# 数据库转管理后台

把 **SQLite 数据库**变成能直接用的**管理后台**：有登录和角色，每张表一个列表（支持搜索和筛选），新增、修改、删除表单都遵守数据库的规则。生成的后台**没有第三方依赖**，只需要 Node.js 22.13 以上。交给你之前，插件会先用数据库的**临时副本**把它**真正启动并自测**一遍。

## 功能

- **读取表结构**（只读）：
  - 表和视图、主键（或 rowid）、外键、`CHECK (col IN (…))` 的选项。
  - 必填列（NOT NULL 且没有默认值）、唯一列、`VARCHAR(n)` 的长度。
  - 布尔、日期和时间、邮箱、电话、链接列，以及表之间的引用关系。
- **规划**：
  - 勾选要管理的表，以及每张表允许的操作（查 / 增 / 改 / 删）。
  - 设置每个角色能做什么：**admin** 拥有全部权限，**editor** 默认可以查、增、改，**viewer** 只能查看。
  - 选择其他表引用这一行时显示哪一列。
  - 名字像密码、哈希、令牌的列默认隐藏，永远不会发到浏览器；迁移记录表默认不纳入。
- **生成** `<数据库名>-admin/`：
  - `server.mjs`：基于 `node:http` + `node:sqlite`，提供：
    - 登录：密码用 scrypt 加盐哈希，会话 Cookie 带 HMAC 签名，并设置 HttpOnly 和 SameSite=Strict。
    - 安全：权限在服务器端检查；SQL 全部参数化，表名和列名只来自表结构；有防 CSRF 的请求头检查；连续输错 5 次密码会锁定。
    - 唯一、外键、CHECK 冲突给出易懂的提示；每次修改都写入 `audit.log`。
  - `public/`：网页界面，没有内联脚本，使用严格 CSP：
    - 侧边栏列出各表；列表支持搜索、筛选（选项、是/否、引用）、排序和分页；引用列显示被引用记录的名称。
    - 每行一个表单：引用和选项用下拉框，日期用日期选择器，布尔用复选框；标出必填项和长度上限；服务器返回的错误显示在对应字段下面。
    - viewer 角色和视图是只读的；界面可选中文或英文。
  - `admin.config.json`（可以手动修改）、`README.md`、`package.json`、`.gitignore`。
  - 用户命令：`node server.mjs user add <名字> <角色>`、`user passwd`、`user list`、`user remove`。
- **自测**：用数据库的**临时副本**，在空闲端口上启动后台，通过 HTTP 检查（示例店铺数据库约 90 项）：
  - 每种角色都能登录，错误密码被拒绝。
  - 每张表都能列出（行数一致），搜索、排序正常，SQL 注入尝试无效。
  - 必填项和类型错误会被拦下；新增 → 读取 → 修改 → 删除都能完成。
  - 唯一值重复返回 409；删除仍被引用的记录也返回 409。
  - viewer 和 editor 的权限限制生效，修改写入了审计日志。

## 使用

在 ZCode Desktop 里对助手说：

- “给 data/shop.db 生成一个管理后台”
- “做一个只读后台，只看客户表和订单表”
- “重新自测生成的管理后台”

也可以用面板：选择数据库，点 **读取结构**，调整表、操作和角色，然后点 **生成管理后台并自测**。生成后这样运行：

```bash
cd shop-admin
node server.mjs      # http://127.0.0.1:8787，第一次启动会创建 admin 用户并打印密码
```

## 工具

| 工具 | 作用 |
|---|---|
| `db_inspect` | 读取表结构并给出建议方案（不写任何文件） |
| `db_generate` | 生成管理后台目录，然后自测 |
| `db_selftest` | 重新自测，例如手动改过生成的代码之后 |

## 范围（v0.1）

- **只支持 SQLite。** 暂不支持 Postgres 和 MySQL（Postgres 版本需要有数据库可以实际测试）。
- 单列外键会显示为下拉框；复合外键按普通值显示。
- 不改表结构，不做迁移，不支持文件上传和 BLOB 编辑，也没有行级权限。
- 试用时请用数据库的测试副本。插件本身从不写数据库；但生成的后台运行之后会写。
- 默认只监听 127.0.0.1。要在网络上共享，请先放到 HTTPS 后面。

## 隐私、网络与文件

- 全部在本地运行，不联网，不需要 API Key。自测只访问 127.0.0.1。
- 以只读方式读取数据库，写入 `<输出目录>/` 和 `.db-admin-generator/plans.json`。自测用的临时副本、测试用户和密码用完即删。
- ZCode 里运行插件和运行生成的后台，都需要 Node.js 22.13 或更新版本（`node:sqlite`）。
