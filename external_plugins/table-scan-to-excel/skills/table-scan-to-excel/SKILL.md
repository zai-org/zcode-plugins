# 扫描表格转 Excel

识别由你（Agent）看图完成；插件负责核对、让用户确认和导出。插件不联网。

1. **打开**：`table_scan_open(image)`（PNG/JPG）。结果里有图片和转写规则；如果这张图以前识别过，会直接返回已保存的结果，不要重复识别，除非用户要求。
2. **转写并提交**：`table_submit(image, tables)`，每个表格：
   - `rows`：从上到下、从左到右照抄（保留千分位、%、货币符号、括号、负号），**不要计算、不要更正、不要补数**；每行格子数相同。
   - 合并单元格：文字写在左上格，被覆盖的格子写 `""`，并在 `merges` 里写 `{row, col, rowSpan, colSpan}`（从 0 开始）。
   - `headerRows`：表头行数。`uncertain`：所有没把握的格子 `[行, 列]`（模糊、手写、被遮挡、易混的数字）。`bounds`：表格在原图中的像素范围（可选）。
   - 图片很大或很密时，可以分块仔细看，但最终一次提交完整的表。
3. **处理核对结果**：插件返回小计/合计不符、数字列里的文字、行格数不一致和存疑格子。你能看清的就重新看图并再次 `table_submit`；合计不符时**不要擅自改数字让它对上**——原单据本身可能就是错的，告诉用户差额，让用户在面板里确认或修改。
4. **导出**：用户核对完（或直接要求导出）后 `table_export(image, format?: "xlsx" | "csv" | "both", output?)`。默认 `tables/<图片名>.xlsx`。告诉用户文件位置和仍存疑的格子数（这些格子在 Excel 里有底色和批注）。
5. 多张图片：逐张 `table_scan_open` → `table_submit` → `table_export`。
