# 扫描表格转 Excel

把表格照片或扫描件（采购单、发票明细、对账单、纸质登记表）变成可以放心使用的 Excel。识别由 ZCode 的 Agent 看图完成；插件负责**核对**和**导出**：合计对不上、看不清的格子都会被标出来，你在原图旁边逐格确认后再导出。

## 功能

- **看图识别**：`table_scan_open` 把图片（自动缩到 2000 像素以内）交给 Agent，并附上转写规则：照抄、不计算、合并单元格怎么写、没把握的格子要标出来。一张图里可以有多个表格，每个表格导出为一个工作表。
- **自动核对**：
  - 每个“小计”行与它上面一段明细之和比对，“合计 / 总计 / Total”行与全部明细之和比对（跳过小计），差额写清楚；
  - 数字列里混入的文字（比如把 10 认成 l0）；
  - 行的格子数不一致（漏列或错位）；
  - Agent 标为“没把握”的格子。
  - 数字识别支持千分位、全角数字、括号负数、负号、百分号、¥/$/€ 和“元”。
- **核对面板**：左边原图（可放大，选中的格子在原图上用橙框大致标出），右边可编辑表格（保留合并单元格和表头），存疑格子黄色、合计不符红色。点问题列表跳到对应格子，“确认无误”或直接改；也可以一键让 Agent 再看一次。修改自动视为已确认，可保存，Agent 重新提交时保留你确认过且没变的格子。
- **导出**：
  - `.xlsx`：每个表格一个工作表；表头加粗、冻结；合并单元格保留；数字存为真正的数值并保留原来的千分位、小数位、百分比格式；仍存疑的格子黄色、合计不符红色，并带批注说明。
  - `.csv`：UTF-8（带 BOM，Excel 直接打开不乱码），每个表格一个文件。
- 识别结果保存在 `tables/<图片名>.tablescan.json`，下次打开同一张图直接载入，不用重新识别。

## 使用

在 ZCode Desktop 中对 Agent 说：

- “把这张采购单照片（采购单.jpg）转成 Excel”
- “看看 对账单.png 里的合计对不对，然后导出 xlsx”
- “把 scans 文件夹里的表格扫描件都转成 CSV”

也可以在会话侧栏打开“扫描表格转 Excel”，选一张图，点“让 Agent 识别”。

## 工具

| 工具 | 作用 |
|---|---|
| `table_scan_open` | 打开图片，返回给 Agent 看并打开面板；已识别过则载入结果 |
| `table_submit` | Agent 提交识别结果；核对并保存，显示在面板里 |
| `table_export` | 导出 `.xlsx` 和/或 `.csv`（默认 `tables/<图片名>.xlsx`） |

## 范围（v0.1）

- 支持 PNG、JPG。PDF 扫描件、HEIC 照片请先转成图片。
- 识别质量取决于 Agent 所用模型的看图能力；插件不自带 OCR 引擎，也不会把图片发到其他地方。
- 原图上的橙框按表格范围等分行列估算，表头特别高或照片倾斜时只是大致位置。
- v0.1 不包含：自动纠偏/裁边、公式还原、在面板里增删行列（可让 Agent 重新提交）。

## 隐私、网络与文件写入

- 插件本身**不联网**、不需要 API 密钥或账号。图片会作为工具结果交给你在 ZCode 中使用的模型（和你直接把图片发给 Agent 一样）。
- 只读取你指定的图片；只在工作区的 `tables/`（或你指定的导出路径）里写文件。不执行命令，没有 hooks。

## 构建与测试（开发者）

源码在 `ui-plugins/table-scan-to-excel/`。在仓库根目录运行 `pnpm install --frozen-lockfile && pnpm build`，把 `dist/local-marketplace` 添加为 ZCode 插件商店的本地来源后安装。测试：`pnpm --filter @penova/plugin-table-scan-to-excel test`（数字解析、小计/合计核对、补齐行、工具输入校验、导出 xlsx/csv 内容）和 `test:e2e`（浏览器面板测试：照片采购单的核对、确认、改错、导出，以及一张 1912 年人口普查扫描件）。
