# GetMyData

让你的 AI 助手把公开网页数据取回来，交付为 JSON。先免费抽样预览，再一次性固定报价。无需注册，无订阅。

GetMyData 按需求从公开网站采集记录，交付两份文件：原始 JSON 记录，以及 `fields.json` 字段说明（哪些请求字段被找到、路径与类型）。只有在记录本身是扁平结构时，才附带 CSV 和 Excel。

## 它是怎么工作的

1. 你说清要什么：公开来源、需要的列、筛选条件、地区、行数、截止时间和用途。
2. GetMyData 先从这些来源取一份有上限的免费样本，让你在付钱之前就看到字段和行。
3. 样本符合预期后，按行数给一个固定报价。你决定购买时，通过私密链接一次性付款。
4. 采集异步执行，交付结果发到已验证的邮箱；助手也可以把结果取回工作区。

适合：一次性的商品与价格对比、公开企业名录（只取企业信息，绝不取个人联系方式）、活动日历、图书目录、开放数据项目。

不适合：按时间表重复监控、预付余额，以及任何需要私有、需登录或非公开数据的场景。不要把密码、Cookie 或会话令牌交给服务。字段是否可得由免费样本决定，不以上面的例子为依据。

## 如何触发

安装并启用插件后，在日常对话里直接提需求，例如：

- 「把这三家茶叶店的公开价目表采集下来，存成 JSON，500 行，尽力而为就行。」
- 「把这个展会的公开参展商名录取回来，要公司名、国家、展位号。」
- 「我需要这家出版社的公开图书目录：书名、ISBN、版次、价格。」

助手会收齐必填信息、确认你的邮箱，并请你粘贴刚收到的一次性验证码。你粘贴后，样本会展示并邮件通知，随后是报价，然后由你决定是否付款。

## 网络、依赖与副作用

- 网络：仅访问 `https://getmydata.io`（`/mcp`、`/api/v1/...`、`/skills/getmydata/SKILL.md`），全部为 HTTPS。
- 依赖：无。没有本地进程、没有 npm 包、没有需要安装的运行时；MCP 服务在远端。
- 凭证：不需要 API Key，不需要注册。会话由服务下发（`Mcp-Session-Id`），有效期 7 天，可续期至 30 天上限。
- 文件：插件本身不写任何文件；助手取回的交付物保存在你的客户端默认目录。
- 副作用：提交请求会立刻在服务端开始抽样；采集与付款只在你确认报价之后发生。样本、报价链接和交付结果都会发到已验证邮箱。
- 费用：按确认的行数以固定价格一次性付款，通过私密链接完成。提交请求本身不产生任何费用。
