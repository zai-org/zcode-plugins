# 发货单拣货单

把从店铺后台导出的订单表变成可以打印的发货单和一张拣货单。订单号相同的行合成一张发货单：收件人、打码后的电话、地址、配送方式、每件商品的勾选框、礼品留言框，以及可以扫描的订单号条码。拣货单把所有订单的同一商品汇总，并按库位排序，走一趟货架就能拣完。还会提示缺少地址、数量不对、同一订单信息不一致。导出发货单 PDF 和拣货单 Excel。在本地运行，不用登录店铺后台，无需 API 密钥。

## 功能

- **直接用店铺导出表**：自动识别中英文列名；没有订单号的续行归到上一个订单。
- **一单一张**：收件人、打码电话（138****5678，可关闭）、地址、配送方式、带勾选框的商品明细（库位、数量）、备注和礼品留言框。
- **订单条码**：订单号的 Code 128 条码，打包台扫码核对。
- **拣货单**：所有订单的同一商品和规格汇总，按库位排序，并列出对应订单号。
- **自动检查**：缺少收件人或地址、数量不是正整数、同一订单地址不一致、重复商品（已合并）、礼品留言过长。
- **纸张**：A4 或 A5；可选显示金额；店铺名、退货地址和感谢语。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `packing-slip-maker/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 orders.csv 生成发货单”
- “改成 A5 纸并显示金额”
- “给我按库位排好的拣货单”

## 工具

| 工具 | 作用 |
|---|---|
| `slips_open` | 读取订单并按订单号分组，并打开面板 |
| `slips_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `slips_status` | 查看当前数据、问题和汇总 |
| `slips_export` | 导出 packing-slips.pdf 和 picking-list.xlsx/.csv |

导出文件写到工作区的 `packing-slip-maker/<项目>/` 文件夹。

## 范围（v0.1）

- v0.1 不生成快递面单，请使用快递公司的系统。
- 订单号含中文时不打印条码（Code 128 只支持 ASCII）。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `packing-slip-maker/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/packing-slip-maker/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-packing-slip-maker test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
