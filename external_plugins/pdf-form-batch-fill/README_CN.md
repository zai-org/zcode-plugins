# 表单批量填写（PDF Form Batch Fill）

用一张名单批量填写同一份空白 PDF 表单：报名表、登记表、证书、申请表……映射一次字段，每个人生成一份 PDF，并在生成前检查漏填和文字超出。

## 能做什么

- **读取表单字段**：自动列出 PDF 的文本框、复选框、单选、下拉字段，按名称给出“字段 ← 名单列”的映射建议。
- **没有表单域也能填**：扁平 PDF（扫描件、Word 导出的表格）可以在侧栏的页面预览上直接拖出文字框，指定填写位置。
- **一次映射，反复使用**：映射、字号、输出文件名保存为工作区里的 `.formfill.json` 模板，下次换一张名单直接用。
- **生成前检查**：必填项为空、文字放不下（按实际字体测量，自动缩小到最小字号仍放不下才报警）、超过字段最大长度、单选/下拉值不在选项里、名单缺列。
- **批量生成**：每行一份 PDF，文件名可用列名拼（如 `{姓名}-报名表.pdf`），可拼平防修改，可另存一份合并 PDF 方便打印，并写出 `_report.csv` 检查报告。
- **逐行预览**：面板里切换到任意一行，看真实填写效果；点问题列表可直接跳到对应行。

## 使用

安装并启用后，在 ZCode Desktop 里对 Agent 说：

- “用 学员名单.xlsx 批量填写 报名表.pdf，每人一份，文件名用姓名”
- “先检查一下名单里哪些人的地址会超出格子”
- “这份 PDF 没有表单域，帮我把每个人的姓名和电话填到第一页对应的格子里”

Agent 会调用 `form_open` 打开侧栏。也可以在会话侧栏手动打开“表单批量填写”面板，选择 PDF 和名单。

面板操作：右侧表格修改每个字段填入的内容（输入 `{` 可选择列名），勾选必填、设置字号；“+ 自由位置文字框”后在左侧页面上拖动即可添加填写位置，拖动紫色框可移动；勾选“预览填写效果”并切换行查看结果；“检查全部”→“生成”。

## 工具

| 工具 | 作用 |
|---|---|
| `form_open` | 打开 PDF 与名单，列出字段并建议映射，打开面板 |
| `roster_read` | 读取名单的列名和前几行 |
| `template_save` | 保存模板 `.formfill.json` |
| `form_check` | 检查全部行（不写文件） |
| `form_generate` | 生成 PDF、报告和可选的合并文件 |

## 支持范围（v0.1）

- 输入：PDF（AcroForm 表单或扁平 PDF）；名单 `.csv` / `.tsv` / `.xlsx`（GBK 编码的 CSV 会自动识别）。
- 暂不支持：Word / Excel 表单、签名图片、条形码、加密 PDF（请先解除密码）。

## 隐私、网络与文件写入

- **全部在本机处理**，不联网，不上传 PDF 或名单，不需要任何 API 密钥或账号。
- 只读写当前工作区：生成文件写到模板指定的输出文件夹（默认 `form-fill-output/`），模板写到你指定的 `.formfill.json`。不执行命令，没有 Hook。
- 填写中文使用系统中文字体（macOS：Arial Unicode / 冬青黑体；Windows：黑体 / 微软雅黑；Linux：Noto CJK）。找不到时在插件设置的 `fontPath` 填写字体文件路径。字体以子集方式嵌入生成的 PDF。

## 构建与测试（开发者）

源码在 `ui-plugins/pdf-form-batch-fill/`。仓库根目录执行 `pnpm install --frozen-lockfile && pnpm build`，然后在 ZCode 插件商店把 `dist/local-marketplace` 添加为本地来源并安装。测试：`pnpm --filter @penova/plugin-pdf-form-batch-fill test`（真实 IRS W-9 表单 + 中文报名表 + 30 行名单）与 `test:e2e`（浏览器面板测试）。
