# 考勤统计

把考勤机或打卡应用导出的原始打卡记录，变成每月的考勤统计。选上导出文件，设置上下班时间、迟到宽限、弹性上班、午休、加班规则、休息日和节假日，就能看到每个人每天的首末次打卡、迟到、早退、缺卡、缺勤和加班。忘打卡的可以直接在表里补，请假、出差也在表里标注，然后导出汇总表和每人一份的明细给本人核对。在本地运行，不用人事系统，无需 API 密钥。

## 功能

- **适配各种打卡导出**：每行一次打卡，含 姓名 和 打卡时间（或 日期 + 时间），CSV 或 Excel；重复打卡自动合并。
- **按你的规则**：上下班时间、迟到和早退宽限、弹性上班、午休、加班起算和最少时长。
- **日历**：双休、单休或无固定休息日；节假日和调休上班日。
- **逐日判断**：迟到、早退、缺卡、缺勤、工作日和休息日加班、工作时长。
- **表内修正**：补上忘打的卡，或在备注写 请假/病假/出差 即不算缺勤。
- **Excel 报表**：每人一行的汇总表，附逐日明细并标色；另给每人一份明细。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `attendance-report/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 punches.xlsx 做 11 月考勤统计”
- “上班时间 9:30–18:30，弹性 30 分钟”
- “赵小雨 11-18、11-19 请年假，然后导出”

## 工具

| 工具 | 作用 |
|---|---|
| `attend_open` | 读取打卡记录并逐日计算，并打开面板 |
| `attend_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `attend_status` | 查看当前数据、问题和汇总 |
| `attend_export` | 导出 attendance-<月份>.xlsx 和 people/<姓名>-<月份>.xlsx |

导出文件写到工作区的 `attendance-report/<项目>/` 文件夹。

## 范围（v0.1）

- v0.1 只支持一种固定班次，不支持轮班和跨零点的夜班。
- 不计算假期余额和工资。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `attendance-report/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/attendance-report/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-attendance-report test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
