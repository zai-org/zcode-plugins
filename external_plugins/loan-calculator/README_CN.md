# 贷款分期计算

签合同之前，把几种房贷、贷款方案放在一起比一比。填好每个方案的金额、年利率、期限和还款方式（等额本息或等额本金），还可以加上提前还款（缩短期限或减少月供）和某月起的利率调整。立即看到首月和最高月供、总利息、还清时间，以及每个方案能省多少利息，并附剩余本金曲线图。导出包含每个方案逐月还款计划的 Excel 和可分享的图表网页。在本地运行，不用登录银行，无需 API 密钥。

## 功能

- **两种方式**：等额本息（每月还款相同）和等额本金（每月本金相同、月供递减）。
- **用大白话写提前还款**：“2029-01:200000 缩短期限; 第36期:5万 减少月供”。
- **利率调整**：“2028-01:2.9”从当月起生效。
- **并排对比**：首月和最高月供、总利息、还清时间，以及比方案 1 少付的利息。
- **Excel**：对比表加每个方案的逐月还款计划，提前还款的月份标色。
- **图表网页**：方案卡片、剩余本金曲线和按年汇总。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `loan-calculator/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “对比 plans.csv 里的几种贷款方案”
- “2029 年 1 月提前还 20 万，缩短期限”
- “如果 2028 年起利率降到 2.9% 会怎样？”

## 工具

| 工具 | 作用 |
|---|---|
| `loan_open` | 读取方案并对比，并打开面板 |
| `loan_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `loan_status` | 查看当前数据、问题和汇总 |
| `loan_export` | 导出 loan-schedule.xlsx 和 loan-report.html |

导出文件写到工作区的 `loan-calculator/<项目>/` 文件夹。

## 范围（v0.1）

- 结果仅供参考，银行实际计算（计息天数、取整、费用）可能略有不同。
- v0.1 不支持公积金与商贷组合贷款，可分别作为两个方案计算。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `loan-calculator/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/loan-calculator/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-loan-calculator test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
