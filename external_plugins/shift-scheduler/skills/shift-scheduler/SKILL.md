# 排班表

1. `shifts_open(inputs, settings?, project?)`：读取员工可上班时间并排出一周的班。inputs 是工作区相对路径。
   - 结果里有汇总、问题列表（错误 / 提醒）和前几行数据，每行有编号 `#n`。
   - 可上班时间表每天一列（周一…周日），格子写 空/全天、休、早班/晚班 或 10-18。班次用 settings.shifts，如 `早班 08:00-16:00 ×2; 晚班 16:00-24:00 ×2`；本周第一天用 `settings.weekStart`（周一的日期）。
2. 向用户简要说明结果，先说错误和需要确认的地方，不要逐行念。
3. 用户要改时调用 `shifts_edit(project, settings?, set?: [{row, values}], add?, remove?)`。
   - 改某人某天：`set: [{row, values: {sun: "休"}}]`（列名也可用“周日”）；改工时上限：`values: {maxHours: 24}`；换一种排法：`settings: {seed: "2"}`。
4. `shifts_export(project, formats?)`：导出 rota.xlsx、rota.html 和 ics/<姓名>.ics。把文件路径告诉用户。
5. 缺人的班要告诉用户是哪天哪个班、缺几个人。
