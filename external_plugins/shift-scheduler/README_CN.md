# 排班表

根据大家能上班的时间，排出一张公平的每周排班表。写上每个人哪天能上什么班——全天、休息、早班/晚班这样的班次名，或 10-18 这样的时间段——再设每人每周最多工时，定义班次和每班需要几个人。按工时平均分配班次，同时遵守工时上限、每天一个班、两班之间的最短休息（不会晚班接第二天早班）。缺人的班会标红，方便调整。导出排班 Excel、可打印的排班网页，以及每个人的日历文件。在本地运行，不用登录，无需 API 密钥。

## 功能

- **灵活的可上班时间**：每天一格，空或“全天”= 什么班都行，“休/x”= 休息，班次名（早班、晚班），或时间段（10-18）。
- **任意班次**：“早班 08:00-16:00 ×2; 晚班 16:00-24:00 ×2”，也支持 22-6 这样的跨夜班。
- **公平合理**：按工时平均分配，不超过个人每周上限，默认每天最多一个班，两班之间保证最短休息。
- **缺人提示**：排不满的班在面板和 Excel 里标红，并写明还缺几个人。
- **导出**：排班 Excel（排班表、个人工时、完整明细）、可打印的排班网页，以及每人一个 .ics 日历文件。
- **面板**：在 ZCode 侧栏里选择输入文件、调整设置、查看问题、直接修改表格里的任意单元格、预览成品并导出。修改保存在 `shift-scheduler/<项目>.project.json`，重新打开输入文件前一直保留。

## 使用方法

在 ZCode 桌面端对助手说：

- “用 staff.csv 排下周的班：早班 08-16 两人，晚班 16-24 两人”
- “Tom 周日不能上班，重新排”
- “导出排班表，再给每个人一个日历文件”

## 工具

| 工具 | 作用 |
|---|---|
| `shifts_open` | 读取员工可上班时间并排出一周的班，并打开面板 |
| `shifts_edit` | 修改设置、按行修改单元格、新增或删除行 |
| `shifts_status` | 查看当前数据、问题和汇总 |
| `shifts_export` | 导出 rota.xlsx、rota.html 和 ics/<姓名>.ics |

导出文件写到工作区的 `shift-scheduler/<项目>/` 文件夹。

## 范围（v0.1）

- 一次排一周；v0.1 不按岗位/技能匹配班次（岗位列仅供参考）。
- 排班由插件计算；要调整某人，改他那天的可上班时间（如写“休”），排班会随之更新。

## 隐私、网络与文件

- **全部在本地运行。** 不联网、不上传，不需要 API 密钥或账号。
- 只读取你选择的文件，只写入工作区的 `shift-scheduler/` 文件夹。没有 Hook。

## 构建与测试（开发者）

- 源码：`ui-plugins/shift-scheduler/`。
- 构建：`pnpm install --frozen-lockfile && pnpm build`，然后把 `dist/local-marketplace` 添加为本地来源。
- 测试：`pnpm --filter @penova/plugin-shift-scheduler test` 和 `test:e2e`（需要 Chrome；样例文件在 `test/samples/`）。
