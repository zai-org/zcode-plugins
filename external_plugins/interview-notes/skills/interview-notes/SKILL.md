# 访谈纪要

插件不做语音识别；没有转写时请用户先用会议或转写工具导出（SRT、VTT、带时间戳的 TXT 都行）。

1. `interview_open(audio, transcript?)`：同名转写会自动带上。读返回的文字稿，每行形如 `[u12 01:05 名字] 内容`。
2. 先确认谁是受访者；用户说了名字就在下一步 `speakers` 里改名（例如 `{"说话人 1": "访谈者"}`）。两个说话人改成同一个名字会合并。
3. 只提炼受访者真正表达的需求、痛点和建议，不要编造。每条需求写清标题（一句话）、说明、分类、优先级，并至少引用一句原话：`quotes: [{utterance: "u12", text: "原话中的一段"}]`。`text` 必须是那一行里的原文。调用 `interview_submit(audio, needs, speakers?)`。
4. 有提示（引用对不上、没有引用）时修正后重新提交。然后告诉用户可以在面板里点 ▶ 听原话、确认或不采纳。
5. 用户要导出时调用 `interview_export(audio, format?)`，告诉用户 md / csv / html 的位置。HTML 引用录音的相对路径，发给别人时要连录音一起发。
