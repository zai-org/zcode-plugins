# 上下文与范围（团队 / 工作区 / 画布 / 分组）

LibTV 的所有操作都发生在一条范围链上：

**团队（team）→ 项目 / 工作区（workspace）→ 画布（project）→ 普通分组（group）→ 节点（node）**

> 📌 **术语**：**画布（project）** 是真正的画布文件；装画布的容器叫 **项目 / 工作区（workspace）**。一个工作区下可放多张画布。

命令（如 [`node`](../commands/node.md) / [`group`](../commands/group.md) / [`upload`](../commands/upload.md)）本身只描述"对哪个节点做什么"；**它作用在哪个团队 / 工作区 / 画布上，由"上下文"决定**。

## 范围参数

| 范围                | 含义             | 命令内 flag       |
| ------------------- | ---------------- | ----------------- |
| **team**            | 团队             | `--team-id`       |
| **workspace**       | 项目 / 工作区    | `-w, --workspace` |
| **project（画布）** | 画布文件         | `-p, --project`   |
| **group**           | 画布上的普通分组 | `-g, --group`     |

每条命令都可显式带上对应 flag 指定范围。

## 缺省值与身份

当命令**省略**这些 flag 时，范围取自"当前上下文"的缺省值；身份 / 鉴权同理。**缺省值的来源、以及能否把某个范围设为默认（省略 flag 即生效），由具体使用方式决定，见 [使用说明](../SKILL.md)。**
