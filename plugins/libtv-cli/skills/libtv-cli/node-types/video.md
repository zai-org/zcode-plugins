# 节点类型：`video` — 视频生成节点

## 整体节点用途

**视频生成节点**：按当前模型的 `modeType`（文生 / 单图生 / 首尾帧 / 多图参考 / 视频参考 / 音频驱动 / 全能参考 等）产出一条或多条视频；节点本体也承载最终视频 URL 与封面。常见相邻节点：上游 `image` / `video` / `audio` 资源节点；下游 `video-clip`、`script` / `storyboard` 的配图行等。

**通用约定**：[README.md](./README.md)。**`schema` 各块含义** 与 `modeType.items` / `rules` 逻辑：[../model-schema/mode-type.md](../model-schema/mode-type.md)（连线条数见 mode-type.md、生成校验见 rules.md）。

## 案例

见[示例](../SKILL.md)（以 Seedance 2.0 `star-video2` 为例）。

## 常见生成器参数（`-s / --set`）

写入 **`data.params`**。schema 里的可调字段一律 **`-s 字段名=值`** 写入，系统会自动归位。

| 字段           | 说明                                                                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`prompt`**   | 提示词。                                                                                                                                            |
| **`model`**    | 视频模型 **名字（`modelName`）**，如 `-s "model=Kling O1"`（含空格需引号；用 `libtv model search --type video` 查看，内部解析为 `modelKey` 落库）。 |
| **`modeType`** | 生成模式；可选键见当前模型的 `schema.properties.modeType.items`（见下表常见枚举）。                                                                 |
| **`count`**    | 条数，需符合 schema。                                                                                                                               |

其余可调字段随 `modelKey` 变化，以 `libtv model <modelKey>` 输出为准。

### `modeType` 常见枚举

| 枚举值                  | 文案             |
| ----------------------- | ---------------- |
| **`text2video`**        | 文生视频（默认） |
| **`singleImage2video`** | 图生视频         |
| **`frames2video`**      | 首尾帧           |
| **`image2video`**       | 图片参考         |
| **`video2video`**       | 视频参考         |
| **`videoEdit2video`**   | 视频编辑         |
| **`audio2video`**       | 音频驱动         |
| **`mixed2video`**       | 全能参考         |

> 不同模型支持哪些 `modeType`、每种下有哪些可调字段**完全由该模型 schema 决定**；以 `libtv model <modelKey>` 输出为准。

### 抽样：Seedance 2.0（`star-video2`，`libtv model star-video2`）

| 字段                 | `-s` 写法             | 取值提示                                                                                |
| -------------------- | --------------------- | --------------------------------------------------------------------------------------- |
| **`ratio`**          | `-s ratio=16:9`       | `adaptive`（展示 Auto）、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`（默认 **`16:9`**） |
| **`resolution`**     | `-s resolution=720p`  | **`480p`** / **`720p`**（默认 **`720p`**）                                              |
| **`duration`**       | `-s duration=5`       | 整数秒 **4–15**（默认 **`5`**）                                                         |
| **`enableSound`**    | `-s enableSound=on`   | **`on`** / **`off`**（默认 **`on`**）                                                   |
| **`search_enabled`** | `-s search_enabled=1` | 联网开关，switch，默认 **`1`**                                                          |

## 常见属性参数（`-u / --update`）

写入 **`data`** 顶层，**不**经生成器 schema 校验，但只接受下表的键并校验形状（见 [README.md](./README.md) 的「`-u` 可写字段」）。

| 键                                       | 类型       | 说明                                                                                                                         |
| ---------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **`url`**                                | `string[]` | 视频 URL（一般由生成 / 上传写入，手工改谨慎）。                                                                              |
| **`poster`**                             | `string`   | 封面图 URL。                                                                                                                 |
| **`contentWidth`** / **`contentHeight`** | `number`   | 内容区宽 / 高（像素）。                                                                                                      |
| **`transition`**                         | `object`   | 剪辑转场，形如 `{"type":"fade","duration":0.5}`：`type` 为非空字符串（如 `fade` / `dissolve`），`duration` 为大于 0 的秒数。 |

> 生成参数（`modeType` / `ratio` / `duration` / …）请用 `-s`；展示名用 `--name`。

## 特殊用法

- **参考图 / 参考视频 / 音频驱动**：先用 [`libtv upload`](../commands/upload.md) 建对应资源节点，再以 `--left` 连到本节点左侧；允许的**类型与条数**由当前 `modeType` 下的 `modeType.items[modeType]` 与 `mixed2videoConfig` 等共同约束（见 [../model-schema/mode-type.md](../model-schema/mode-type.md)）。
- **列出 / 查询视频模型**：`libtv model search --type video`、`libtv model <modelKey>`（见 [../commands/model.md](../commands/model.md)）。
- **文档 / 链接上下文（`--attachment` / `--link`）**：部分模型（如 Wan 3.0）支持给生成附一份文档或一个链接作为上下文，是否支持看该模型 schema 的 `supportAttachment.attachment` / `supportAttachment.link`（`libtv model <modelKey>`）。用法见 [`node`](../commands/node.md) 的选项表，规则如下：

  | 规则             | 说明                                                                                                                       |
  | ---------------- | -------------------------------------------------------------------------------------------------------------------------- |
  | 写入即校验       | 写入时按当前模型 schema 校验：模型不支持、类型不在白名单、大小超上限都会**直接报错且不写入**；本地文件校验通过后才上传。   |
  | 互斥             | 两者同时给，或节点上已有另一种未清除，都会报错；要换另一种，先对当前那个传 `none` 清除。                                   |
  | 本地文件         | 文件须带扩展名（如 `.pdf` / `.txt`），用于判断文档类型。                                                                   |
  | URL              | 须带扩展名，且服务器能返回文件大小（`Content-Length`）；取不到时改传本地文件。                                             |
  | 切到不支持的模型 | 节点上已有的上下文不会被清除也不拦截切换；`--run` 时按新模型 schema 判定，不支持则打印告警并**忽略**该上下文，不中止生成。 |

- **合规校验（Seedance 家族）**：`--run` 用 Seedance 家族模型生成时（schema 标记 `properties.portrait=true`，或模型属于 `star-video2*` 系列），系统在提交前自动送审上游引用的**图片 / 视频 / 音频**，与网页同一套规则：

  | 情况                                 | 行为                                                                                                                                               |
  | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
  | 素材已审核且凭证在 **60 天**有效期内 | 跳过，不重复送审。                                                                                                                                 |
  | 无凭证或凭证已过期                   | 送审；通过后本次请求改用审核后的素材地址，未检测到真人的素材标记为免检并继续用原地址。                                                             |
  | 送审前图片本地预检不合格             | **整批不送审**、生成中止，并列出不合格节点。要求：格式为 jpeg / png / webp / bmp / tiff / gif / heic；边长 300–6000px；宽高比 0.4–2.5；小于 30MB。 |
  | 任一素材审核不通过                   | 生成中止；若为真人素材，需先在网页「角色库」录入真人资产后再用。已签发的凭证仍会保存，下次不必重审。                                               |
  | 模型关闭了自动核验，但已有凭证过期   | 生成中止，提示「核验已过期，请重新核验」。                                                                                                         |
  | 素材库已满                           | 后端拒绝送审，提示先删除不需要的素材。                                                                                                             |

- **高清 / 样片转正片**：对已生成的视频做超分，或把 Seedance 2.5 样片转为 1080P 正片，用 [`libtv video`](../commands/video.md)（会在右侧新建节点并自动连线）。
