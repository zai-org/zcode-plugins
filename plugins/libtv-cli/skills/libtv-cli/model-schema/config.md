# `config` — 设置面板布局与任务映射

> 模型 schema 四块之一，索引见 [README.md](./README.md)。

`config` 描述模型在网页端设置面板的布局，以及生成任务的类型映射。

**命令行无需关心面板布局**——所有可调字段一律 `-s 字段名=值` 写入，系统按 schema 自动归位（见 [properties.md](./properties.md)）。

`config` 里与命令行相关的只有：

| 字段                | 含义                                                                                                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`generateTypes`** | 创建生成任务时与 **`taskType` / checkpoint** 等相关的数值映射（`text` / `image` / `audio` / `checkpointId` 等）；**不**用于画布连线条数判断。退化为空 `{}` / `[]` 时以线上解析逻辑为准。 |
