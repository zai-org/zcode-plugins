# `libtv group` — 普通分组

对画布的**普通分组**（画布上可承载一组子节点的 group 节点）做**列表 / 新建 / 查询或绑定子节点**等操作。

## 子命令

| 子命令                            | 作用                                                                                      |
| --------------------------------- | ----------------------------------------------------------------------------------------- |
| **`libtv group list`**            | 列出画布上所有**普通**分组（便于抄 `groupNodeKey` 或展示名）                              |
| **`libtv group create <group>`**  | **仅新建**分组；已有同名**普通**分组则失败                                                |
| **（默认）`libtv group [group]`** | **仅操作已有**分组：查询 / 追加或解绑子节点 / `--run`；分组不存在时报错，**不会自动新建** |

## 公共参数

| 选项                   | 必填 | 说明                                                                                         |
| ---------------------- | ---- | -------------------------------------------------------------------------------------------- |
| `-p, --project <uuid>` | 否   | 目标画布 UUID；缺省来源见 [../concepts/context.md](../concepts/context.md)。所有子命令通用。 |

### `libtv group list`

用法骨架：`libtv group list [flags]`

**位置参数**：无。

**选项**：`-p, --project`（见公共参数）。

**输出**：含所有普通分组的 `groupNodeKey`、展示名、子节点数量等。

### `libtv group create <group>`

用法骨架：`libtv group create <group> [flags]`

**位置参数**

- **`<group>`**（必填）：新建分组的展示名。若该展示名（或在 `-g` 父组内的解析规则下）已对应**普通分组**节点，会报错并提示改用默认子命令 `libtv group <group>` 查询 / 绑定；若被**非普通分组**节点占用，也会报错退出。

**选项**

| 选项                   | 必填 | 说明                                                                                                                                                                               |
| ---------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-p, --project <uuid>` | 否   | 见公共参数。                                                                                                                                                                       |
| `-g, --group <父组>`   | 否   | 父级**普通分组**；在其 `childNodeIds` 内解析分组名 / 子节点名，避免同名冲突。                                                                                                      |
| `-r, --run`            | 否   | 主流程成功后对**目标普通分组**做一次**整组按顺序执行**（与网页「整组执行」一致），阻塞等待终态结果后返回。                                                                         |
| `--node <子节点>`      | 否   | 绑定到**新建分组**的子节点（即该组的初始子节点），可重复指定多个。优先按节点 id 匹配，否则按展示名匹配（重名取第一个）；若某子节点已在别的普通分组里，会先从原分组移走再挂到这里。 |

### `libtv group [group]`（默认子命令）

用法骨架：`libtv group [group] [flags]`

**位置参数**

- **`[group]`**（可选）：已有分组的展示名或 id（id 优先，重名取第一个）。省略时用 `libtv group use` 绑定的默认分组。

**选项**

| 选项                   | 必填 | 说明                                                                                                                                                             |
| ---------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-p, --project <uuid>` | 否   | 见公共参数。                                                                                                                                                     |
| `-g, --group <父组>`   | 否   | 父级**普通分组**；在其 `childNodeIds` 内解析分组名 / 子节点名，避免同名冲突。                                                                                    |
| `-r, --run`            | 否   | 主流程成功后对**目标普通分组**做一次**整组按顺序执行**（与网页「整组执行」一致），阻塞等待终态结果后返回。                                                       |
| `--node <子节点>`      | 否   | 要**追加**绑定的子节点（id 或展示名，重名取第一个），可重复。与现有子节点合并去重，不覆盖、不清空；若子节点原属别的分组会先移走再挂到这里。与 `--node-rm` 互斥。 |
| `--node-rm <子节点>`   | 否   | 要**解绑**的子节点（id 或展示名），可重复。解绑后子节点回到画布，分组本身保留。与 `--node` 互斥。                                                                |

找不到对应的普通分组时报错退出（退出码 1），提示改用 `libtv group create`；带了 `--node` 也不会顺带建组。该显示名被**非普通分组**节点占用时同样报错退出。

**与 `create` 的分工**：默认子命令只管**已有**分组，`create` 只管**新建**（已有同名普通分组时失败）。

## 示例

```bash
# case 1: 列出画布上的所有普通分组
libtv group list

# case 2: 仅新建一个空分组（已有同名则报错）
libtv group create "本镜资源组"

# case 3: 新建并绑定子节点（--node 可重复）
libtv group create "本镜资源组" --node "图A" --node "图B"

# case 4: 向已有分组追加子节点（分组不存在则报错，需先 create）
libtv group "本镜资源组" --node "图A" --node "图B"

# case 5: 追加子节点后整组执行
libtv group "本镜资源组" --node "图C" --run

# case 6: 从分组解绑子节点（子节点回到画布，分组保留）
libtv group "本镜资源组" --node-rm "图A"
```
