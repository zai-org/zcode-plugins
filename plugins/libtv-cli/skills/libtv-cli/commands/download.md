# `libtv download` — 下载节点资源到本地

把画布节点上的产物下载到本机目录，对应画布工具栏「下载」与分组「批量下载」。单个媒体节点直接存为文件；普通分组或一次产生多个文件时打成一个 ZIP。目标画布由 `-p` 指定，分组范围由 `-g` 指定（缺省来源见 [../state.md](../state.md)）。

## 子命令

无子命令，仅 flags。

用法骨架：`libtv download -n <node> --watermark <true|false> [flags]`

### 选项

| 选项                        | 必填 | 说明                                                                                                                  |
| --------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------- |
| `-n, --node <node>`         | 是   | 目标节点 id 或展示名（精确匹配、id 优先，同 [`node`](./node.md) 的 `<node>`）。传**普通分组**节点即批量下载该组。     |
| `-p, --project <uuid>`      | 否   | 目标画布 **UUID**；缺省读当前目录 `.libtv/project.json`。                                                             |
| `-g, --group <node>`        | 否   | 只在该普通分组的子节点内解析 `-n`；未传时若已 `group use` 则自动套用绑定分组。                                        |
| `-o, --out <dir>`           | 否   | 输出目录，默认当前工作目录。                                                                                          |
| `--watermark <true\|false>` | 是   | 断言本次下载物是否带**社区水印**：会员传 `false`、非会员传 `true`；与服务端会员态不一致时报错退出（退出码 1）。       |
| `--vip`                     | 否   | **已废弃**：会员态由服务端判定，传了只会在 stderr 提示一次、不影响结果。环境变量 `LIBTV_DOWNLOAD_IS_VIP` 同样已废弃。 |

### 各类节点的落盘形式

| 节点类型                    | 文件                              |
| --------------------------- | --------------------------------- |
| `image` / `video` / `audio` | 原媒体文件（单节点直存，不打包）  |
| `script` / `storyboard`     | `.csv`                            |
| `text`                      | `.txt`                            |
| 普通分组 / 多文件           | 一个 `.zip`，内部按节点展示名命名 |

### 水印

- **AI 水印**：CLI 下载一律不加，不读账号在网页的 AI 水印设置。
- **社区水印**：由**服务端会员态**决定，CLI 不能自报 —— 会员不带、非会员带。`--watermark` 必须与之一致：

| 账号   | `--watermark true`   | `--watermark false` |
| ------ | -------------------- | ------------------- |
| 会员   | 报错退出             | 下载原文件，无水印  |
| 非会员 | 下载带社区水印的文件 | 报错退出            |

会员态读取失败时无法核对，同样报错退出；水印接口未返回地址时也报错退出，不会回落到无水印原文件。不确定账号是否会员时，先传任意一个值，报错信息会给出应传的值。

### 输出

| 流     | 内容                                                                        |
| ------ | --------------------------------------------------------------------------- |
| stdout | **每行一个**已写出文件的绝对路径（纯文本，**不是 JSON**，与其它命令不同）。 |
| stderr | 错误原因（含 `--watermark` 与会员态不一致的提示）。                         |

## 示例

```bash
# case 1: 非会员下载单个视频节点到当前目录（带社区水印）
libtv download -n "镜头-01" --watermark true

# case 2: 下载到指定目录，并拿到文件路径继续处理
FILE=$(libtv download -n "镜头-01" --watermark true -o ./out)
ffprobe "$FILE"

# case 3: 批量下载整个分组（-n 传分组节点），得到一个 zip
libtv download -n "首集分镜" --watermark true -o ./out

# case 4: 在某分组内按名字解析子节点
libtv download -n "参考图1" -g "本镜资源组" --watermark true

# case 5: 会员账号下载无水印原文件；非会员这样传会报错退出（退出码 1）
libtv download -n "镜头-01" --watermark false
```
