# İAA — İştirak-i A‘mâl-i Ajanîye（ZCode 插件）

版本：0.1.1

面向代理 CLI 的**委派决策策略**：一个技能决定*是否、何时以及如何*将工作委派给子代理——按任务自适应——并为小型或紧耦合的工作提供零代理回退，在其模式下是唯一的编排权威。

- **用途：**在主 Agent 中管理委派决策。仅当具体收益（真正的并行、有界上下文隔离、专业化、上下文卸载、独立验证）超过协调成本时才委派；小型、琐碎或紧耦合的工作保留在主上下文中（零代理回退）。
- **它不是什么：**不是一个框架——没有角色、没有评审配额、没有状态文件、没有规划阶段；它绝不禁用、修补或重新配置其他插件、框架或设置。当用户按名称显式请求另一个工作流时，İAA 会退让。
- **组件：**恰好一个技能（`iaa`——委派策略）和一个显式命令（`/orchestrate`）。没有其他内容：没有内置代理（agents）、没有钩子（hooks）、没有 MCP 服务器、没有守护进程。
- **依赖：**无。
- **权限：**无需任何权限。
- **网络访问：**无。İAA 不引入任何外部网络依赖，也不需要 İAA API 密钥（您自己的 ZCode 模型提供方账户即可）。
- **副作用：**运行时无副作用。可选的集成步骤（源码仓库中有文档）仅在用户显式运行时，向 `~/.zcode/AGENTS.md` 写入一个带标记的块。
- **安装 / 禁用 / 卸载：**通过 ZCode 插件管理器（marketplace）安装并启用。禁用插件后，技能和命令都会从发现列表中消失；卸载只移除插件自身管理的文件——不会改动您机器上的其他任何内容。
- **触发方式：**`$iaa`（显式技能调用）、任务确实受益于委派时的隐式调用，或作为显式入口的 `/orchestrate` 命令。
- **兼容性：**仅作版本锁定的声明——见源码仓库中的兼容性矩阵。不宣称普遍兼容。
