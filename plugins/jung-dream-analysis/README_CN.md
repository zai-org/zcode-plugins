# 荣格梦的解析（Jungian Dream Analysis）

一个 ZCode 插件，按照 C.G. 荣格分析心理学的实践方式来解析梦——不是梦典式的查表对应，而是你与自身潜意识之间的一场引导对话。

插件由专家指令（一个技能和一个斜杠命令）与参考资料构成。它不添加任何工具、不发起网络请求、不需要配置——一切都在你与 ZCode 智能体的对话中完成。

## 它做什么

面对一个梦，智能体会按荣格的真实工作方法逐步推进：

1. **背景**——几个聚焦的问题：你当下的生活处境、醒来时的情绪、你在这个领域的惯常姿态。
2. **结构**——先忠实地复述梦，再按荣格的"四幕剧"展开（开场、发展、转折、结局——包括没有结局的开放式收尾）。
3. **个人联想**——询问每个意象*对你个人*意味着什么；以你的联想为准，而不是词典。
4. **放大**——当意象抵抗个人联想时，以提问的方式引入神话、童话与宗教象征中的平行意象，而非给出答案。
5. **原型映射**——尝试性地识别梦中的人物与动力（阴影、阿尼玛/阿尼姆斯、人格面具、自性、大母神、智慧老人、神圣儿童、捣蛋鬼、英雄），并以你的共鸣来检验。
6. **补偿**——荣格式解梦的核心：把你的清醒姿态与梦的相反立场并置，看梦在纠正怎样的片面性。
7. **综合**——梦向你提出的那个建设性问题，以及（若有）它在自性化道路上的位置。
8. **落地**——积极想象、一个外在的小行动，或记梦日记；重复出现的梦可以跨会话追踪为系列。

## 安装

在 ZCode 插件市场中安装，或将本仓库作为市场源添加。

## 用法

- 输入 `/dream` 加上你的梦——或直接对智能体说"我做了个梦……"，技能会自动触发。
- 不带参数的 `/dream` 会开启引导式会话。
- 回答背景问题时，简短、真实的日常语言效果最好；整个解释都建立在你的回答之上。

示例：

```
/dream 我梦见自己开着一辆家里的旧车下山，刹车几乎不管用；
去世的爷爷坐在我旁边，很平静地说：你会到的。
我醒来时很焦虑。
```

预期行为：智能体会先询问你当下的生活处境与醒来时的感受，复述梦并梳理其戏剧结构，再问"这辆车""爷爷"对你意味着什么，然后才给出原型假设、补偿解读与一个建设性问题——最后以一个积极想象练习收尾。

## 边界与伦理

- **象征不是记号。** 插件绝不给出固定对应义；每个解释都是有待梦者确认或否决的假设。
- **梦者是最终权威。** 不产生共鸣的解读会被放弃。
- **不是心理治疗。** 这是自我反思与学习，不是诊断或治疗，也不预测未来。若素材涉及严重创伤或危机，插件会指示智能体明确说明，并建议寻求专业治疗师的帮助。
- 会话中谈论的梦按你与 ZCode 智能体的普通对话处理——存储方式见 ZCode 的隐私设置。

## 依赖与副作用

无。插件只包含文本指令：没有 MCP 服务器、没有钩子、没有脚本、不访问网络、不写文件，也不包含任何第三方代码或素材。荣格的概念来自其公开出版著作（如《回忆·梦·思考》与《文集》），仅作为背景引用；插件中的全部文字均为原创。
