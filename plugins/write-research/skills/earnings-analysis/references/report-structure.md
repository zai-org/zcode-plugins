This document provides complete page-by-page templates and formatting requirements for the earnings update report.

## CLOSING SECTIONS (mandatory, in this order)

### `## Coverage and Limitations`

What was obtained, what was not, and when — see SKILL.md Requirement 7 for the
three states (`On record` / `Not found within the search scope` /
`Source unavailable`) and the table shape. Include it even when everything was
obtained; state the retrieval timestamp, which materials were not yet available,
and which line items consensus covered (this is where blank segment-consensus
cells are explained).

### `## Sources`

Starts on its own page — the only hard page break besides the one after the
cover. Heading is exactly `## Sources`; one entry per marker:

```
[n] 〔Primary|Secondary〕 Publisher · Document or system · Date (published; retrieved) · URL
```

The count of distinct `[n]` markers in the report must equal the number of
entries, and a `〔Secondary〕` entry must name what it relays.

## FORMATTING REQUIREMENTS

### 1. Page 1 Requirements
- Clear rating (MAINTAIN OUTPERFORM, RAISE TO BUY, etc.)
- Updated price target prominently displayed
- Summary table with old/new estimates
- 3-4 paragraph-length bullets with ■ character

### 2. All Tables Requirements
- Source line at bottom (with `[n]` citation), stated exactly once per table
- Clear column headers
- Shading for header rows; no vertical rules in a document table
- Every number carries a provenance chip — `[Reported]` / `[Est.]` / `[Consensus]` / `[Inferred]` / `[Media]`, one tag style throughout; leave unsourced consensus cells blank and account for them in `## Coverage and Limitations`, never fabricated

### 3. All Charts Requirements
- "Figure X - [Title]" caption above
- "Source: [Source]" as a figure-level footnote BELOW the plot (use `fig.text()` + reserved bottom margin; never `ax.text()` at data coordinates, which overlaps axis labels)
- **Caption + image bound as one unit** (e.g. reportlab `KeepTogether([caption, image, note])`) so the title never splits from its figure across a page
- **Size charts to fit the page** — if a full-width chart spills over and strands a half-empty page, shrink its width (e.g. 174mm → ~138mm) rather than leaving the gap
- Plot only disclosed values; if mixing disclosed/estimated points, distinguish them visually
- Professional styling

### 4. Year Notation
- Use A for actual (Q3'24A)
- Use E for estimate (Q4'24E)

### 5. Writing Style
- Lead with numbers ("Revenue grew 15% to $1.2B" not "Strong revenue growth")
- Use "vs." not "versus"
- Be direct and concise
- Focus on what's NEW

### 6. Hyperlink Requirements (any link-supporting format)
- ALL URLs must be real clickable links, not plain blue text — `/Link` annotations in PDF (reportlab `<a href="...">`), `<a>` in HTML
- **In DOCX the vehicle is different and the requirement is the same**: `[n]` is a `w:hyperlink` carrying `w:anchor`, pointing at a `w:bookmarkStart` on its Sources entry; the entry's URL is a relationship marked `TargetMode="External"`. Measured failure: a hand-built Word deliverable linked its body markers and left **every figure and table note plain**, so citations worked in the prose and died under each exhibit — which is where a chart's only provenance lives. **要出 Word 就先载入 `report-render` 技能，再动手建**——`DocxReport` 与 `Report` 同一套调用，机制记录在那个技能里。
- Inline `[n]` citation markers are clickable and jump to `## Sources` (e.g. `<a href="#refN">`)
- Sources entries link out to the source; make the whole title line clickable, not just the bare URL
- Display text meaningful (not raw URL); verify in the built file by counting `/Link` annotations
- No plain, non-clickable URLs anywhere

### 7. CJK / Chinese Reports
- Embed a real TrueType font (Regular + Bold) and set `wordWrap='CJK'` on every Chinese paragraph style — built-in CID fonts render blank, and without `wordWrap='CJK'` lines stop short of the right margin. Both fail silently.
- Let content flow; the only hard breaks are after the cover and before `## Sources`.
- After building, render the file and confirm: Chinese visible, lines run to the right margin, no half-empty / orphan / overflowing pages.
- The full catalogue of silent rendering failures lives in `report-render`'s `references/pitfalls.md`.

## Citation Examples for Specific Content

Markers are `[n]`, matching entries in `## Sources`. The prose names the
document; the entry carries `〔Primary|Secondary〕`, the dates, and the URL.

### For Beat/Miss Analysis:
```
Revenue of $2.45B [Reported] beat consensus of $2.39B [Consensus] by $60M (2.5%) [Est.] [1][4]

[1] 〔Primary〕 <Company> · Q3 FY24 earnings release · 2024-11-07 (published; retrieved <date>) · https://…
[4] 〔Primary〕 <provider> · consensus, revenue and EPS · 2024-11-06 16:00 close (retrieved) · https://…
```

### For Guidance:
```
Management raised FY24 revenue guidance to $9.8-10.0B from prior $9.5-9.7B [Reported] [3][5]

[3] 〔Primary〕 <Company> · Q3 FY24 earnings call transcript, CFO prepared remarks · 2024-11-07 (published; retrieved <date>) · https://…
[5] 〔Primary〕 <Company> · Q2 FY24 earnings call transcript (prior guidance) · 2024-08-08 (published; retrieved <date>) · https://…
```

### For Key Metrics:
```
Enterprise customers grew 23% YoY to 845, with net revenue retention at 128% [Reported] [2][6]

[2] 〔Primary〕 SEC EDGAR · <Company> Form 10-Q, Q3 FY24, p.23 · 2024-11-08 (filed; retrieved <date>) · https://www.sec.gov/…
[6] 〔Primary〕 <Company> · Q3 FY24 investor presentation, slide 8 · 2024-11-07 (published; retrieved <date>) · https://…
```

Whole title lines are clickable in link-supporting formats; the marker itself
jumps to the entry.
