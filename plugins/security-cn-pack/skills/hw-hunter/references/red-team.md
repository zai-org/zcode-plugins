# 红队篇：护网计分、手法链与降噪

## 计分规则（先懂规则再打法）

- 攻击方以**获取权限/数据**得分，路径上资产均得分；**提交漏洞不得分**——别浪费动作证明漏洞存在，直接打权限链。
- 靶标提前 3 周通知，不限攻击路径。
- 攻击得分手感（=防守扣分表）：终端权限 10/台、Webshell 20/个、邮箱/VPN/FTP 账密 20-60/个、**域控管理员 300（累计上限 3000）**。
- 防守加分项（=红队陷阱）：发现木马 50、处置 Webshell 50——防守要样本+流量+日志完整取证链；攻击报 1 小时内上报且取证可免扣分。
- **只截设备告警图的上报不计分**——在告警明显的路径上浪费动作没有意义。

## 攻击链

```
侦察 → 武器化 → 载荷传输 → 弱点利用 → 装后门 → C2 → 横向
```

攻击队默认手法顺序：旁站攻击 → 暴力破解 → Web 渗透 → 提权。

## 检测三角 → 三条降噪主线

蓝队检测体系三大支柱（详见 blue-team.md），对应三条规避路线：

### 1. 告警依赖设备规则启用
- 未启用的场景规则 = 无告警（TAM 重点事件需手动启用）
- 日志未接入的哑设备/旁路死角 = 监测盲区
- 私网 IP 未导入资产库不产生态势事件（"资产+事件"双条件）
- 私有协议/自定义协议 = 设备不识别

### 2. "攻击动作+外连行为"二段式判定
- Webshell 访问保持**异常响应码**（非 200 漏报——蓝队公式是"Webshell URL + HTTP 主动访问 200 OK"才判入侵）
- C2 走**新鲜域名/CDN**（威胁情报库无历史劣迹——防守靠 NTI 类情报平台对 IP 画像秒级识别，有 C2/扫描历史劣迹的 IP 必挂）
- payload 不回连、控制端域名不进黑名单 = "关联闭环"断掉

### 3. 统计特征（源IP/频率/响应码）
- **IPS 日志归并默认 3600 秒**：同源同目标同事件只告一次——慢速低频攻击天然稀释告警
- 慢速多源低频：把高危利用做成"分布式低频"降级为扫描级事件（4 级，防守备案后封禁即止，响应慢）
- 出网 IP 全国轮换规避封禁
- 纯内网口令复用不外呼不触发 TAM 失陷判定（失陷=内→外连接且攻击阶段≥5）

## TAC 沙箱规避（检测链顺序：白名单优先）

```
自定义白 → 自定义黑 → 文件白 → 信誉 → 病毒AV → 静态 → 动态沙箱
（命中白名单不再往下检）
```

- **PE 改图片后缀**：哈希信誉查不到（后缀变了）
- **新型/免杀样本**：信誉库为空，AV 引擎过时
- **无文件/不落盘载荷**：钓鱼宏直接内存执行 → 只走静态环节，沙箱（动态）不触发
- 沙箱逃逸：检测依赖行为触发——sleep 拖延、检查虚拟环境特征后再执行真实载荷
- 信誉云每天 7 点才拉取一次——凌晨到 7 点间的未知样本有窗口

## 免杀要点

- **落盘规避**：shell 落随机名/加密目录；复用现有 web 进程用户执行命令（无新增文件+无新账户——蓝队经验法检查就这两类）
- **无文件化**：powershell 内存执行、反射加载
- **静态特征**：shellcode 分离（loader+加密载荷）、加壳（注意沙箱会动态脱壳）、代码签名伪造
- **行为特征**：sleep 混淆、注入正常进程（explorer.exe）、流量伪装（域前置/CDN）
- 权限维持位置（蓝队 AutoRuns 必查项，选冷门）：计划任务命名模仿系统任务、WMI 订阅、COM 劫持
