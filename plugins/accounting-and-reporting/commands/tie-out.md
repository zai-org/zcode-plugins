Load the `statement-consistency-check` skill and review: $ARGUMENTS

**Do not rebuild the statements.** Take them as given and test them — a reconstruction from the trial balance tests our own construction and systematically misses the preparer errors this review exists to find: a mapping decision, a caption composed differently, a note drawn from the wrong schedule. Hold the set unmodified on `Statements_AsGiven`; corrections belong to the preparer on a separate pass.

Check the unit on each statement separately before anything else — a set mixing 元 and 万元 fails ties for reasons unrelated to accounting. Then run within-statement, cross-statement (净利润三表一致、现金与货币资金、未分配利润滚存、权益合计), prior-period **line by line**, and notes-against-face.

A tie that only closes on an unnamed difference is a finding, not rounding. An agreeing opening total over moved lines is an undisclosed restatement, which is 🔴. Where the trial balance was not provided, say the review tested internal consistency only — that is not a clean review.

With any unresolved 🔴, the status is 存在未解释差异. Never 复核通过, never 无异常. Locate differences; do not decide which side is wrong and do not name anyone.
