# Research Matching Criteria

Choose criteria according to the user's goal. Judge content evidence and technical similarity separately.

| Goal | What to verify | Common misjudgments |
| --- | --- | --- |
| Full original / HD version | The corresponding segment is the same footage from the same shoot; the candidate actually covers more complete content, and its resolution meets the requirement | Same subject, a different shoot, only the title says "full" |
| Screenshot provenance | Exclude the influence of text added afterwards; find a frame with the same scene, same composition and same moment. Check first whether the screenshot is a crop (aspect ratio vs. the platform's 16:9), a blend of two shots (ghosted UI, a second scene bleeding through = a dissolve in an edited video) or a picture shown inside another video — each changes which candidates can match at all | Treating added subtitles as clues to the original; only the subject is similar; concluding "not this video" from a hash miss when the screenshot was cropped or blended |
| Tracing each segment of a compilation | Establish the correspondence between input and candidate times separately for each actual segment | Declaring everything done after finding one segment |
| Other viewpoints of the same event | Same time and place, same occurrence of the event; different camera position or composition | A reupload of the same footage; a similar but different occurrence |
| Other occasions of the same person | Identity supported by a name, subtitles or a reliable source; the occasion really is different | Relying only on similar appearance; a different camera angle of the same occasion |
| Different periods of the same location | The same landmark/neighborhood; the shooting year and changes over time have a basis | Taking the upload date directly as the shooting date; a different place in the same city |
| Next episode in a series | First confirm the input's series and episode number; the candidate is exactly the next episode, with different content | Another reupload, an arbitrary episode of the same series; confusing parts with episode numbers |
| Another language version | Same work/same footage, and verify subtitles or transcript in the target language | Relying only on a language tag in the title |
| Finding a video from a vague recollection | Clearly remembered details match one by one; vague details serve as clues | Claiming to have found the unique original just because the genre fits |
| Fact/provenance verification | Visuals/original speech correspond to a reliable source; state dates, names and the original source | Filling in unseen facts from titles or model memory |
| Screening materials for editing | Content and the user's specified duration, resolution, aspect ratio and other requirements are each satisfied | Confusing the download quality tier with the resolution the original site advertises |
| Judging usage conditions | Judge based on the license and usage notes actually read, and record the source | Treating downloadable as authorized for any use |

When a match is uncertain, give the candidates and the specific gaps. Hash similarity is not responsible for judging identity, event relationships, authorization or factual truth.
