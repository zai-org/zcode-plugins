# Post-edit Subtitles

Record each stage's inputs and outputs and the enabled features: content editing/condensing, subtitles, speakers, highlighting, translation, term notes. Enable them based on the user's task; plain subtitles do not automatically turn on every feature.

1. If the materials already meet the editing goal, go straight to the [subtitle workflow](talking-head-subtitles.md). For multiple independent materials, use the [assembly workflow](../../video-edit-assembly/SKILL.md) first; for long talking-head condensing, use [speech-condense](speech-condense.md) first. Complete other long-video selections with existing editing capabilities; do not treat the talking-head method as the full set of long-video processing capabilities.
2. First finish edits that affect duration, order and speed, then lock the current final video for subtitling. Keep the source/output time mapping; do not apply source times directly to the final video.
3. The `output_transcript` returned by the speech renderer, bound to the actual output, can be reused; if the plan changed, the video was overwritten, or uncorrected partial units exist, it cannot be used directly for subtitles. For multiple materials or other edits without a mapping, re-run transcribe on the final video.
4. When speaker labels are needed, review identity and write a corrected copy; when translation/annotations are needed, the main Agent creates and verifies the content; when word-level highlighting is needed, first check that real word-level times are available, then enable it per [subtitle features](../references/subtitle-features.md).
5. Re-observe the subtitle safe area on the final video, especially when the original materials already have hard subtitles. Build cues, render the output format the user requested, and run subtitle QC plus the F/T checks. After upstream changes, redo the affected mapping, subtitles and acceptance checks.

Deliver the requested final video/subtitles and necessary companion files. The pipeline report lists the stages, each stage's materials and time base, enabled features, identity/translation evidence, check scope and final paths. Technical QC of the editing stage and subtitle QC each target their own actual version and cannot substitute for each other.
