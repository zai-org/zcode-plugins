按 `setup-guide` 技能帮用户把这台电脑的环境准备好。

- 附加参数（可选）：`$ARGUMENTS` —— 含 `--fix` 时，体检后直接安装插件的 Python 依赖；系统软件（ffmpeg、Node.js 等）仍然要先征得用户同意再装。

要点：

1. 先运行体检脚本（Bash timeout ≥ 180000 ms），不要凭记忆判断缺什么。
2. 先看「能力汇总」，按用户要做的事决定装哪些组：基础组都要；网页复刻、3D 动画只在用户需要时才装。
3. 系统软件先说明用途、耗时和会看到的提示，用户同意后只装同意的那几项：`--fix --system --only <项 id>`；需要用户自己操作的步骤（安装 Homebrew、sudo 命令、下载安装包）给出原样可复制的步骤，有多种装法时说明任选其一，并等用户确认完成。
4. 装完系统软件后提醒用户完全退出并重新打开 ZCode，再输入 `/setup-guide` 继续，然后复查一次。
5. 不要让用户申请或填写任何 API key：语音、生图、生视频等外部服务由平台统一提供，未接入就如实说明暂不可用。
6. 收尾用能力来说明结果：现在能做什么、还不能做什么、用户还需要做什么。

只做环境准备，不要顺手开始视频任务。
