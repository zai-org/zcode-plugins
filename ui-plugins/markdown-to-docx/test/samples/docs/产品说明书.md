# 青禾茶业会员系统 产品说明

版本 **v2.1** · 更新于 2026-11-25 · 负责人：*林小满*

## 1. 概述

会员系统用于管理门店和线上的会员积分、等级和优惠券。详见 [官网](https://penova.example/docs)。

> 提示：本文档面向门店店长和客服，不涉及技术实现。

## 2. 功能清单

- 会员注册与资料维护
- 积分累计与兑换
  - 消费 1 元积 1 分
  - 生日当月双倍积分
- 优惠券发放

### 2.1 会员等级

| 等级 | 累计消费 | 折扣 |
|---|---:|:---:|
| 普通 | 0 | 无 |
| 银卡 | ¥2,000 | 9.5 折 |
| 金卡 | ¥8,000 | 9 折 |

## 3. 操作步骤

1. 打开收银台，点击“会员”
2. 输入手机号，确认会员信息
3. 结账时选择使用积分或优惠券

示例接口返回：

```json
{ "member": "M0001", "points": 1280 }
```
