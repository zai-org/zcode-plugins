# 茶铺小程序 产品手册

## 会员积分
会员积分（Loyalty Points）是顾客每次消费后获得的奖励。会员积分可以在小程序里兑换优惠券。每消费 1 元获得 1 个会员积分，会员积分有效期为 12 个月。

## 优惠券
优惠券（Coupon）分为满减优惠券和折扣优惠券。满减优惠券在订单金额达到门槛后可用，折扣优惠券按比例减免。一个订单只能使用一张优惠券。

## 外卖配送
外卖配送（Delivery）由合作骑手完成。配送范围为门店 3 公里以内。顾客可以在订单详情页查看配送进度。超出配送范围的地址会提示改为到店自提（Pickup）。

## 储值卡
储值卡（Stored Value Card）可以在门店或小程序充值，储值卡余额可用于所有门店。储值卡不能兑换现金。
