# Release notes 2.4

- Loyalty Points now expire after 12 months; members see the expiry date on the points page.
- Coupon stacking: a Coupon cannot be combined with Loyalty Points redemption.
- Delivery radius is now set per store. Orders outside the delivery radius switch to Pickup.
- Stored Value Card top-ups of 200 yuan earn 100 Loyalty Points.
- The order details page shows delivery progress in real time.
