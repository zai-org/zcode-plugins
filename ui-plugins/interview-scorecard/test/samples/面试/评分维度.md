# 门店运营专员 · 面试评分维度

评分：1–5 分（可打半分），加权平均 3.5 分以上建议录用。每个维度打分时写一句依据。

## 沟通表达 20%
1 = 答非所问，表达混乱
3 = 清楚完整，能讲明白一件事
5 = 简洁有说服力，会根据对象调整说法

## 数据分析 / 数据能力 30%
1 = 看不懂基础报表
3 = 会用 Excel 做透视和简单图表，能从数据里看出问题
5 = 能自己搭指标、做对比实验并给出可执行的结论

## 用户思维 25%
1 = 只从自己角度想问题
3 = 能说出用户的主要痛点
5 = 有真实的用户调研或改进案例，能量化效果

## 执行与抗压 15%
1 = 遇到困难就停下
3 = 能按时完成分配的任务
5 = 主动推进跨部门的事，高峰期也稳定

## 团队协作 10%
1 = 只关心自己的部分
3 = 能配合他人
5 = 主动补位，带动团队
